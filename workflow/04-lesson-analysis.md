# 流程四 · 单课考查方向分析

> **触发词**：分析某课考查方向、某课考什么、归纳 X 课考点、结合题库看重点、某课在中考/期末怎么考、这课的命题规律。
>
> **前置检查**：运行前确认已初始化（`<skill>/scripts/skill_config.json` 含有效 vault 或 `TNOTE_VAULT` 已设）；**未配置 → 先读 `workflow/00-init.md`**。

从题库按「课」取题 → 统计分布 → 归纳考查方向 → 产出教师用报告。

**与流程五的分工**：本流程管「**一课怎么考**」（微观、命题角度）；流程五管「**一册考什么**」（宏观、范围与取舍）。

## 1. 确认课名（必须能命中题库「课」字段）

- 课名以 BOOK_INDEX 为准，形如 `第5课 古代希腊`；用户给简称（如「古代希腊」）时先补全为词表课名
- ⚠ **课次漂移**：教材改版后同一内容课次会变（旧 9上「第一次工业革命」第 20 课 → 2026 版第 19 课）→ **课名比对优先于课次比对**
- 跨册考点（如 9下 内容出现在 9上 卷）按课名照样取得到，不受册别限制

## 2. 取题（三口径）

```bash
python scripts/scan_lesson.py --lesson "第5课 古代希腊"                    # 全涉（默认，防漏题）
python scripts/scan_lesson.py --lesson "第5课 古代希腊" --口径 主考        # 该课被直接考查（命题落点）
python scripts/scan_lesson.py --lesson "第5课 古代希腊" --口径 兼涉        # 该课只作背景/参照/结论被调用
python scripts/scan_lesson.py --lesson "第5课 古代希腊" --body            # 附题干全文
```

**报告口径**：主体用 **主考**（这才是这课真正被考的部分）；**兼涉单列一节**——说明该课被当参照系/背景板的频次与方式。实测例：9上第5课《古代希腊》全涉 25 题 = 主考 16 + 兼涉 9，兼涉题集中在跨时段材料题（第 21 题）作对比项。

## 3. 漏标与关联题排查（必做）

```bash
python scripts/scan_missed.py "第5课 古代埃及" "金字塔|法老|尼罗河|象形文字"
python scripts/scan_missed.py "第5课 古代希腊" "雅典|城邦|民主" --口径 主考   # 专查「只当背景标过、正文却在讲它」
```

- 命中题**逐条判断**：属**跨课综合**（材料涉及它、落点在别处）还是**漏标**（该补进该题「课」字段）
- ⚠ 两个检查别混：本工具查**正文内容**漏标；`scan_questions.py` 的 `ℹ 定位字段提示` 查**单元/册别漏写**

## 4. 读关键材料题正文

材料解析题首行常是「阅读材料，完成下列要求。」，看不出考点，须提全文：

```bash
awk 'BEGIN{c=0} /^---$/{c++; if(c==2) print "--BODY--"; next} c>=2' "<题文件路径>" | head -40
```

## 5. 归纳考查方向

按知识点聚类成 3—5 个方向，每个方向给：题量 / 占比 / 主力题型 / 设问规律 / 答题落点。

## 6. 产出报告

**落点**：`{vault}/3-试题研究/{册别}第N课{课名}-考查方向分析.md`

报告结构（7 节，固定）：

1. 数据来源与筛选口径（课名、题量、**主考 / 兼涉拆分**、覆盖年份考区、教材子目）
2. 结论速览表：方向 / 题量 / 占比 / 主力题型 / 命题重心
3. 分方向详解：每方向一表（题号 + 材料切入 + 答案落点）+ 教学落点
4. 能力与素养画像：关键能力、核心素养、素养层次、难度、年份、考区分布
5. 教学与备考建议（约 5 条）
6. 学生版学习要点（可直接抄给学生的记忆点、易错点）
7. 附：题目清单表（题号 / 题型 / 年份考区 / 方向 / 知识点 / 难度 / 能力）

## 铁律（分析专属）

1. **数据说话**：结论须由 `scan_lesson.py` 的统计支撑，不凭经验判断
2. **口径写明**：报告首节必须写「主考 N 题 / 兼涉 M 题」，兼涉题单独成节，不与主考混算
3. **漏标题单列**：`scan_missed.py` 命中的题在报告中单独列出，并说明归属判断（跨课 / 漏标）

## 陷阱（分析专属，血泪）

1. **frontmatter 列表三种写法**：顶格 `- 值`、缩进 `  - 值`、内联 `[a, b]`——脚本统一走 `qb_schema`；若自己另写解析器必须同时兼容三种，否则严重漏题（历史实测漏 4/25）
2. **Windows 中文路径**：脚本一律用绝对路径调用，避免 MSYS 路径转换出错
3. **标注会滞后**：部分题「课」字段为空或只标主考课，务必跑 `scan_missed.py` 并在报告中单列
4. **课次漂移**：改版教材课次会变，比对课名而非课次

## 交付

- 报告写完用 present_files 呈现
- 若还要给学生讲，可另出「学生版考向总结」（考什么 / 怎么问 / 一句话答题模板 / 配题），或生成 PPT（走 tencent-pptx）
