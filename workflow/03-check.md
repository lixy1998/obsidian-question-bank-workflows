# 流程三 · 校验与词表维护

> **触发词**：题库质量检查、校验、scan。
>
> **前置检查**：运行前确认已初始化——`<skill>/scripts/skill_config.json` 含有效 vault 或 `TNOTE_VAULT` 已设；**若脚本报「未配置题库库」→ 先读 `workflow/00-init.md`** 完成配置再继续。

## 校验

`python scan_questions.py`（必填字段/id 唯一/枚举/课名词表/正文非空 + 统计；**关键能力旧格式为提示级**——存量徐奉先 3×3 标注迁移未完成时输出 `ℹ` 提示，不计入「✓ 无问题」）；`--json` 机器可读

- **id 多值校验（v1.3.0）**：id 为 list 时逐项查重（含列表内自重复）；并做**一题多卷交叉校验**——别名 id（第 2 项起）若仍作为独立题存在于库中，报 `[别名未归档]`（提示该跑 `dedupe_questions.py --merge`）
- **学史方法课名**（方案 B，2026-09-13）：`学史方法-<方法名>` 只校验方法名是否在 BOOK_INDEX「初中·学史方法（全六册）」15 表内，**不校验册别**（各册分配待确认；中高考题常按「史事 + 方法维度」跨册标注）
- 输出中的「一题多卷：N 题含别名 id」为信息行，非问题

## 查重体检（v1.3.0 起，建议每次批量录入后跑）

```bash
python dedupe_questions.py --scan --out <工作区>/疑似重复清单_YYYYMMDD.md   # 全库查重 → 候选清单
python dedupe_questions.py --list-merged                                   # 已合并题一览（id 多值）
```

- 命中候选 → 走 L4 AI 裁定 + L5 用户裁定（判定规则见 `references/fields.md`「一题多卷与去重」）
- 合并/回滚一律经 `dedupe_questions.py --merge / --rollback`（默认 dry-run，`--apply` 才写盘）
- ⚠ **禁止手工删除重复题**：手工删除不写日志、不更新别名 id、不留卷内清单，无法回滚也无法还原原卷

## 词表校准

scan 定位「课名词表」问题 → 写一次性映射脚本（`{字段}: {旧值}` 行替换）或对照 BOOK_INDEX 手动 Edit；反复场景写通用重映射脚本或直接 Edit md 的 YAML 字段

## 索引维护

`python gen_index.py`：从 BOOK_INDEX 生成 `1-MoC-索引/` 六册试题索引 + 学史方法索引（词表更新后重跑即可重建）

## 铁律（校验专属）

1. **校验不过不交付**：录入/词表维护后必须跑 scan，输出「✓ 无问题」才可交付；「关键能力旧格式」的 `ℹ` 提示级问题不阻塞交付，但需标注待迁移

## 陷阱（校验专属，血泪）

1. **索引列由 gen_index.py 模板决定**（2026-08-24）：六个试题索引的 Dataview 列（`TABLE id AS 题号, 课, 知识点, 题型, 素养层次水平, 关键能力`）写死在 `gen_index.py` 的 `dv_query()`；**手工改索引文件会在下次重建时被覆盖**——要改索引列必须改脚本模板，不要只改生成后的 md 文件
2. **录入/组卷流程勿跑 gen_index.py**（2026-08-24）：索引为「混合式 MOC」（手工骨架 + Dataview 动态查询），新题 YAML 命中「课」字段即自动流入对应课，**录入新题、组卷出题均无需重建索引**；仅当 BOOK_INDEX 词表变化（新课加入/课名修订）时重跑重建
