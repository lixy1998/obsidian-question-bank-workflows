# 流程四 · 多维度考查方向分析（课 / 单元 / 专题）

> **触发词**：分析某课/某单元考查方向、某课考什么、某单元考什么、归纳 X 课/单元考点、结合题库看重点、某课在中考/期末怎么考、这课/这单元的命题规律、专题分析（跨单元主题，如「区域文明的多元发展」「中央集权的演变」）、按考察角度出练习、角度分类练习。
>
> **前置检查**：运行前确认已初始化（`<skill>/scripts/skill_config.json` 含有效 vault 或 `TNOTE_VAULT` 已设）；**未配置 → 先读 `workflow/00-init.md`**。

从题库按「课 / 单元 / 专题」取题 → 统计分布 → 按**考察角度**归纳 → 产出教师用报告 → （可选）产出按角度分组的系列练习。

**产物定位：报告即发布稿，内部与发布合一。** 落库报告同时是对外可发布的稿子（公众号/网页/文档），故按**发布化规范**撰写（见 §6b）：正文用教师语言、表格窄化、出处用**纯发布式表述**、不出现内部路径与 id。题库搭建者本人可据「学年+考区+卷别+题号」直接回库对应（卷别与题库目录名同形）。

**方法论来源**（2026-09-19 吸收闫亚宁「角度分类法」，源自闫亚宁老师公众号「历史实战方法课堂」《高考题应该这样分类》一文）：把真题按**考察角度**归类，而非仅按知识点罗列——让学生快速看到"同一考点命题人是如何切入考察的"；每角度配典型设问词与判断依据；同角度真题成组，做完自能消化。

**与流程五的分工**：本流程管「**怎么考**」（课=微观命题角度；单元=中观结构；专题=跨单元聚焦）；流程五管「**一册考什么**」（宏观、范围与取舍）。

## 0. 维度选择（先定维度，再取题）

| 维度 | 粒度 | 适用场景 | 取题依据 | 报告落点名 |
|---|---|---|---|---|
| 课 | 微观 | 一课怎么考、单课命题规律 | 「课」字段 | `{册别}第N课{课名}` |
| 单元 | 中观 | 一单元怎么考、单元内各课侧重、跨课综合题占比 | 「单元」字段 | `{册别}第N单元{单元名}` |
| 专题（跨单元） | 宏观聚焦 | 围绕主题跨单元跨册聚合（如「区域文明的多元发展」＝9上第1—6课＋纲要下第1—2课） | 专题定义（课名组，可选单元组） | `专题-{专题名}` |

- 三维度数据口径同源：主考 / 兼涉 / 全涉（`scan_lesson.py` 对单元与多课组同样适用）
- 不确定选哪个：问「分析结果给谁用」——讲一节课用课维度；整单元复习/期中备考用单元维度；专题复习课、跨册知识整合、命题研究用专题维度

## 1. 确认对象名（必须能命中题库对应字段）

- **课维度**：课名以 BOOK_INDEX 为准，形如 `第5课 古代希腊`；用户给简称（如「古代希腊」）时先补全为词表课名。⚠ **课次漂移**：教材改版后同一内容课次会变 → **课名比对优先于课次比对**
- **单元维度**：单元名以 BOOK_INDEX 单元名行为准（如 `第2单元 古代欧洲文明`）；⚠ 单元名不得带注记
- **专题维度**：先写**专题定义**（报告须在「附：样本说明」原样记录，保证可复现）：
  
  1. **课名组**：跨单元/跨册的**完整课名**列表（逗号分隔传给 `--lesson`）
  2. **可选单元组**：以整单元为范围时用 `--单元` 补充
  3. **特征关键词组**：留给第 3 步漏标反查用，不进取题主口径
  - ⚠ **跨册同名课次**：必须传完整课名——裸课次「第1课」会误中他册同课次课（9上第1课 ≠ 纲要下第1课）；子串匹配按完整课名隔离

## 2. 取题（三口径，`scan_lesson.py`）

```bash
python scripts/scan_lesson.py --lesson "第5课 古代希腊"                    # 单课·全涉（默认，防漏题）
python scripts/scan_lesson.py --lesson "第5课 古代希腊" --口径 主考        # 该课被直接考查（命题落点）
python scripts/scan_lesson.py --lesson "第5课 古代希腊" --口径 兼涉        # 该课只作背景/参照/结论被调用
python scripts/scan_lesson.py --lesson "第5课 古代希腊" --body            # 附题干全文
python scripts/scan_lesson.py --单元 "古代欧洲文明"                        # 单元维度
python scripts/scan_lesson.py --lesson "第2课 古代两河流域,第3课 古代埃及,第4课 古代印度,第5课 古代希腊,第6课 古代罗马"   # 专题维度（多课聚合）
python scripts/scan_lesson.py --单元 "史前时期" --卷 "洛阳市2024-2025学年7上期末,洛阳市2025-2026学年7上期末"   # 限定卷范围（逗号多值子串匹配卷目录名；范围收窄器，不改变口径逻辑）
```

**分阶段取数（报告「分阶段分析」节用）**：

```bash
python scripts/scan_lesson.py --单元 "史前时期"                                    # 全库取题（含中考）→ 按 id 带「中考」筛出中考坐标
python scripts/scan_lesson.py --单元 "史前时期" --卷 "2024河南中考,2025河南中考,2026河南中考"        # 上位·真题：河南中考近年
python scripts/scan_lesson.py --单元 "史前时期" --卷 "2025郑州一模,2026南阳一模,2026安阳一模"          # 上位·模拟：各地中考模拟题
python scripts/scan_lesson.py --单元 "史前时期" --卷 "一模,二模,测评"                              # 上位·模拟全量：本地＋各地模拟卷一次取齐（子串匹配，实测卷×3、命中 33 题）
python scripts/scan_lesson.py --单元 "史前时期" --卷 "郑州市二七区2024-2025学年7上期末,郑州市经开区2024-2025学年7上期末"   # 同层对照：外地阶段测试卷
```

- 三层关系：**本卷（阶段测试）→ 同层（外地同期卷）→ 上位（中／高考真题 ＋ 各地中／高考模拟题）**
- ⚠ **上位不只真题**：各地一模／二模／名校联盟测评**同属「上位」**，与真题并列取材。真题反映既定命题事实，模拟卷反映当年度备考取向，两者合看才是完整的上位参照；只取真题会漏掉整类坐标。模拟卷目录名形如 `{年份}{地区}{一模\|二模\|测评}`（如 `2025郑州一模`、`2024中原名校联盟测评`）
- ⚠ **分值口径不可混算**：河南中考卷为 50 分制、地市期末多为 100 分制（见 `references/分析基线-洛阳.md`），跨类只比题型与考点，不比分值权重

**报告口径**：主体用 **主考**（这是对象真正被考的部分）；**兼涉单列一节**——说明对象被当参照系/背景板的频次与方式。

**多课/单元模式自动输出三段分布**（单课模式不输出，行为向后兼容）：

| 段 | 内容 | 用法 |
|---|---|---|
| 【主考落点】 | 各课/单元作为首项的题数 | 单元内各课侧重、专题内各考点权重 |
| 【兼涉调用】 | 各课/单元在第 2 项起被调用的次数 | 哪些课常当背景板 |
| 【册别分布】 | 命中题按册别首项计数 | 专题跨册结构一目了然 |

- ⚠ **命中分布按位置计数、题数按题计数**：一题多处命中（如课列表两个位置都命中目标组）时，分布合计可大于题数 1~2，属正常统计口径差异，明细里人工核对即可
- `--lesson` 与 `--单元` 可同给（并集口径），但一般只用其一，混用会让报告口径难写清

## 3. 漏标与关联题排查（必做，专题维度尤其重要）

```bash
python scripts/scan_missed.py "第5课 古代埃及" "金字塔|法老|尼罗河|象形文字"
python scripts/scan_missed.py "第5课 古代希腊" "雅典|城邦|民主" --口径 主考   # 专查「只当背景标过、正文却在讲它」
```

- ⚠ **首参是「课名」，不是单元名／专题名**：工具按「课」字段匹配，传单元名（如「第2单元 夏商周时期」）会把全库所有正文命中关键词的题一律报出，等于没筛。**单元维度**须**逐课分别反查**（单元内每课各跑一次，再合并结果、去掉重复）；**专题维度**的课名组同样逐课跑，另叠加下方的特征关键词反查
- 命中题**逐条判断**：属**跨课综合**（材料涉及它、落点在别处）还是**漏标**（该补进该题「课」字段）
- **专题维度**：用专题特征关键词反查（如「区域文明的多元发展」用 `金字塔|汉谟拉比|种姓制度|佛教|城邦|民主政治|亚历山大|罗马法|楔形文字|象形文字`），能捞到「正文讲文明但课字段只标了别处」的漏网题
- ⚠ 两个检查别混：本工具查**正文内容**漏标；`scan_questions.py` 的 `ℹ 定位字段提示` 查**单元/册别漏写**

## 4. 读关键材料题正文

材料解析题首行常是「阅读材料，完成下列要求。」，看不出考点，须提全文：

```bash
awk 'BEGIN{c=0} /^---$/{c++; if(c==2) print "--BODY--"; next} c>=2' "<题文件路径>" | head -40
```

## 5. 归纳考察角度（本流程核心）

按**考察角度**聚类，不只按知识点。一个「考察角度」= **三件套**：

| 件 | 内容 | 示例（考点：雅典民主） |
|---|---|---|
| **切入视角** | 命题人从哪个角度切进考点 | 从「地理环境制约政体」切入 / 从「公民范围局限」切入 / 从「文化影响」切入 |
| **典型设问词** | 该角度高频设问词及其作答逻辑 | 选择题：反映/体现/说明/表明/旨在/意在/据此可知/强调/折射；非选择题：概括/分析/简述/比较/评述（各设问词决定答案组织方式） |
| **判断依据** | 学生识别该角度的一句话依据 | 设问指向「多元性」→ 找各文明**差异**而非共性；设问「折射」→ 由现象推背后制度/观念 |

- **概念辨析**：角度涉及易混概念时单独标出（如「宗法制 vs 宗法观念」「城邦 vs 帝国」）——高频概念要细化到「什么情境选它」
- 每角度给：题量 / 占比 / 主力题型 / 年份考区分布 / 难度
- 角度数量：3—6 个为宜；题量少的对象（<20 题）2—3 个即可
- ⚠ **角度有据**：每个角度须有 ≥2 题支撑；单题不成角度（并入相近角度或归「其他」）

## 5b. 选题与筛题判据（对接《命题方法论》· 2026-10-23 定）

**定位：这是内部判据，不进报告措辞。** 定完角度、选典型题之前，先用这批判据把不合规的题剔出去——避免把「看着热闹实则无效」的题当成本课/本单元的典型，再据此下教学结论。

> 判据来源：`D:/Documents/Teach-历史教学/methodology-方法论/topics-主题/命题方法论.md`（Obsidian 中即 [[命题方法论]]）。该文件是**命题端（怎么出题）＋评估端（怎么验题）**的框架，**不是选题目录**——只能拿来筛题，不能当「选题清单」用。

### 可用的判据

| 判据 | 方法论位置 | 在选题环节怎么用 |
|---|---|---|
| **情境有效性** | §2.9 七维度·有效性 | 「遮住情境还做得出来吗？」——能 → 情境是摆设，**不作典型题** |
| **情境典型性** | §2.9·典型性 | 「这条史料除该篇论文外还有人用过吗？」——没有 → 孤证，**降级不用** |
| **伪素养识别** | §2.7 两条诊断判据 | 「不看材料即可作答」＝知识记忆题，**别标成素养题当典型** |
| **开放题质量** | §2.7 | 「开放 ≠ 好题」——须有明确考查目标与路径预设，否则不作范例 |
| **三不考** | §2.5 第 8 条 | 敏感问题、消极问题、过于时政化的问题**不入正文角度例证**（可进附表留档） |
| **难度分层** | §2.8 | 只用**定性**易／中／难，判据见 `references/fields.md`「难度标注判据」（三档定义＋非选择题同样分档） |
| **目标要求写法** | §2.1b | 标注「学科内容 → 目标要求」时按「行为动词＋内容对象＋认识层动词＋价值落点」一句式，不写「基础能力／高阶能力」这类空话 |

### 三条硬约束（跨学段坑，务必守住）

| # | 约束 | 原因 |
|---|---|---|
| 1 | **初中不套高中 2025 修订口径** | 义教课标 2025 修订仍作「运用**可信史料**」；高中 2025 修订才删「可信的」、改考「辨伪过程」。用高中新口径评初中题＝误判（会把正常题判成「材料不够可疑」）。 |
| 2 | **不套难度数值** | 0.55—0.65／易中难 3∶6∶1／区分度 ≥0.4 是**高中等级考**口径；初中无对应课标数值，只能定性。 |
| 3 | **不标「水平 N」** | 义教课标**不划水平**；初中报告写「水平 3」是把高中学业质量的编号硬搬过来。 |

### 报告层怎么写（唯一出口）

报告正文**不出现**「命题方法论」「情境七维度」「命题蓝图」等内部框架名——读者不认，也暴露内部体系。只在**「附：样本说明」**写一行：

> **选题依据**：以《义务教育历史课程标准（2022 年版 2025 年修订）》学业质量要求为基本依据，参照河南省近年中考试题特点；每个角度不少于 2 题，优先选取情境完整、设问指向明确的题目。

- 高中对象把「义务教育（2022 年版 2025 年修订）」换成「普通高中（2017 年版 2025 年修订）」
- 报告用途为**命题研究**（非教学备考）时，可加「并参照高考评价体系的能力考查要求」——属公开公认表述，不涉内部框架
- ⚠ 该行是「选题依据」，**不是**「理论基础」；不展开论述，一句话结束

| 七 | **附：样本说明＋试卷－题目清单** | ① 样本说明：卷源（按阶段测试、模拟题、真题顺序排列，可表格化）、题量、统计口径一句话、**专题维度须原样记录专题定义**、**选题依据一行**（写法见 §5b）；② 题目清单：**全部主考题**逐条列明题号/题型/年份考区/角度/考点/难度/能力/出处（出处列逐题挂 wikilink），**正文已照录原文者标「已录」**。详细统计不进正文 |

⚠ **正文照录范围与附表分工**（2026-10-23 定）：

| 出处 | 照录什么 | 附表怎么标 |
|---|---|---|
| 分角度详解 | 每角度 2~3 道，含图/含材料者优先，难度覆盖易—中 | 标「已录」 |
| 分阶段分析 · ① / ② 各自段末 | 该段提及的**全部**题（见 §6f） | 标「已录」 |
| 其余题 | 不照录 | 只列信息行 |

⚠ **「求全」的边界要分清**：**分角度详解**不求全——完整性由附表兜底，该节只求「看懂怎么考」；**分阶段分析的 ①② 两段则要求全录**（铁律 8），缺题即不合格。附表是**全量回溯清单**（不是「剩余题清单」——否则铁律 6 的角度计数三重回校无法成立）。

⚠ **存量报告不返修**：早期按 8 节／9 节写成的报告（角度速览单列、原文单列小节等）仍属正常，新报告一律按上面 7 节。


## 6b. 发布化规范（报告与练习通用）

报告即发布稿，以下要点**默认执行**：

| 项 | 要求 |
|---|---|
| 出处表述 | **纯发布式**：`{学年}{考区}{卷别} 第N题`（如「2025-2026 学年洛阳市7上期末 第1题」），卷别与题库目录名同形；**禁自创简写**（「2026河南-09」这类既像中考又实为期末的写法禁用） |
| 内部信息 | **不出现**题库 id、库内路径、设备/环境信息、学生信息 |
| 术语 | 正文用教师语言（「以提炼归纳为主」「开始考因果推断」）；`A3-概括`/`层次2` 等受控术语仅在必要处括注 |
| 表格 | ≤4 列优先；4 列以上改分条列点或出图；超 10 行的宽表不进正文（入附表） |
| **真题引用** | **选择题：题干＋四个选项完整照录**——材料不压缩改写、表格按原形态、选项一个不缺（**禁「……」截断**）；**非选择题：可节选**——节选**依据分析对象**（跨课/跨单元题该留哪一问、哪段材料，见 **§6d**），篇幅性摘取材料亦可，两者均须标「节选」。**答案与选项文字一律照录题库字段，禁凭判断书写**（2026-09-20 实测教训：良渚水利题官方答案 C「环境适应与改造能力」，曾凭常识误写为 A「经济发展水平」，连带教学结论出错） |
| **图片处理** | **只写图注、不嵌原图**（2026-10-23 定）；**图注必写画面内容，禁裸「（图）」**（实案：两份报告共 88 处裸图注，读者无从理解题意）；取法优先级＝**读原图＞解析字段＞题干上下文＞显式标注「待核」**；多图用「｜」分隔、年代尺写结构、括号必须配对；看图循题目链接回题库。详见 **§6g**。引文中的引号统一中文弯引号 |
| 配图 | 建议出 1 张信息图（角度占比＋分值权重／三年对比），便于保存转发 |
| 本地性 | 主动挖掘本地元素（本地考古发现、本地史事入题的卷面证据）——对外发布的差异化价值点 |
| 篇幅 | **不设字数限制**——以「把该对象的命题角度讲透」为准，篇幅服从内容，**不因凑字数删减真题与角度细节**——发布时按平台拆「**分析篇＋练习篇**」两篇：分析篇＝开篇（含角度速览表）/样本/能力画像/建议，练习篇＝分角度真题（含题干）＋学生版要点＋附表 |
| 合规 | 真题注明来源与年份、不整卷搬运、图片注明出处（教材/考古报告）、不标原创声明 |

## 6c. 题目回溯链接规范（报告正文与附表）

**原则：报告里出现的每一道题，都要能一键回溯原题。** 链接用 Obsidian wikilink，别名统一用**纯发布式出处**（与 §6b 出处表述同形），使读者读到的文字与链接语义一致。

**四处必挂链接**（缺一即不合格）：

| 位置 | 挂法 | 说明 |
|---|---|---|
| **分角度详解 · 正文题** | 标题行＝「**类型 + 出处**」，出处段做链接：`**【{类型}】[[卷别路径/题号\|{学年}{考区}{卷别} 第N题]]（题型 · 分值）**` | 正文选入的题（2~3 道/角度）**逐道必挂**，不留裸题号 |
| **分阶段分析 · ①② 两参照层** | 正文与表格中**每一处提及的题号**就地挂链接（别名「{卷别} 第N题」） | ① 课堂教学同步（各市一模/同期卷）＋ ② 上位（**中／高考真题与各地模拟题**）内出现的题号**全部挂链**，不写裸题号 |
| **分阶段分析 · ①② 段末原文** | 每题标题行同「正文题」写法（自带出处链接） | 段末照录的题**逐道自带链接**，不再另挂；段末未收但分析中提及的题，仍须在分析正文就地挂链 |
| **附表** | 逐题挂 wikilink（出处列） | 已由陷阱 11 覆盖，本规范重申为其上位要求 |

**标题行的「类型」按题目实际来源写（2026-10-02 定）**：

| 题目所在类别（路径第一段） | 类型写法 |
|---|---|
| `初中-1中考真题` / `高中-1高考真题` | **中考真题** / **高考真题** |
| `初中-2中考模拟题` / `高中-2高考模拟题` | **中考模拟题** / **高考模拟题** |
| `初中-3阶段测试` / `高中-3阶段测试` | **阶段测试** |

- ⚠ **废止「真题 N」流水序号**：旧写法把期末卷、模拟卷一并标成「真题」（归类错误），且序号在每个角度内从 1 重新编号、同一报告里多处重号，读者据此指代必然歧义。**新标题一律不出现「真题 N」**。
- ⚠ **不取「来源」字段的类型标签**（`真题/模拟卷/期末卷`）：该标签实际标注不严（期中卷也标 `期末卷`），**按库类别取才准**。
- 正文需要泛称这批考试原题时，用「这批题」「上述各题」等表述，**不要写「真题 3」**——标题行已给出唯一出处，可直接复述出处（如「2026河南中考 第 14 题」）。

- ⚠ **两参照层挂链注意**：该节多为「洛阳卷 第 10—13 题」这类**区间表述**——区间无法逐题挂链时，拆为单题链接（如 `第 10—13 题` → `[[…10|…第10题]]、[[…11|…第11题]]…`）；确属概括性一笔带过（如「共 3—4 题」的总量描述）可不挂，但**凡写出具体题号即挂链**
- ⚠ **同一题在正文多处出现**：每处都挂（Obsidian 允许同链接多次出现），保证任何一处都能回溯，不做「首见挂链、后文裸写」

**正文「引用原题」的判断（按重要性三档，非一刀切）**——链接是「回得去」，引用是「看得见原文」，两者独立。

⚠ **适用范围：只管「分角度详解」节**。「分阶段分析」节的题**一律全录**（见 §6f），不走这三档。

| 档 | 何时引用（贴出题干） | 典型场景 |
|---|---|---|
| **必引** | 附表有此题、但正文此前无对应落点（**补缺**）；史事/素材/情境需**细化说明**才能讲清角度（如材料题的多则材料、图像题的画面内容） | 兼涉转主考的关键题、需展示材料细节的例证 |
| **可引** | 同角度支撑题、设问词典型题、答案分寸需展示「怎么错」的题 | 与正文题同角度、可并列比较者 |
| **不引** | 与正文题同质、仅作批量罗列者 | 留给附表兜底即可（附表是全量回溯清单，见 §6） |

- 引用格式与 §6b「真题引用」一致：**选择题题干＋四选项完整照录；非选择题可节选并标注「节选」**；答案照录题库字段
- 判断口诀：**「读者读到这里，会不会想看到原题？」** 会 → 引；只想确认「有这回事」→ 只挂链

**真题正文的书写形态（2026-10-02 定，原为引用块，已全库改造）**：

真题标题行（`**【{类型}】…**`）下方的题干／材料／选项**一律写成普通段落，不加 `>` 引用符**：

```
**【阶段测试】[[…|洛阳市2025-2026学年7上期末 第1题]]（选择 · 2 分）**
下面是我国境内的部分古人类情况，由此可知（　　）
                ← 此处必须有空行（md 表格硬约束）
| 古人类 | 时间 | 地点 | 考古发掘成果 |
| --- | --- | --- | --- |
| 元谋人 | 距今约170万年 | 云南元谋 | 两颗门齿化石、一些粗糙的石器 |
(A) 我国有百万年的人类史　(B) 各地均有了丰富的考古发现　(C) 古人类开始了定居生活　(D) 古人类已掌握农业生产技术
✅ 答案 **A**

**【中考真题】[[…|2026河南中考 第 23 题]]（材料 · 节选：第(2)(3)问，共 8 分）**
```

- 节选题的括注＝`（题型 · 节选：第(N)问…，共 X 分）`；整题照录则写 `（题型 · X 分）`

**为什么不用引用块**：① 标题行已用加粗给出出处，引用块纯属冗余；② Obsidian **不支持在引用块内渲染表格**（Live Preview 与阅读模式都塌成文字），迫使表格写 HTML，而 HTML `<table>` 单元格内**不能再放 wikilink 与图片**——去掉引用符后限制解除，表格回归 md 语法、单元格可正常嵌链嵌图。

**段落间距规范（2026-10-02 定）**——真题块要**紧凑成一体**，逐题之间才留白：

| 位置 | 间距 | 说明 |
|---|---|---|
| 标题行 → 题干 | **不加空行** | 标题与内容紧连，整题为一体 |
| 题干 → 图片占位 → 选项／小问 → 答案／点拨 | **不加空行** | 同属一题，紧密相连 |

| 答案点拨 → 下一题标题行 | **1 空行** | 真题与真题之间留白 |
| 真题块 → 块外正文（`**点拨**`／`**教学落点**`／章节标题） | 保持原间距 | 块外不压缩 |

- 交付前自查：① `**【{类型}】` 标题行（类型＝中考真题／中考模拟题／阶段测试／高考真题…）的下一行**必须直接是题干**（不得为空行）；② 各 md 表格首行前一行**必须**是空行；③ 块内非空行不得因压缩而变动（脚本保证）

| 文档扉页元信息块（`> 数据来源：… 试题来源：… 分析日期：…`） | 与真题无关，属卷首说明 |
| 「原文示例／范文」类引文块（如小论文母题的例文） | 是引文而非真题照录 |

## 6d. 跨课 / 跨单元题的节选规则（2026-10-02 定）

**要解决的问题**：题库里有大量跨课、跨单元、跨册的综合题（「课」字段多值，首项＝命题落点、其后为兼涉项）。当分析对象只是其中一课或一个单元时，整题照录会把与本对象无关的材料与设问一并带进报告——既冲淡主题，也让读者分不清「**这道题里到底哪一问在考本课**」。

**总规则：只留与本对象有关的那一问及其依据材料。**

### 五步操作

| 步 | 做法 |
|---|---|
| ① 定位 | 看「课」字段：本对象在**首项**＝主考，在**其后项**＝兼涉；单元维度同理看「单元」字段 |
| ② 找问 | 逐小问读设问，就一句判据：「**这一问考的是本课／本单元吗？**」——设问指向本对象的保留 |
| ③ 配材料 | **先定留哪几问，再为它们配材料**：保留「材料 N」**当且仅当**被保留的小问**回指**它；「综合上述材料／综上所述／据此」类设问，须带上它回指的**全部**材料（不限于紧邻的一则），见下「回指型设问」 |
| ④ 标注 | 标题行括注写明：`（材料 · 节选：第(2)(3)问，共 8 分）` |
| ⑤ 兜底 | **一题里找不出任何与本对象有关的小问 → 不入正文**（按命中方式决定进附表或不列） |

### 回指型设问：节选的最小单位（2026-11-27 定）

**问题**：`2026许昌一模 第24题` 为材料一（1860/1879 俄国机器制造业统计表）＋材料二（苏联霸权衰落）＋(1)(2)(3)，(3) 设问「**综上所述**，谈谈俄国（苏联）发展历程对中国的启示」。报告只留材料二＋(2)(3)——设问一字未改，但「综上」只剩一则材料可综，答案 (3) 的「勇于改革」「改善民生」两条在节选文本里找不到依据。**节选失义不靠改字发生，靠删字发生。**

节选顺序须反过来：**先定留哪几问（每问能否独立成立）→ 再为留下的问配它回指的全部材料。**

| # | 判据 |
|---|---|
| ① | **回指词先定范围**：设问含「综上所述／综上／上述材料／据此／由此可见／这一／这些」时，节选单位是「该问 ＋ 它回指的全部材料」，不是「该问 ＋ 紧邻一则」；指涉拿不准按整题处理。全题仅一则材料时，「综上」即指该则，节选不受此限。 |
| ② | **合不上就删问，不删料**：回指范围与被留材料对不上时，删该问（如只留 (2) 供「归因」分析），不要把依据材料删掉、留一个空转的设问。删问是减法，删料会让留下的问失义。 |
| ③ | **答案回指自查**：节选后按题库 `答案` 字段逐点核，每个要点须能在保留的文字或表格里找到依据；找不到即删多了，回退整题或补齐材料。 |

- **编号不重排**：节选后小问保持原卷编号（留 (2) 仍是 (2)），不改写成 (1)，否则回原卷对不上。
- **该题的正确走法**（两种，不设中间态）：只服务「苏联解体的多重归因」→ 材料二＋(2)，标 `（节选：第(2)问，共 3 分）`；要保留「启示」落点 → **整题照录**（材料一的统计表照转，6 分）。

### 分场景口径

| 场景 | 处理 |
|---|---|
| 正文 · 本对象＝**首项**（主考） | **整题照录**；材料过长可作**篇幅性摘取**（删无关段落、留与设问相关部分；⚠ 回指型设问须留足回指对象，见上节）并标「节选」 |
| 正文 · 本对象＝**非首项**（兼涉）或跨课综合 | **按小问节选**（走上表 ①—④） |
| 附表 | **整题登记、不节选**——附表是回溯清单，须与题库原题对得上 |
| 角度练习（给学生做） | **整题呈现、不裁剪**——学生要作答，题目残缺就做不了；跨范围题在练习里要么整题收录、要么不收 |
| 组卷出卷 | 见 `workflow/02` 铁律 1（跨范围题按小问裁剪，优先整题剔除）；⚠ 脚本**不支持小问级裁剪**，卷面节选须人工完成 |

- **先判「整题」还是「节选」，再动括注**（2026-10-02 存量复查教训：40 处标「节选」的题里，15 处其实是**整题照录**，误标会让读者以为题面不全）：
  - **全部小问都与本对象相关 → 就是整题**，写 `（材料解析题 · 14 分）`，**不标「节选」**。判据两条：① **小问齐全**（报告保留的问号＝原题全部问号）；② **材料则数不减**——⚠ 报告按 §6b 用「（图：…）」图注占位呈现图片，**不算删材料**，别据此误判节选。
  - 只有确实**删了小问**或**删了材料**才标「节选」，并把保留范围写进括注。
  - ⚠ 判据要**回题库读原题实测**（小问数、材料则数），不凭印象；「设问类型」类报告（按设问分类摘录）几乎必为节选，须逐条写明保留哪几问。
- **括注格式**：`（材料解析题 · 节选：第(2)(3)问，共 8 分）`；**题型名用受控枚举**（选择题／材料解析题／论述题／综合探究题／填空题），不写「材料」「小论文」等简称
- **两条硬约束**：① **设问文字一律照录原文**（不得改写、不得为行文顺畅而调字）；② **不得把别课的材料或小问挪来凑**——节选是**减法**，只能删，不能改、不能加
- **分值口径**：节选后标**实际保留小问的分值之和**，取值顺序——**原题小问末尾分值 → 答案字段该问分值**；两者都取不到则**不标分**（**不可按整题分值均分**，那是组卷答题卡留白的口径，不适用于报告引用）
- ⚠ **节选只发生在输出环节**（报告／练习／卷面），**题库原题文件一律不动**——题库是原始资料，节选是呈现策略

## 6e. 导出 docx（2026-10-23 定·两条路径按需选）

报告要发给别人时走这里。**核心事实：wikilink 是 Obsidian 私有语法，任何转换器默认都不认**——不预处理就会把 `[[初中-3阶段测试/…/08|第 8 题]]` 整串内部路径印进 word。

| 路径 | 适用 | 前置设置 | 结果 |
|---|---|---|---|
| **A · Obsidian 内 Pandoc 插件**（主用，单篇按需导） | 手边导出某一份 | ① Export from = **Markdown**；② Extra Pandoc arguments 填 `--from markdown+wikilinks_title_after_pipe` | wikilink→别名、表格 `\|` 正常、frontmatter 不输出，**无需预处理报告** |
| **B · `md批量导出word` 脚本**（批量） | 整目录一次导 | 脚本已默认剥离 wikilink（`--keep-links` 关闭） | 同上，且带图片缩放与表格锁宽 |

- ⚠ **A 的机制**：pandoc 默认 md reader 不认 `[[a|b]]`，必须显式开 `wikilinks_title_after_pipe` 扩展。插件的 Extra args 追加在它自带的 `--from markdown` **之后**，pandoc 取**后出现者**为准（3.11 实测）。同理换行会被转成空格，一行写完即可。
- ⚠ **`[[路径]]` 裸链接导出后是整条内部路径**——wikilink 一律带别名（现有报告已全部合规，2026-10-23 实测 32 份 0 例）。
- ⚠ **两条路径都不带图**：正文图片是「（图：…）」图注占位。要让对方看到图，须先把原图复制汇总到 md 同级 `images/`、引用改写为 `images/文件名`、图注占位替换为 `![](...)`。
- ⚠ **A 路径排版朴素**（pandoc 默认参考模板，中文字体不定）——要求规范排版时加 `--reference-doc="<模板>.docx"` 到 Extra args，或改用路径 B。
- **导出后必查**（30 秒）：docx 内搜 `[[`、`]]`、`\|`、`初中-` 四项均应为 0；表格列数与 md 一致。

## 6f. 分阶段分析的写法：分析正文＋段末附原文（2026-10-23 定）

**为什么段末要附原文**：报告导出 docx 发给同行、领导、家长看时，段内只有「某卷 第 N 题」的出处和 wikilink——**导出后链接是死的，读者看不到题**。原文随段附上，读者读完分析立刻能对照原题，报告**离开 Obsidian、离开题库也能自足**。

### 两小节的结构（每段自成一体）

| 小节 | 前半：分析 | 后半：原文 |
|---|---|---|
| ① **课堂教学同步** | 作业练习、阶段测试（单元测试/月考/期中/期末）怎么考：卷源表 + 三条可借的经验 | 以 `**本段试题原文**` 加粗行起头，紧接逐题照录 |
| ② **上位（中／高考真题＋各地模拟题）** | 中／高考与各地卷怎么考：题位规律、落点演进、与本地卷的差异。**取材含真题与模拟题两类**，不只真题 | 同上 |

- ⚠ **上位不只真题（2026-10-23 定）**：② 的取材范围＝**中／高考真题 ＋ 各地中／高考模拟题**（一模／二模／名校联盟测评等）。真题反映既定命题事实，模拟卷反映当年度备考取向，两者并列取材、合看才构成完整的上位参照。卷源表与段末原文都要标清是真题还是模拟题（类型标签见 §6c），不要把模拟卷笼统写作「各地中考」。
- ⚠ **归位按性质、不按地域**：**中考模拟卷（无论本地外地）一律归 ② 上位**；期末／月考／期中这类**阶段测试**归 ① 课堂教学同步。本地模拟（如洛阳一模、涧西区一模）归 ② 时在卷源表标注「本地模拟」，便于读者对照「本地中考模拟 vs 外地中考模拟」的差异。
- ⚠ **题库模拟卷目录形如** `{年份}{地区}{一模\|二模\|测评}`（41 份，实测：`2025郑州一模`、`2024中原名校联盟测评`、`2023洛阳涧西区一模`）；取全量用 `--卷 "一模,二模,测评"`（子串匹配，任一命中即收）。
- ⚠ **原文不另开小节**：**不设** `### ③ 本节试题原文` 之类的独立小节。原文是该小节的**后半部分**，用 `**本段试题原文**` 加粗行分隔——加粗行不是标题，不进目录层级，读者顺着读下来是一体的。
- ⚠ **顺序不可倒**：先分析、后原文。读者要先知道「这一段在说什么规律」，再看题验证；先堆题会把分析淹没在题海里。
- ⚠ **学段内取材（2026-10-23 定）**：①② 选什么卷，**由分析对象的学段决定**——初中对象（7 上—9 下）只选**初中范围**试题（中考真题／**中考模拟题**／初中阶段测试）；高中对象（纲要上—选必 3）只选**高中范围**（高考真题／**高考模拟题**／高中阶段测试）。**不跨学段混选**：不拿高考题给初中课当「上位坐标」，也不拿中考题给高中课作对照。跨学段对照只在**专门做学段对比**的报告里出现（如「一道高考题的初中化改造」），不属本流程。
- ⚠ **分值口径不混算**：河南中考卷 50 分制、地市期末多为 100 分制（见 `references/分析基线-洛阳.md`），跨类只比题型与考点，不比分值权重；同一小节内 50／100 分制混排时，卷源表须标出制式。

### 原文的收录规则

| 项 | 规则 |
|---|---|
| **收录范围** | 该段里**凡写出具体出处**的题一律收（含仅作背景提及者）；只用总量描述（如「共 3—4 题」）而未指名的不收 |
| **归属** | 题收在**它被提及的那一段后面**——① 提到的收在 ① 末，② 提到的收在 ② 末；同一题两段都提到，收在**首次提及处**，后一处给指针 |
| **排序** | 段内按**卷次由近及远**，同卷按题号升序 |
| **重复题** | 分角度详解已照录的题，**只给指针**「见分角度详解·角度②」，不重复照录（避免同题两遍） |
| **书写形态** | 与 §6c「真题正文的书写形态」完全一致：标题行 + 题干 + 选项 + 答案，普通段落**不加 `>`**，表格前留 1 空行 |
| **跨课/跨单元题** | 按 §6d 节选，括注写明所涉小问与分值 |
| **图片** | 「（图：…）」图注占位（同 §6b）；对方要看真图须先按 §6e 汇总到 `images/` |
| **节选标注** | 整题照录写 `（题型 · X 分）`；**删了小问或材料才标「节选」** |
| **篇幅** | **不设上限**——原文是交付刚需，题多就长，不因篇幅删题 |

## 6g. 图片处理：图注必写内容，禁裸「（图）」（2026-10-23 定）

**问题实案**：`7上第2单元夏商周时期-考查方向分析.md` 有 **71 处**、`9下第1单元殖民地人民的反抗与资本主义制度的扩展-考查方向分析.md` 有 **17 处** 裸「（图）」——只有一个「图」字，读者根本不知道画的是什么；题干若写着「请从下图中任选两个及以上史实」，这道题就等于废了。根因不在脚本：题库题目文件的图片引用是 `![](images/18_1.jpg)`，**alt 为空**，生成报告时照抄模板就写成了「（图）」。

### 两条硬规则

1. **禁裸「（图）」**——图注必须写清画面内容，读者不看图也能读懂题意。
2. **括号必须配对**——`（图：总统（行政权）` 这类截断即不合格（实案见 `9上第6单元资本主义制度的初步确立-考查方向分析.md`）。

### 图注内容从哪来（按序，取到即止）

| 序 | 来源 | 做法 | 实例 |
|:--:|---|---|---|
| 1 | **直接读原图**（首选） | 用 `Read` 打开 `{题目目录}/images/` 下的图，一句话写「素材类型＋关键元素」 | 2026濮阳一模 第18题 → `（图：漫画，日本地图被缝成一体，一只手拿针线，"缝补"二字）` |
| 2 | **解析字段** | 题干无图注、但 `解析` 里有画面描述时据此提炼 | 解析与检测卷5 第25题 → `（图：改革与发展示意图，中心"改革·发展"，四方为中国戊戌变法等、日本明治维新、美国罗斯福新政、俄国彼得一世改革等）` |
| 3 | **题干上下文** | 题干能确认素材类型时可用，**但不得补造画面细节** | 「下图漫画体现了……」→ 可写「漫画」，不可编出画面内容 |
| 4 | **兜底显式标注** | 都取不到 → `（图：漫画，画面内容待核）` | 显式标注缺失，**绝不隐式留空**（违反「不隐式补全」） |

- ⚠ **优先读图，不靠猜**：题目 `解析` 常含画面描述，但那是作者视角的概括；读图能拿到解析没写的信息（如"缝补"二字）。两者冲突时以图为准。
- ⚠ **一题多图逐图写**：图上内容是并列关系时用「｜」分隔，不要把三张图写成一句笼统描述。

### 格式

| 情形 | 写法 |
|---|---|
| 单图 | `（图：处死查理一世）` |
| 多图并列 | `（图：碳化稻谷 ｜ 骨耜 ｜ 猪纹陶钵，均出土于河姆渡遗址）` |
| 带出土地/来源 | `（图：玉龙 ｜ 玉猪龙；内蒙古赛沁塔拉遗址　牛河梁遗址）` |
| 年代尺／示意图／表格图 | **写出结构**，如 `（图：年代尺，含世界事件 1991 年苏联解体、1993 年欧盟成立；中国事件 1978 年十一届三中全会、2001 年加入世界贸易组织）` |
| 表格化排版的多图题（§10.2.1） | 单元格内逐个写图注，**不得每格都填「（图）」** |

- **禁用的等价空表述**：「图略」「见原图」「（图片）」「（图见卷）」——与裸「（图）」同罪
- 引号统一中文弯引号

### 默认不嵌图（2026-10-23 定，含反例实测）

**报告一律只留图注、不嵌原图。** 三条路线都实测过：

| 路线 | Obsidian 内 | 导出 docx | 代价 |
|---|:---:|---|---|
| 复制到同级 `images/` + `![](images/xx.jpg)` | 能看 | 两条路径**都能带图** | 报告绑定资源目录，归档、改名、单篇发送都不便 |
| **直接引用原图相对路径** `![](../初中-3阶段测试/…/images/03_1.jpg)` | 能看 | **取决于运行目录**：`cd` 到 md 所在目录才成功（实测 1 张），在上级目录即使加 `--resource-path=.` 也报 `Could not fetch resource` | Pandoc 插件导出时 cwd 不受控 → **不可靠** |
| `![[03_1.jpg]]`（文件名全库搜） | 能看 | **必丢**（pandoc 不认 wikilink 图片语法） | 题库图片名 `18_1.jpg` 类跨卷重名极普遍 → 串图 |

- **看图的正道是点题目 wikilink 回题库**——报告里每题都挂了链，比嵌缩略图看得更清楚
- ⚠ **代价要认**：交付给没有 Obsidian 的人时，对方只有图注、看不到图。图像史料题、漫画题尤其吃亏——所以图注必须写足（见上面的四级取法），不能写成「（图）」两字了事
- ⚠ **确需带图交付时（家长会 PPT、纸质讲义）**：**临时**生成带图版，导出后即删，不进 vault 常驻。做法：复制原图到报告同级 `images/`、正文改 `![](images/文件名)`、按 `{卷别}_{题号}_{序号}` 重命名防串图（题库名跨卷重名极普遍）

### 题库图片的两种引用形态（写图注时取图用）

| 形态 | 样子 | 取图位置 |
|---|---|---|
| 标准 md | `![](images/18_1.jpg)` | 题目文件**同目录**下 `images/` |
| Obsidian embed | `![[Pasted image 20260924104359.png\|337]]` | 题目目录 `images/` 里同名文件（**不在 vault 根附件区**）；正则须排除 `\|` 转义 |

- ⚠ **正则要同时兼容两种**：只写 `!\[[^\]]*\]\(([^)]+)\)` 会**整体漏掉** embed 形态（实案：洛阳市2025-2026学年7上期末第25题的两张文物图）
- ⚠ **alt 默认为空**：题库图片引用不带 alt，这正是裸「（图）」的源头——图注信息只能从题干、解析或原图取

### 表格内多图（不嵌图，但要写对图注）

多图并列题在报告里常写成两行表格（图注行＋图名行）。**md 表格单元格不能放块级图片**（`md批量导出word` 会把 `![](...)` 当文本写进格子），所以表格内永远只写图注。

| 表格形态 | 图注怎么写 |
|---|---|
| **2 行（图注行＋分隔行，无图名）** | 逐格写；若读起来突兀可拆成非表格 `（图：A ｜ B）` |
| **≥3 行（含图名/说明行）** | 图注行逐格写，图名行照原文保留 |
| 单元格内 | 只写 `（图：…）`，**任何情况下不嵌图** |

- ⚠ **图名行本身就是最好的图注**：题干表格里的 `图1 利簋及铭文拓片`、`二里头夏都遗址博物馆` 这类文字是**原文照录**，优先于任何自行描述（即四级取法里「题干上下文」的实际形态）
- ⚠ **表格内链接要转义管道符**：`[[路径\|别名]]`——漏了 `\` 表格会被拆列（实案：`7上第2单元…` 的「漏标反查」行）

### 存量修复的验证清单

- `grep -c "（图）"` 须为 0（版权声明里若残留该字样，改写为「文字图注」）
- `grep -c "^!\["` 须为 0——不嵌图，报告内**不应有任何图片引用**；若此前嵌过，须连同 `3-Research-研究/images/` 一并撤除
- 图注数与题内图数对得上：多图题用「｜」并列写全，勿只写一张

## 7. 产出角度练习（报告定稿后联动）

依据报告「考察角度分类表」，产出**按角度分组的系列练习**——这是角度分析的落地物，让学生同角度真题成组、做完自能消化：

- **学生版**：每组前给「**角度提示卡**」（识别口诀 + 典型设问词 + 判断依据一句话）；组内真题按难度/年份排列；题面忠实原卷、出处用**纯发布式**（如「2023 年河南中考 第15题」「2024-2025 学年洛阳市9上期末 第1题」），禁自创简写（规范见 §6b）；只给题不给答案
- **教师版**：学生版全部内容 + 每题答案落点 + 角度归纳点评
- **落点**：`{vault}/3-Research-研究/角度练习-{维度对象名}/`，内含 `学生版.md` + `教师版.md`
- **docx 导出**：角度练习卷同样走 `export_student_paper.py`（组卷清单 → `--模式 学生/命题说明 --docx`，版式与字号由脚本按《试卷排版规范》对齐），命名 `角度练习-{对象名}-{学生版|命题说明}.docx`；**不要手写 python-docx 拼 docx**——它不解析 md 表格语法，管道符会原样进文档。⚠ 该脚本只认「md 同级 `images/` 目录下的文件名」，vault 内散落图片须先复制汇总到同级 `images/` 并把引用改为 `images/文件名`（重名自动改名防串图）
- ⚠ 练习是**报告的衍生品**：先有定稿角度分类表，再出练习；角度未定稿不出练习
- ⚠ docx 出到 3-Research-研究/ 或工作区交付，**不入 vault 题目录**（同组卷铁律）

## 铁律（分析专属）

1. **数据说话**：结论须由 `scan_lesson.py` 的统计支撑，不凭经验判断
2. **口径可复现**：样本说明须写清卷源（学年＋考区＋卷别）与「主考 N 题 / 兼涉 M 题」，兼涉题单独成节，不与主考混算
3. **漏标题单列**：`scan_missed.py` 命中的题在报告中单独列出，并说明归属判断（跨课 / 漏标）
4. **角度有据**：每个考察角度 ≥2 题支撑；单题不成角度
5. **专题定义可复现**：报告原样记录课名组/单元组/关键词组与命令行，他人按记录能重跑出同样数据
6. **角度计数三重回校**：定稿前核对三处的角度题量**完全一致**——**分角度详解各角度标题的题数 ｜ 考察角度速览表 ｜ 附表逐题标注的合计**，且各角度题数之和**必须等于主考题总数**。人工预分与附表实标常不一致（实测：正文按 ①20②5③5④15 写、附表实标为 ①19②6③4④16，差 4 处）；**一律以附表逐题标注为准回改正文与速览表**，改完再跑一次计数（统计附表「角度」列的行数分布与合计）确认无残留，然后才定稿。
7. **链接全覆盖**：报告正文（分角度详解正文题、分阶段分析①②题号、段末原文题）与附表，**凡出现的题号一律挂 wikilink**（规范见 §6c）；交付前跑 `check_note_links.py` 且扫裸题号确认无漏挂。
8. **原文自足**：分阶段分析 ①② 两段末都必须收齐本段提及的全部题原文（§6f）——报告定稿后应能**脱离题库独立交付**（导出 docx 发给他人时无需再附题）。缺题即不合格，不因篇幅删题。
9. **图注有效**：所有含图处必须写出画面内容，**禁裸「（图）」**（§6g）——图注空白的题对读者等于无题，尤其图像史料题、漫画题。

## 陷阱（分析专属）

1. **frontmatter 列表三种写法**：顶格 `- 值`、缩进 `  - 值`、内联 `[a, b]`——脚本统一走 `qb_schema`；若自己另写解析器必须同时兼容三种，否则严重漏题
2. **Windows 中文路径**：脚本一律用绝对路径调用，避免 MSYS 路径转换出错
3. **标注会滞后**：部分题「课」「单元」字段为空或只标主考课，务必跑 `scan_missed.py` 并在报告中单列
4. **课次漂移**：改版教材课次会变，比对课名而非课次；**多课聚合传完整课名**，裸课次「第1课」会跨册误中
5. **命中分布按位置计数**：与题数可差 1~2（一题多位置命中），报告统计说明口径
6. **分值口径**：50 分制与 100 分制卷不可混算占比（同流程五）
7. **练习导出勿入库**：docx 不进 vault 题目录
8. **出处表述须唯一可定位**：一律用**纯发布式** `{学年}{考区}{卷别} 第N题`，卷别写全、与题库目录名同形；**禁自创简写**。写完对照 scan 输出的卷名+题号集合全量校验无残留（不再要求内部 id 全称，但卷别不能省写）
9. **手写 python-docx 不解析 md 表格**：md 表格语法会以管道符原样进 docx——docx 一律走 md→docx 导出链路（`md批量导出word` skill），转换后用 python-docx 读回质检（表格数/图片数/管道符残留）
10. **真题引用必须逐字复制题目文件原文**：禁止从中间产物手抄或凭判断补写选项/答案——某次分课版 分析13 处选择引用缺选项、其中 6 处编造了「（A）……（示例方向）」，还有一处答案写错（漏掉《法典》）。
    - **根因不在工具**：`scan_lesson.py` 单课/单元模式输出的「题干」字段**完整含选项行**；问题出在写作环节——只摘抄设问句、遇缺选项便自行「补全」，属**隐式补全**（违反「缺失证据显式标注，不臆测填补」）。
    - **自造标注即违规信号**：报告里一旦出现「（示例方向）」「（备选文件含……）」这类字样，说明选项未取自原文，**必须回题目文件重取**；取不到就不写选项、显式标注缺失，绝不编造。
    - **交付前三项自动校验（缺一不可）**：① 引用块完整性——凡引用块含选项者必须同时出现 `(A)(B)(C)(D)`（材料/论述题除外）；② **答案一致性**——「✅ 答案」的字母须与题目文件 YAML 的 `答案` 字段逐一比对；③ **题干一致性**——与题目文件正文归一化后比对相似度（<0.93 人工复核；注意题库把**图注写在题干文本里**、报告按规范改为「（图：……）」占位，属正常差异，非改写）。
    - **改块时块边界 = 该块内的 `✅ 答案` 行**，**不可**用「下一个真题标题行」（即 `**【{类型}】[[…]]…**`，会吞掉块后的「**教学落点**」等正文）。改写后用 `diff --strip-trailing-cr` 复核（行尾符差异会让整文件全红，须忽略 CR），确认**被删行仅为旧选项行/旧答案行/旧题干行**，无正文段落丢失。
    - **标题行按实际来源写**：`**【{类型}】[[…|{学年}{考区}{卷别} 第N题]]（题型 · 分值）**`，类型＝库类别短名（中考真题／中考模拟题／阶段测试；高中为高考真题／高考模拟题／阶段测试）。**不用「真题 N」流水序号**（期末卷/模拟卷被标成「真题」属归类错误，序号各角度重编也非唯一）。详见 §6c。
    - **非选择题节选要有依据**：跨课/跨单元题按分析对象裁剪——**只留与本课/本单元有关的小问及其材料**，括注写明所涉小问与分值；设问照录、只删不改不加；**一题里找不到与对象相关的小问就不入正文**。详见 §6d。
11. **链接体检必跑**：报告**正文（分角度详解正文题、分阶段分析①②题号、段末原文题）与附表**逐题挂 wikilink（规范见 §6c），一旦**卷别归属目录或题型目录写错**即静默断链（Obsidian 不报错，同名文件多时还会模糊匹配到**另一道无关题**，看着能点实为指错）。另：题目被「一题多卷」**合并归档**后，早先引用它的链接同样静默失效——合并后须跑一次体检改指主卷（`references/fields.md`「合并对笔记引用的影响」）。
    - **表格内须转义管道符**：**表格单元格内**写 `[[路径|别名]]` 会被表格当作列分隔符吃掉——链接**失效**，页面直接显示原始 `[[...]]` 文本且不可点击；必须写成 `[[路径\|别名]]`。**正文段落内不转义**。⚠ 路径与 `\|` 之间不得留对齐填充空白（会把空格算进路径尾部）。
    - **交付前必跑**：`python scripts/check_note_links.py --file "3-Research-研究/<报告>.md"`（权威工具，内部按题目 id 索引反查，能识别归档区引用与模糊误指；退出码 1 = 仍有断链）。
    - **正文题号裸写自查**：分角度详解、分阶段分析①② 凡出现 `第 N 题` 或「{卷别} 第N题」却无同行 wikilink 的，即漏挂——交付前用 grep 扫 `第 ?[0-9]+ ?题` 的行，逐行确认是否已带 `[[`。
    - **写链接时先核实**：卷别目录归属（中考真题/中考模拟题/阶段测试三类）与题型子目录（选择题/材料解析题/论述题/综合探究题/填空题）**一律以 `ls` 实查为准**，不凭卷名推测。
    - **断链自检的正判据（不可用只覆盖表格的正则）**：只匹配 `\|` 的正则**只覆盖表格内的链接，会整体漏掉正文链接**。正确做法是**两类写法分别处理**：表格内取 `inner.split('\\|',1)[0]`、正文取 `inner.split('|',1)[0]`，再逐条判存在；且**表格行的判据是 `line.lstrip().startswith('|')`**。自查脚本若只做「路径存在性」判断，同样须先 `t.replace('\\|','|')` 剥离表格转义，否则会把**全部**表格内链接误报为断链。
    - **验证方法**：`obsidian links path="…"` 数**解析出的 `.md` 目标条目数**——只数源码里的 `[[` 出现次数会把失效链接一并算进去。

12. **Dataview DQL 语法**（报告与练习里写 DQL 时）：**无 `CONTAINS` 操作符**；检索一律 `contains(字段, "值")` 函数语法；字符串字面量**只认双引号**——操作符写法或单引号参数必 PARSING FAILED；词表课名里的中文引号（“”）无害，勿误删。
