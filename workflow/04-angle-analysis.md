# 流程四 · 多维度考查方向分析（课 / 单元 / 专题）

> **触发词**：分析某课/某单元考查方向、某课考什么、某单元考什么、归纳 X 课/单元考点、结合题库看重点、某课在中考/期末怎么考、这课/这单元的命题规律、专题分析（跨单元主题，如「区域文明的多元发展」「中央集权的演变」）、按考察角度出练习、角度分类练习。
>
> **前置检查**：运行前确认已初始化（`<skill>/scripts/skill_config.json` 含有效 vault 或 `TNOTE_VAULT` 已设）；**未配置 → 先读 `workflow/00-init.md`**。

从题库按「课 / 单元 / 专题」取题 → 统计分布 → 按**考察角度**归纳 → 产出教师用报告 → （可选）产出按角度分组的系列练习。

**产物定位：报告即发布稿，内部与发布合一。** 落库报告同时是对外可发布的稿子（公众号/网页/文档），故按**发布化规范**撰写（见第 6 节后「发布化规范」）：正文用教师语言、表格窄化、出处用**纯发布式表述**、不出现内部路径与 id。题库搭建者本人可据「学年+考区+卷别+题号」直接回库对应（卷别与题库目录名同形）。

**方法论来源**（2026-09-19 吸收闫亚宁「角度分类法」，源自闫亚宁老师公众号「历史实战方法课堂」《高考题应该这样分类》一文）：把真题按**考察角度**归类，而非仅按知识点罗列——让学生快速看到"同一考点命题人是如何切入考察的"；每角度配典型设问词与判断依据；同角度真题成组，做完自能消化。

**与流程五的分工**：本流程管「**怎么考**」（课=微观命题角度；单元=中观结构；专题=跨单元聚焦）；流程五管「**一册考什么**」（宏观、范围与取舍）。

## 0. 维度选择（先定维度，再取题）

| 维度 | 粒度 | 适用场景 | 取题依据 | 报告落点名 |
|---|---|---|---|---|
| 课 | 微观 | 一课怎么考、单课命题规律 | 「课」字段 | `{册别}第N课{课名}` |
| 单元 | 中观 | 一单元怎么考、单元内各课侧重、跨课综合题占比 | 「单元」字段 | `{册别}第N单元{单元名}` |
| 专题（跨单元） | 宏观聚焦 | 围绕主题跨单元跨册聚合（如「区域文明的多元发展」＝9上第1—6课＋纲要下第1—2课） | 专题定义（课名组，可选单元组） | `专题-{专题名}` |

- 三维度数据口径同源：主考 / 兼涉 / 全涉（`scan_lesson.py` 对单元与多课组同样适用）
- 不确定选哪个：问「分析结果给谁用」——讲一节课用课维度；整单元复习/期中备考用单元维度；专题复习课、跨册知识整合、命题研究用专题维度

## 1. 确认对象名（必须能命中题库对应字段）

- **课维度**：课名以 BOOK_INDEX 为准，形如 `第5课 古代希腊`；用户给简称（如「古代希腊」）时先补全为词表课名。⚠ **课次漂移**：教材改版后同一内容课次会变 → **课名比对优先于课次比对**
- **单元维度**：单元名以 BOOK_INDEX 单元名行为准（如 `第2单元 古代欧洲文明`）；⚠ 单元名不得带注记
- **专题维度**：先写**专题定义**（报告第 1 节必须原样记录，保证可复现）：
  
  1. **课名组**：跨单元/跨册的**完整课名**列表（逗号分隔传给 `--lesson`）
  2. **可选单元组**：以整单元为范围时用 `--单元` 补充
  3. **特征关键词组**：留给第 3 步漏标反查用，不进取题主口径
  - ⚠ **跨册同名课次**：必须传完整课名——裸课次「第1课」会误中他册同课次课（9上第1课 ≠ 纲要下第1课）；子串匹配按完整课名隔离

## 2. 取题（三口径，`scan_lesson.py`）

```bash
python scripts/scan_lesson.py --lesson "第5课 古代希腊"                    # 单课·全涉（默认，防漏题）
python scripts/scan_lesson.py --lesson "第5课 古代希腊" --口径 主考        # 该课被直接考查（命题落点）
python scripts/scan_lesson.py --lesson "第5课 古代希腊" --口径 兼涉        # 该课只作背景/参照/结论被调用
python scripts/scan_lesson.py --lesson "第5课 古代希腊" --body            # 附题干全文
python scripts/scan_lesson.py --单元 "古代欧洲文明"                        # 单元维度
python scripts/scan_lesson.py --lesson "第2课 古代两河流域,第3课 古代埃及,第4课 古代印度,第5课 古代希腊,第6课 古代罗马"   # 专题维度（多课聚合）
python scripts/scan_lesson.py --单元 "史前时期" --卷 "洛阳市2024-2025学年7上期末,洛阳市2025-2026学年7上期末"   # 限定卷范围（逗号多值子串匹配卷目录名；范围收窄器，不改变口径逻辑）
```

**分阶段取数（报告第 5 节用）**：

```bash
python scripts/scan_lesson.py --单元 "史前时期"                                    # 全库取题（含中考）→ 按 id 带「中考」筛出中考坐标
python scripts/scan_lesson.py --单元 "史前时期" --卷 "2024河南中考,2025河南中考,2026河南中考"        # 上位坐标：河南中考近年
python scripts/scan_lesson.py --单元 "史前时期" --卷 "郑州市二七区2024-2025学年7上期末,郑州市经开区2024-2025学年7上期末"   # 同层对照：外地阶段测试卷
```

- 三层关系：**本卷（阶段测试）→ 同层（外地同期卷）→ 上位（中考真题）**；对照维度＝角度分布、典型设问词、能力层次、难度
- ⚠ **分值口径不可混算**：河南中考卷为 50 分制、地市期末多为 100 分制（见 `references/分析基线-洛阳.md`），跨类只比题型与考点，不比分值权重

**报告口径**：主体用 **主考**（这是对象真正被考的部分）；**兼涉单列一节**——说明对象被当参照系/背景板的频次与方式。

**多课/单元模式自动输出三段分布**（单课模式不输出，行为向后兼容）：

| 段 | 内容 | 用法 |
|---|---|---|
| 【主考落点】 | 各课/单元作为首项的题数 | 单元内各课侧重、专题内各考点权重 |
| 【兼涉调用】 | 各课/单元在第 2 项起被调用的次数 | 哪些课常当背景板 |
| 【册别分布】 | 命中题按册别首项计数 | 专题跨册结构一目了然 |

- ⚠ **命中分布按位置计数、题数按题计数**：一题多处命中（如课列表两个位置都命中目标组）时，分布合计可大于题数 1~2，属正常统计口径差异，明细里人工核对即可
- `--lesson` 与 `--单元` 可同给（并集口径），但一般只用其一，混用会让报告口径难写清

## 3. 漏标与关联题排查（必做，专题维度尤其重要）

```bash
python scripts/scan_missed.py "第5课 古代埃及" "金字塔|法老|尼罗河|象形文字"
python scripts/scan_missed.py "第5课 古代希腊" "雅典|城邦|民主" --口径 主考   # 专查「只当背景标过、正文却在讲它」
```

- ⚠ **首参是「课名」，不是单元名／专题名**：工具按「课」字段匹配，传单元名（如「第2单元 夏商周时期」）会把全库所有正文命中关键词的题一律报出，等于没筛。**单元维度**须**逐课分别反查**（单元内每课各跑一次，再合并结果、去掉重复）；**专题维度**的课名组同样逐课跑，另叠加下方的特征关键词反查
- 命中题**逐条判断**：属**跨课综合**（材料涉及它、落点在别处）还是**漏标**（该补进该题「课」字段）
- **专题维度**：用专题特征关键词反查（如「区域文明的多元发展」用 `金字塔|汉谟拉比|种姓制度|佛教|城邦|民主政治|亚历山大|罗马法|楔形文字|象形文字`），能捞到「正文讲文明但课字段只标了别处」的漏网题
- ⚠ 两个检查别混：本工具查**正文内容**漏标；`scan_questions.py` 的 `ℹ 定位字段提示` 查**单元/册别漏写**

## 4. 读关键材料题正文

材料解析题首行常是「阅读材料，完成下列要求。」，看不出考点，须提全文：

```bash
awk 'BEGIN{c=0} /^---$/{c++; if(c==2) print "--BODY--"; next} c>=2' "<题文件路径>" | head -40
```

## 5. 归纳考察角度（本流程核心）

按**考察角度**聚类，不只按知识点。一个「考察角度」= **三件套**：

| 件 | 内容 | 示例（考点：雅典民主） |
|---|---|---|
| **切入视角** | 命题人从哪个角度切进考点 | 从「地理环境制约政体」切入 / 从「公民范围局限」切入 / 从「文化影响」切入 |
| **典型设问词** | 该角度高频设问词及其作答逻辑 | 选择题：反映/体现/说明/表明/旨在/意在/据此可知/强调/折射；非选择题：概括/分析/简述/比较/评述（各设问词决定答案组织方式） |
| **判断依据** | 学生识别该角度的一句话依据 | 设问指向「多元性」→ 找各文明**差异**而非共性；设问「折射」→ 由现象推背后制度/观念 |

- **概念辨析**：角度涉及易混概念时单独标出（如「宗法制 vs 宗法观念」「城邦 vs 帝国」）——高频概念要细化到「什么情境选它」
- 每角度给：题量 / 占比 / 主力题型 / 年份考区分布 / 难度
- 角度数量：3—6 个为宜；题量少的对象（<20 题）2—3 个即可
- ⚠ **角度有据**：每个角度须有 ≥2 题支撑；单题不成角度（并入相近角度或归「其他」）

## 6. 产出报告（9 节，固定；发布稿形态）

**落点**：

| 维度 | 路径 |
|---|---|
| 课 | `{vault}/3-试题研究/{册别}第N课{课名}-考查方向分析.md` |
| 单元 | `{vault}/3-试题研究/{册别}第N单元{单元名}-考查方向分析.md` |
| 专题 | `{vault}/3-试题研究/专题-{专题名}-考查方向分析.md` |

- ⚠ 命名**紧凑无空格**（`9上第5单元走向近代-考查方向分析.md`）、**不带日期前缀**（日期进 `撰写日期` 属性）
- **报告笔记属性（必填）**：按 `references/fields.md`「试题研究笔记属性」**B 档**填写 frontmatter——`类型: 考查方向分析`、`维度`（课/单元/专题）、`对象`（与文件名主干一致）、`学段`、`册别`、`覆盖卷别`、`课`（可选）、`难度`、`核心素养`、`关键能力`、`主题`、`核心结论`、`撰写日期`；`关联题目` 在涉题 ≤10 道时填，否则留空。模板 `{vault}/0-Template-模板/试题报告笔记.md`
- ⚠ 落库前自查：frontmatter 齐备（缺则 Dataview 检索不到）；旧报告若缺属性须补齐

报告结构（9 节，固定）：

1. **开篇速览**：3~5 行结论 + 关键数字（单元卷面权重区间、角度数、最稳考点、命题总特征）——让读者三行内建立预期
2. **样本说明**：卷源（学年＋考区＋卷别）、题量、统计口径一句话；**专题维度须原样记录专题定义**（保证可复现）；详细统计不进正文
3. **考察角度速览表**：角度 / 题量·占比 / 主力题型 / 命题重心（≤4 列）
4. **分角度详解**（本篇主体）：每角度＝怎么考（切入视角）＋典型设问词＋识别口诀（判断依据）＋**精选真题**（题干＋答案落点＋一句点拨）＋概念辨析＋教学落点；兼涉题单独成节
5. **分阶段分析**：① 课堂教学同步——作业练习、阶段测试（单元测试/月考/期中/期末等）怎么考；② 上位——河南中考＋各地中考怎么考；对照维度＝角度分布/典型设问词/能力层次/难度；节末给「**阶段教学重点 vs 中考备考**」建议。**本节凡写出具体题号必挂链接**（规范见 §6c）
6. **能力与素养画像**：关键能力、核心素养、素养层次、难度、年份、考区分布；单元维度加课次热度表；**术语转译为教师语言**（如「以提炼归纳为主、开始考因果推断」），受控术语必要时括注
7. **教学与备考建议**（约 5 条，可操作）
8. **学生版学习要点**（可直接抄给学生：必背清单＋易错警示）
9. **附：题目清单**（未入选第 4 节的题目：题号/题型/年份考区/角度/考点/难度/能力；**出处列逐题挂 wikilink**）

⚠ **真题入正文的选取原则**：每角度 2~3 道，含图/含材料者优先，难度覆盖易—中；其余入第 9 节附表。**完整性由附表兜底，正文不求「全」只求「看懂怎么考」**。

## 6b. 发布化规范（报告与练习通用）

报告即发布稿，以下要点**默认执行**：

| 项 | 要求 |
|---|---|
| 出处表述 | **纯发布式**：`{学年}{考区}{卷别} 第N题`（如「2025-2026 学年洛阳市7上期末 第1题」），卷别与题库目录名同形；**禁自创简写**（「2026河南-09」这类既像中考又实为期末的写法禁用） |
| 内部信息 | **不出现**题库 id、库内路径、设备/环境信息、学生信息 |
| 术语 | 正文用教师语言（「以提炼归纳为主」「开始考因果推断」）；`A3-概括`/`层次2` 等受控术语仅在必要处括注 |
| 表格 | ≤4 列优先；4 列以上改分条列点或出图；超 10 行的宽表不进正文（入附表） |
| **真题引用** | **选择题：题干＋四个选项完整照录**——材料不压缩改写、表格按原形态、选项一个不缺（**禁「……」截断**）；**非选择题：可节选**（材料可摘取、设问保留主体并标注「节选」）。**答案与选项文字一律照录题库字段，禁凭判断书写**（2026-09-20 实测教训：良渚水利题官方答案 C「环境适应与改造能力」，曾凭常识误写为 A「经济发展水平」，连带教学结论出错） |
| **图片处理** | 以**图注占位**呈现，如「（图：碳化稻谷 ｜ 骨耜 ｜ 猪纹陶钵）」，**不嵌库内相对路径**（报告在 `3-试题研究/`、图在题目目录，相对路径必断链）；发布时按图注上传实际图片。引文中的引号统一中文弯引号 |
| 配图 | 建议出 1 张信息图（角度占比＋分值权重／三年对比），便于保存转发 |
| 本地性 | 主动挖掘本地元素（本地考古发现、本地史事入题的卷面证据）——对外发布的差异化价值点 |
| 篇幅 | **不设字数限制**——以「把该对象的命题角度讲透」为准，篇幅服从内容，**不因凑字数删减真题与角度细节**——发布时按平台拆「**分析篇＋练习篇**」两篇：分析篇＝开篇/样本/角度速览/能力画像/建议，练习篇＝分角度真题（含题干）＋学生版要点＋附表 |
| 合规 | 真题注明来源与年份、不整卷搬运、图片注明出处（教材/考古报告）、不标原创声明 |

## 6c. 题目回溯链接规范（报告正文与附表）

**原则：报告里出现的每一道题，都要能一键回溯原题。** 链接用 Obsidian wikilink，别名统一用**纯发布式出处**（与 §6b 出处表述同形），使读者读到的文字与链接语义一致。

**三处必挂链接**（缺一即不合格）：

| 位置 | 挂法 | 说明 |
|---|---|---|
| **第 4 节 · 正文真题** | 每道入选真题的标题行整体做链接：`**【真题 N】[[卷别路径/题号\|{学年}{考区}{卷别} 第N题]]（题型 · 分值）**` | 正文选入的真题（2~3 道/角度）**逐道必挂**，不留裸题号 |
| **第 5 节 · 两参照层** | 正文与表格中**每一处提及的题号**就地挂链接（别名「{卷别} 第N题」） | ① 课堂教学同步（各市一模/同期卷）＋ ② 上位中考（河南中考）内出现的题号**全部挂链**，不写裸题号 |
| **第 9 节 · 附表** | 逐题挂 wikilink（出处列） | 已由陷阱 11 覆盖，本规范重申为其上位要求 |

- ⚠ **第 5 节挂链注意**：该节多为「洛阳卷 第 10—13 题」这类**区间表述**——区间无法逐题挂链时，拆为单题链接（如 `第 10—13 题` → `[[…10|…第10题]]、[[…11|…第11题]]…`）；确属概括性一笔带过（如「共 3—4 题」的总量描述）可不挂，但**凡写出具体题号即挂链**
- ⚠ **同一题在正文多处出现**：每处都挂（Obsidian 允许同链接多次出现），保证任何一处都能回溯，不做「首见挂链、后文裸写」

**正文「引用原题」的判断（按重要性三档，非一刀切）**——链接是「回得去」，引用是「看得见原文」，两者独立：

| 档 | 何时引用（贴出题干） | 典型场景 |
|---|---|---|
| **必引** | 附表有此题、但正文此前无对应落点（**补缺**）；史事/素材/情境需**细化说明**才能讲清角度（如材料题的多则材料、图像题的画面内容） | 兼涉转主考的关键题、需展示材料细节的例证 |
| **可引** | 同角度支撑题、设问词典型题、答案分寸需展示「怎么错」的题 | 与正文真题同角度、可并列比较者 |
| **不引** | 与正文真题同质、仅作批量罗列者 | 留给附表兜底即可（正文不求全，见 §6「真题入正文选取原则」） |

- 引用格式与 §6b「真题引用」一致：**选择题题干＋四选项完整照录；非选择题可节选并标注「节选」**；答案照录题库字段
- 判断口诀：**「读者读到这里，会不会想看到原题？」** 会 → 引；只想确认「有这回事」→ 只挂链

**真题正文的书写形态（2026-10-02 定，原为引用块，已全库改造）**：

真题标题行（`**【真题 N】…**`）下方的题干／材料／选项**一律写成普通段落，不加 `>` 引用符**：

```
**【真题 1】[[…|洛阳市2025-2026学年7上期末 第1题]]（选择 · 2 分）**
下面是我国境内的部分古人类情况，由此可知（　　）
                ← 此处必须有空行（md 表格硬约束）
| 古人类 | 时间 | 地点 | 考古发掘成果 |
| --- | --- | --- | --- |
| 元谋人 | 距今约170万年 | 云南元谋 | 两颗门齿化石、一些粗糙的石器 |
(A) 我国有百万年的人类史　(B) 各地均有了丰富的考古发现　(C) 古人类开始了定居生活　(D) 古人类已掌握农业生产技术
✅ 答案 **A**

**【真题 2】…
```

**为什么不用引用块**：① 标题行已用加粗给出出处，引用块纯属冗余；② Obsidian **不支持在引用块内渲染表格**（Live Preview 与阅读模式都塌成文字），迫使表格写 HTML，而 HTML `<table>` 单元格内**不能再放 wikilink 与图片**——去掉引用符后限制解除，表格回归 md 语法、单元格可正常嵌链嵌图。

**段落间距规范（2026-10-02 定）**——真题块要**紧凑成一体**，逐题之间才留白：

| 位置 | 间距 | 说明 |
|---|---|---|
| 标题行 → 题干 | **不加空行** | 标题与内容紧连，整题为一体 |
| 题干 → 图片占位 → 选项／小问 → 答案／点拨 | **不加空行** | 同属一题，紧密相连 |
| **表格前** | **1 空行（强制保留）** | md 表格必须空行隔断，删了就塌（见 `workflow/01` 陷阱 21） |
| 答案点拨 → 下一题标题行 | **1 空行** | 真题与真题之间留白 |
| 真题块 → 块外正文（`**点拨**`／`**教学落点**`／章节标题） | 保持原间距 | 块外不压缩 |

- 一键改造：`python scripts/fix_item_spacing.py --dir "3-试题研究" [--apply]`（默认 dry-run，`--scan` 先勘察，逐文件备份 `.bak-space`）；脚本自动保护表格前空行
- 交付前自查：① `**【真题…】` 标题行的下一行**必须直接是题干**（不得为空行）；② 各 md 表格首行前一行**必须**是空行；③ 块内非空行不得因压缩而变动（脚本保证）

| 保留引用块的场景 | 说明 |
|---|---|
| 文档扉页元信息块（`> 数据来源：… 试题来源：… 分析日期：…`） | 与真题无关，属卷首说明 |
| 「原文示例／范文」类引文块（如小论文母题的例文） | 是引文而非真题照录 |

- ⚠ **形态有两种**，改造与自查都要覆盖：① 标题在引用块**外**（`**【真题 N】…**` + 空行 + `> 题干`，绝大多数）；② 来源标题在引用块**内**（`> **【[[…]]（节选）】**`，河南中考与《解析与检测》两份设问类型报告专用）
- 一键改造：`python scripts/fix_quote_to_plain.py --dir "3-试题研究" [--apply]`（默认 dry-run，逐文件备份 `.bak-unquote`）
- 交付前自查：`3-试题研究/` 内 `**【真题…】`／`**【补充】` 标题行的下一非空行**不得**以 `>` 开头

## 7. 产出角度练习（报告定稿后联动）

依据报告「考察角度分类表」，产出**按角度分组的系列练习**——这是角度分析的落地物，让学生同角度真题成组、做完自能消化：

- **学生版**：每组前给「**角度提示卡**」（识别口诀 + 典型设问词 + 判断依据一句话）；组内真题按难度/年份排列；题面忠实原卷、出处用**纯发布式**（如「2023 年河南中考 第15题」「2024-2025 学年洛阳市9上期末 第1题」），禁自创简写（规范见 §6b）；只给题不给答案
- **教师版**：学生版全部内容 + 每题答案落点 + 角度归纳点评
- **落点**：`{vault}/3-试题研究/角度练习-{维度对象名}/`，内含 `学生版.md` + `教师版.md`
- **docx 导出**：角度练习卷同样走 `export_student_paper.py`（组卷清单 → `--模式 学生/命题说明 --docx`，版式与字号由脚本按《试卷排版规范》对齐），命名 `角度练习-{对象名}-{学生版|命题说明}.docx`；**不要手写 python-docx 拼 docx**——它不解析 md 表格语法，管道符会原样进文档。⚠ 该脚本只认「md 同级 `images/` 目录下的文件名」，vault 内散落图片须先复制汇总到同级 `images/` 并把引用改为 `images/文件名`（重名自动改名防串图）
- ⚠ 练习是**报告的衍生品**：先有定稿角度分类表，再出练习；角度未定稿不出练习
- ⚠ docx 出到 3-试题研究/ 或工作区交付，**不入 vault 题目录**（同组卷铁律）

## 铁律（分析专属）

1. **数据说话**：结论须由 `scan_lesson.py` 的统计支撑，不凭经验判断
2. **口径可复现**：样本说明须写清卷源（学年＋考区＋卷别）与「主考 N 题 / 兼涉 M 题」，兼涉题单独成节，不与主考混算
3. **漏标题单列**：`scan_missed.py` 命中的题在报告中单独列出，并说明归属判断（跨课 / 漏标）
4. **角度有据**：每个考察角度 ≥2 题支撑；单题不成角度
5. **专题定义可复现**：报告原样记录课名组/单元组/关键词组与命令行，他人按记录能重跑出同样数据
6. **角度计数三重回校**：定稿前核对三处的角度题量**完全一致**——**第 4 节各角度标题的题数 ｜ 第 3 节速览表 ｜ 第 9 节附表逐题标注的合计**，且各角度题数之和**必须等于主考题总数**。人工预分与附表实标常不一致（实测：正文按 ①20②5③5④15 写、附表实标为 ①19②6③4④16，差 4 处）；**一律以附表逐题标注为准回改正文与速览表**，改完再跑一次计数（统计附表「角度」列的行数分布与合计）确认无残留，然后才定稿。
7. **链接全覆盖**：报告正文（第 4 节真题、第 5 节两参照层题号）与第 9 节附表，**凡出现的题号一律挂 wikilink**（规范见 §6c）；交付前跑 `check_note_links.py` 且扫裸题号确认无漏挂。

## 陷阱（分析专属）

1. **frontmatter 列表三种写法**：顶格 `- 值`、缩进 `  - 值`、内联 `[a, b]`——脚本统一走 `qb_schema`；若自己另写解析器必须同时兼容三种，否则严重漏题
2. **Windows 中文路径**：脚本一律用绝对路径调用，避免 MSYS 路径转换出错
3. **标注会滞后**：部分题「课」「单元」字段为空或只标主考课，务必跑 `scan_missed.py` 并在报告中单列
4. **课次漂移**：改版教材课次会变，比对课名而非课次；**多课聚合传完整课名**，裸课次「第1课」会跨册误中
5. **命中分布按位置计数**：与题数可差 1~2（一题多位置命中），报告统计说明口径
6. **分值口径**：50 分制与 100 分制卷不可混算占比（同流程五）
7. **练习导出勿入库**：docx 不进 vault 题目录
8. **出处表述须唯一可定位**：一律用**纯发布式** `{学年}{考区}{卷别} 第N题`，卷别写全、与题库目录名同形；**禁自创简写**。写完对照 scan 输出的卷名+题号集合全量校验无残留（不再要求内部 id 全称，但卷别不能省写）
9. **手写 python-docx 不解析 md 表格**：md 表格语法会以管道符原样进 docx——docx 一律走 md→docx 导出链路（`md批量导出word` skill），转换后用 python-docx 读回质检（表格数/图片数/管道符残留）
10. **真题引用必须逐字复制题目文件原文**：禁止从中间产物手抄或凭判断补写选项/答案——某次分课版 分析13 处选择引用缺选项、其中 6 处编造了「（A）……（示例方向）」，还有一处答案写错（漏掉《法典》）。**交付前三项自动校验**：引用块含 `(A)(B)(C)(D)` ｜ 「✅ 答案」字母与 YAML `答案` 字段一致 ｜ 题干与原文归一化比对。细则与改块边界（**= 该块内的 `✅ 答案` 行**，不可用「下一个 `**【真题` 行」，否则吞掉块后正文）见根目录 SKILL.md 全局陷阱 8。
11. **链接体检必跑**：报告**正文（第 4 节真题、第 5 节两参照层）与附表**逐题挂 wikilink（规范见 §6c），一旦**卷别归属目录或题型目录写错**即静默断链（Obsidian 不报错，同名文件多时还会模糊匹配到**另一道无关题**，看着能点实为指错）。
    - **交付前必跑**：`python scripts/check_note_links.py --file "3-试题研究/<报告>.md"`（权威工具，内部按题目 id 索引反查，能识别归档区引用与模糊误指；退出码 1 = 仍有断链）。
    - **正文题号裸写自查**：第 4、5 节凡出现 `第 N 题` 或「{卷别} 第N题」却无同行 wikilink 的，即漏挂——交付前用 grep 扫 `第 ?[0-9]+ ?题` 的行，逐行确认是否已带 `[[`。
    - **写链接时先核实**：卷别目录归属（中考真题/中考模拟题/阶段测试三类）与题型子目录（选择题/材料解析题/论述题/小论文/综合探究题）**一律以 `ls` 实查为准**，不凭卷名推测；表格内链接管道符务必转义 `\|`。
    - ⚠ 自查脚本若只做「路径存在性」判断，须先 `t.replace('\\|','|')` 剥离表格转义，否则会把**全部**表格内链接误报为断链。
