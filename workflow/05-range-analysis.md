# 流程五 · 册别/学段考试范围分析

> **触发词**：某册期末考什么、考试范围分析、哪些课是重点、复习优先级、学困生/差生怎么提分、时间不够先放弃哪些。
>
> **前置检查**：同流程四（vault 配置见 `workflow/00-init.md`）。
>
> **与流程四的分工**：本流程管「**一册/一学段考什么、怎么取舍**」（宏观）；流程四管「一课怎么考」（微观）。两者数据口径均建立在「主考 / 兼涉」之上。

## 0. 前置：样本选择与口径确认

- **样本优先级**：同考区同册历年卷 > 同考区相近学年 > 外地卷（外地卷仅作题型考点参考，**分值权重不可比**）
- ⚠ **满分口径**：同区不同学校期末卷满分可能是 50 或 100（南阳卷、河南省实验中学卷 = 50 分制）→ 跨卷累计前必须确认，否则梯队划分失真

## 1. 拉取统计

```bash
python scripts/scan_volume.py --册 9上                                    # 该册全部题（跨卷累计）
python scripts/scan_volume.py --册 9上 --卷 "洛阳市2025-2026学年9上期末"     # 定位单卷
python scripts/scan_volume.py --册 9上 --json                             # 机器可读
```

输出五段：

| 段 | 内容 | 用法 |
|---|---|---|
| 【0】**范围判定** | 同卷中属**其他册别**的题（题号 + 册别 + 分值） | 回答「考 9上 到底考到哪儿」——洛阳9上期末实测全卷 25 题有 5 题（选择 16-20，10 分）属 9下 |
| 【1】卷面结构 | 卷 × 题型：题量 / 分值 | 判断题型配比与论述题是否单列 |
| 【2】难度分布 | 易/中/难 的题量与分值占比 | 估算「读懂材料即可作答」的分值比例 |
| 【3】**课次热度 + 三梯队** | **主考计满分、兼涉单独计数**，按主考分值累计 80% / 95% 切三梯队 | 复习优先级与止损清单 |
| 【4】【5】 | 关键能力/素养分布 + 非选择题知识点清单 | 能力画像与材料题主线归纳 |

- **热度口径**：**主考计满分、兼涉单独计数**——不跨课均摊（均摊会把「只作背景」的课抬成重点）
- **未命中课 ≠ 不重要**：须注明是「样本未涉及」还是「教材版本差异导致课次错位」
- ⚠ **一题多卷归档的影响**：某卷若有题被合并归档（`{vault}/.trash/`，库内回收站），按卷统计的题量与分值会偏小 → 与卷目录下 `_重复题清单.md` 核对补齐

## 2. 材料题主线归纳（人工）

逐题读非选择题知识点（【5】段已列出题号 + 知识点 + 题干首行），归纳 5—8 条命题主线。

## 3. 输出规范（六节）

1. **结论先行**（表格：结论 + 关键证据）
2. **学习任务与路径**（任务量测算、进度表、要讲给学生的真相）
3. **考试范围实证分析**（卷面结构、课次热度三梯队表、材料题主线表、特殊课次说明）
4. **教学取舍**（若用户提供了课件：逐页盘点 + 增删建议）
5. **学困生提分方案**（提分杠杆表 + 可执行路径 + 一学期节奏）
6. **待确认事项**（表格）

**落点**：`{vault}/3-Research-研究/卷-考情分析/{范围}-考情分析.md`（如 `卷-考情分析/洛阳7年级期末-考情分析.md`）——命名紧凑无空格、**不带日期前缀**（日期进 `撰写日期` 属性）

**报告笔记属性（必填）**：按 `references/fields.md`「试题研究笔记属性」**B 档**填写 frontmatter——`类型: 考情分析`、`维度`（`册别` 或 `考情`）、`对象`（与文件名主干一致）、`学段`、`册别`、`覆盖卷别`、`难度`、`核心素养`、`关键能力`、`主题`、`核心结论`、`撰写日期`。模板 `{vault}/0-Template-模板/试题报告笔记.md`

## 4. 学困生提分方案的标准结构

**提分杠杆表**（按性价比排序：板块 / 卷面分值 / 现状得分 / 训练后目标 / 周期 / 星级）：

1. 选择题——史实辨识 + 排除法，性价比最高
2. 材料题「据材料指出/概括」问——**答案就在材料里，4 周见效，提分最快**
3. 小论文三段式模板——等级评分下二等（4-7 分）可达
4. 材料题「分析/说明」问——需史实积累，放最后，允许只拿一半分
5. 冷门课内容——明确止损

**四条可执行路径**：

- **只认「脸」不背书**：每课 3—5 个关键词做卡片（「看到能认出」即可，不要求背诵）
- **一根时间轴**：全册只标 10—15 个点，只记先后不记精确年份
- **材料题三圈法**：圈设问动词 → 圈材料关键句 → 圈分值（几分答几点）；设问动词决定答题动作（指出＝抄原句 / 概括＝删修饰 / 分析＝材料句＋课本一句 / 认识＝套话）
- **小论文填空法**：题目 + 观点（判断句）+ 两个史实（时间+人物+事件）+ 结论升华，80—120 字

**核心诊断原则**：关键的不是「学生不会概括」，而是「**没有史实可概括**」。**先给最小必要史实，再给机械答题技术，顺序不可颠倒。**

## 5. 证据诚实（三条硬要求）

1. **版本差异**：样本卷若使用旧教材，必须注明「课次为事后按新教材重标，热度反映内容权重，课次序号以新教材为准」
2. **零命中课次**：新增课次零命中要说明是**数据缺失**而非不重要
3. **分值口径不同的卷**：只作题型考点参考，不可作分值权重参考

## 陷阱（范围分析专属）

1. **分值口径不同**：50 分制与 100 分制混算 → 梯队失真
2. **课次序号漂移**：教材改版后同一内容课次会变，**课名比对优先于课次比对**
3. **空字段干扰**：部分题「课」「册别」未标注，统计时会混入空串（脚本已显式过滤）
4. **`images/` 子目录**：遍历时若不限定 `.md` 后缀会对目录调用 `open`，触发 PermissionError
5. **不要手写解析脚本**：一律用 `qb_schema`（`split_frontmatter`）＋ `scan_volume.py`——手写解析器易踩 `re.MULTILINE + \s*` 让 `\s` 匹配换行、字段值溢出吞掉下一行等坑
6. **教材改版后的新单元名**：BOOK_INDEX 中单元名行**不得带注记**（如「（完全重写）」），否则与题库比对全军覆没；改版信息写在 `references/book_index.md` 的说明段，不写进单元名本身
