# 流程二 · 组卷/出题

> **触发词**：出题、组卷、出一套卷子、某个范围/某个知识点（用户说「某个范围/某个知识点」→ 检索，**不是还原原卷**）。
>
> **前置检查**：运行前确认已初始化——`<skill>/scripts/skill_config.json` 含有效 vault 或 `TNOTE_VAULT` 已设；**若脚本报「未配置题库库」→ 先读 `workflow/00-init.md`** 完成配置再继续。

```
检索题库 ──> 出候选清单（题号+题干预览+考点，可跨卷） ──> 圈定写成「组卷清单」 ──> 一条命令出卷（md / Word）
```

> **成卷版式规范**：学生卷/教师卷的卷面版式（卷头/大题结构/选项断行/图片/答案卷/字体）一律遵循 `references/试卷排版规范.md`；题面信息标注（来源括注/分值括注/出处）格式见同文件 **§十二**（自包含副本）。

## 1. 检索

按 册别/单元/课/知识点/题型/难度/来源/年份 任意组合筛选：

- **Obsidian 内**：Bases/Dataview 查询（`TABLE 题干 FROM "历史题库" WHERE contains(册别, "8上") AND contains(知识点, "鸦片战争")`；册别/课/知识点均为多值 list，检索一律用 `contains(字段, "值")` 函数语法，参数必须双引号——⚠ Dataview DQL 没有 `CONTAINS` 操作符，字符串字面量只认双引号；操作符写法或单引号参数都会 PARSING FAILED）
- **命令行**：`python scan_questions.py --dump` 输出全量题目元数据（JSON 数组：id/册别/课/题型/难度/来源/年份/卷名/文件路径），按条件过滤

**三口径检索（v1.5.0）**——定位三字段多值、**首项＝命题落点**，按场景选口径：

| 口径 | 取法 | 适用场景 |
|:--|:--|:--|
| **主考** | 首项命中：`课[0]`（命令行取 `课` 数组第 1 项；DQL 写 `课[0] = "第5课 甲午中日战争与列强瓜分中国狂潮"`） | 出课练卷、判断课时投入 |
| **兼涉** | 非首项命中：`contains(课, "…") AND 课[0] != "…"` | 看「背景型课」、关联教学、答题落点总结 |
| **全涉** | 任一命中：`contains(课, "…")` | 复习卷、跨课主题组卷 |

- **默认用全涉**（不特别说明时，避免漏题）；课练卷/课时决策走主考；两者的差值即该课的「背景化程度」

## 2. 列出候选

向用户展示 题号、题干（截断）、册别/课、题型/难度/分值，供用户圈定。

候选题多时建议落成**候选清单文件**（如 `candidates.md`：按单元/课分组，每题带 层次/能力/答案/知识点/解析/正文/有无图），便于逐条比对圈定——9/21 周测即此做法（`build_candidates.py` → `candidates.md`）。**圈定结果写成「组卷清单」**（见 §3），不要再靠命令行堆题号。

## 3. 圈定后出卷（清单驱动）

**核心接口是一份「组卷清单」**——有序的题目引用，可跨卷，每项可带分值/来源括注/考察角度。
题目正文**实时从题库读取**（清单只管「选哪些、什么顺序、怎么标注」），题目日后修订，重跑即生效。

清单三种形态（同结构）：`.yaml`（人写，模板见 `templates/组卷清单.yaml`）、`.json`（程序/工作台产出）、`.txt`（一行一个 id）；
**兼容 9/21 式 `selected.json`**（顶层数组、元素带 id/文件 快照）——老清单可直接复用。

```bash
python export_student_paper.py --清单 组卷清单.yaml --体检                       # 先看卷面结构，不出卷
python export_student_paper.py --清单 组卷清单.yaml --模式 学生 --输出 卷_学生版.md
python export_student_paper.py --清单 组卷清单.yaml --模式 教师 --docx 卷_教师版.docx
```

- **清单顺序即卷面顺序**，脚本自动重编题号（`1．2．…`）——跨卷不再有「两卷各有第 1 题」的问题
- **非选择题分值紧随题号**（`21．（6分）`）；学生卷默认不标来源，加 `--标来源` 才附来源括注
- **答案分布均衡**：对部分题加 `选项序: [3,1,2,4]`（新 A/B/C/D 位依次放**原第几项**），**答案自动换算**，题库原题不动
- **作答括号**默认自动补；卡片式/条文式材料题的设问在材料之前，会补在设问行而非末行，此时体检提示核对，可用 `括号: 首行|末行|无` 手工指定
- **图片**统一放 `{输出目录}/images/{卷名}/`，跨卷同名图不互撞；解析字段里的图也一并改写命名空间（与题干重复的自动去掉）
- **体检**（每次出卷自动打印）：题量/总分/题型、难度分布、答案分布（仅选择题）、来源构成、册别、卷源数、考点覆盖，以及**同课多题、答案连续同项、括号补在非末行**三项告警

### 产物形态（md / Word / 答题卡，同一条命令）

| 形态 | 场景 | 做法 |
|:---|:---|:---|
| **md 卷** | Obsidian 内使用/存档 | `--输出 卷.md`（默认） |
| **Word 卷** | 打印/分发/考试用 | 加 `--docx 卷.docx`（**可与 md 同时出**）。版式见下「Word 卷版式执行表」 |
| **答题卡** | 校级测试（手阅，非网阅） | 给了 `--docx` 就**默认同出** `{卷名}_答题卡.docx`（A4 两页）；`--无答题卡` 关、`--答题卡 <路径>` 另指位置、`--答题卡每行 N`（默认 10 题/行）、`--答题卡行数 N`（默认每小问 2 行）调参 |

**Word 卷版式执行表**（《试卷排版规范》条款 → 脚本实现）：

| 条款 | 实现 |
|:---|:---|
| §七 字号行距 | 正文宋体 12pt ＋ 固定行距 24pt；辅文 10.5pt／行距 ≥20pt |
| §二 大题结构 | 自动插入 `一、选择题（每小题X分，共Y分）`／`二、非选择题（共Z分）`；**小题跨大题连续编号** |
| §三/§12.4 选项 | **两项一行**、`A．` 全角顿点、项间全角空格×2 |
| §四 分值 | 非选择题**分值紧随题号**（`21．（6分）`）；选择题在卷头说明 |
| §四 材料 | `材料一/二` 顶格独立成段；**材料出处 `——摘编自…` 右对齐** |
| §12.1 来源括注 | 加 `--标来源` 时**紧跟题号后**（`1.（2026·河南中考·14）`） |
| §五/§十 图片 | 单图独立成段居中（`--图靠右` 可改右对齐）；**连续多图并排**（无框表一行 N 列 ＋ 图注行）；图注紧随居中原位插入 |
| §六 教师卷 | 答案**分页另起**；**选择题答案连排**（每行 10 项：`1．B　2．D…`），解析在连排后逐题列出 |
| §十一 自检 | 成卷后跑 `verify_paper_layout.py --docx`（本脚本产出的卷已实测 ✓ 10 项合规 / 0 不合规） |

⚠ **图片质量**：脚本只管取图与摆放；扫描件清晰度不达标时由人工替换 `images/` 内原图后重出。
⚠ **单项未自动实现**：§10.1「单图靠右、题干绕左」要求**文字环绕**（浮图），python-docx 需手写 `wp:anchor`；现提供 `--图靠右`（段落右对齐，图仍在题干下方独立成行），**真正的环绕效果需在 Word/WPS 里人工拖动**。

### 3.5 答题卡（校级测试·手阅版）

版式照 2026.09.22 月考答题卡实物（A4 两页）：

- **页面**：A4；**左边距 30mm 作装订区**（右 20 / 上 18 / 下 18，页脚距 12.7mm，版心 160mm）
- **姓名栏在页眉**（页面最上方、**每页都有**）：`姓名____　班级____　考场____　考号____`，居中，页眉距顶 10mm
  ⚠ **不能作正文段落**——那样第二页顶部直接就是学生作答区，装订时会被钉住/盖住（2026-09-25 用户实测反馈）
- **正文卷头**：卷名 ＋「答　题　卡」两行，黑体 14pt 居中
- **选择题栏**：`一、选择题（每小题X分，共Y分）`（分值不统一时写 `共N小题，Y分`）＋**全框线表**`题号`／`答案` 两行，每行 10 题（首列 16mm、其余 14.4mm、行高 8.5mm），超 10 题自动续表
- **非选择题栏**：`二、非选择题（共Z分）` ＋ 逐题逐小问 `21．（1）`，**每小问留 2 行**；从题目正文自动提取小问号；无小问的题（小论文/论述）留 6 行
- **页脚**：`历史答题卡　第 X 页　共 Y 页`
- ⚠ 留白行数按分值算不准，**材料题答案长时应调大 `--答题卡行数`**（实测 20 选择 + 5 材料题＝2 页）

### 3.1 备用成卷路径（`--docx` 已覆盖常规成卷，以下仅供特例或改版）

**A. 本地 Office 编辑通道**（需逐块微调时）：以题库原题 md 为内容源——`create_doc` → 分块 `doc_insert_markdown` → `images/` 原图 `doc_insert_image`（独立段落居中）→ 标题/图片段落居中 → 答案分页另起 → `save_file`。
⚠ editor_sdk 插入图片的 `idx` 是 DOC 坐标，**不可手算**——用上一步写操作的返回值或 `doc_get_last_operable_pos` 链式取位；插错可用 `doc_undo_ai_edit` 按 version 撤销（2026-09 实测）。

**B. 自写 python-docx 脚本**（要批量出多卷、或加答题卡等脚本未覆盖的版面），版式参数与踩坑：

- **版式参数**：A4、左右边距 21mm、上下 25mm；正文宋体 12pt ＋ **固定行距 24pt**；⚠ **辅文（卷头说明/图注/表内/续行）10.5pt 时行距须 ≥20pt**——16pt、18pt 的净空 <3.0mm，`--docx` 校验的 A3 项会直接拦
- **选项「两项一行」的配对**：第一行 `(A)(B)`、第二行 `(C)(D)`（`a,b = k*2, k*2+1`）；⚠ 误写成 `k, k+half` 会排成 A,C / B,D，卷面看着"整齐"但字母顺序错乱，极难自查
- **卷面惯例**：卷头标题居中、大题"一、选择题/二、非选择题"、**小题跨大题连续编号**（河南通例）；短选项同行（全角空格×2）／长选项两两换行；材料出处 `——摘编自…`；外国作者加 `[日]`/`[美]` 前缀；`右图`→`下图`（本 skill 单图居中而非靠右）
- **文本清理**：中文之间的半角 `,` `;` → 全角；**中文与中文之间的空格改全角**（保留并列词，如「兼收并蓄　融合创新」）、数字/字母两侧空格删除；成对半角引号内含中文时改弯引号
- ⚠ **清理前必须先保护 `（　　）` 作答括号**——括号内部是全角空格、两侧是括号（非中文字符），会被「删多余空格」清成 `（）`，与后补的括号叠成 `（）（　　）`（2026-09-25 实测）
- **图片**：单图独立段落居中（宽 58~138mm 按图幅定）；多图并排用**无框表格**（第 1 行放图、第 2 行放图注）以保证图注对齐；**图注行须从题干行中剔除**，否则卷面重复出现一次
- **防跨页**：题干段/图片段/图注段/首个选项段设 `keep_with_next`，各段设 `keep_together`
- **答题卡**：题号列宽须 **≥9mm**（25 题排一行会挤到"11"折行成"1/1"）→ 建议 **17 题一行、分 3 段**；页脚插 `PAGE`/`NUMPAGES` 域
- **成卷后**必跑 `verify_paper_layout.py --docx`；需要目视分页时用 win32com 导 PDF 复核（`ExportAsFixedFormat`；⚠ 目标 PDF 已存在会报"文件为只读"，导出前先删旧文件；Word COM 首次调用常报"被呼叫方拒绝接收呼叫"，先 `taskkill /F /IM WINWORD.EXE` 再重试即通）

### 3.2 选择题答案分布均衡（成卷前必检）

体检打印的 `答案 A… B… C… D…` 即分布快照；某项占比超 35% 会告警。均衡办法——**在清单里给该题加 `选项序`**（v1.12.0 起脚本原生支持，**答案自动换算**，题库原题不动）：

```yaml
- id: 2024河南中考-15
  选项序: [3, 1, 2, 4]        # 新 A/B/C/D 位依次放**原第** 3、1、2、4 项
```

- 目标：10 题卷各 2-3 个、20 题卷各 5 个上下
- 学生卷与教师卷用**同一份清单**，自然一致
- 来源括注沿用原卷来源，不因重排改变；解析里提到「故选 C」等文字需人工核对（脚本不改解析文字）

### 3.3 一题多卷题的处理（v1.3.0）

- 题库内一题只存一份（主卷），`id` 多值表示"另被哪些卷收录"——**检索按主卷命中即可，不会因多卷收录而重复出题**
- 学生卷**来源标注按主卷**（如 `(2024·河南中考·8)`）；若想体现"本卷亦曾收录"，可在教师卷备注"原题见《别名卷名》"
- 别名题已归档到 `{vault}/_归档/重复题/`，**不在检索与组卷范围内**；要还原某卷完整卷面，按该卷目录下 `_重复题清单.md` 的「主题 id」取题
- ⚠ 因此"按卷还原原卷"会缺重复题——**原卷 PDF 存档才是还原的正源**，归档仅留痕

### 3.4 版式合规自检（v1.4.0 起，成卷必做）

```bash
python verify_paper_layout.py --docx "<成卷.docx>"        # Word 卷：字号/行距/字体/页面尺寸/图片/答案分页
python verify_paper_layout.py --卷 <卷名>                  # 题库卷结构层：题号连续/选项/图片/学生卷无答案
```

- **有「✗ 不合规」项不得交付**（退出码 1，可作流程阻断）；按输出的「修法」列修正后重跑
- **国标底线**（GB 40070-2021 §7，强制）：正文 **宋体 ≥12pt（小四）**、行空 **≥3.0mm**（等效行距 ≥21pt，本 skill 取固定行距 24pt）、辅文 **≥9pt（小五）**；⚠ Word 默认单倍行距与 1.5 倍行距**均不达标**
- **页面尺寸两模式**：A4 打印模式（版心 ≈168mm）／**中考仿真模式 185×260mm**（6 开长条三折单页，版心 ≈145~155mm）——河南中考卷实物为一张 6 开纸三折双面印、共 6 页
- 调参项：`--正文最少字号/--辅文最少字号/--行空最少` 可覆盖国标默认阈值（非标纸张实测校准时用，正常成卷不动）；`--json` 机器可读输出
- 版式条款见 `references/试卷排版规范.md`（含**图文混排规范**：单图靠右/多图并排/图注/表格/主题框）；依据与实测见 `references/标准-试卷排版依据.md`；核验分工见 `references/试卷版式核验矩阵.md`
- 人工项（同一题不得跨页、图注不脱图、选项两项一行、卷头注意事项）需在 Word 分页预览中过一遍

## 4. 册别索引

**默认 MOC 模式 = 「混合式 MOC：手工骨架 + 动态查询」**：vault 的 `1-MoC-索引/` 下已有 7上/7下/8上/8下/9上/9下 六个试题索引，按教材逻辑（单元-课）半自动索引：

- **特征**：① 单元-课分组标题 = 手工静态骨架（与 BOOK_INDEX 词表一致，保留教材层级）；② 每课下题目 = Dataview 动态查询（新题自动流入已有课）；③ 新课需手动补一个标题+查询块（半自动）；④ 跨课/跨册题会同时出现在其命中的多个课块下
- 查询模板（⚠ DQL 无 CONTAINS 操作符，一律 `contains(字段, "值")` 函数 + 双引号参数）：
  ```dataview
  TABLE id AS 题号, 课, 知识点, 题型, 素养层次水平, 关键能力
  FROM "初中-1中考真题" OR "初中-2中考模拟题" OR "初中-3阶段测试"
  WHERE contains(册别, "7上") AND contains(课, "第X课 课名")
  SORT id ASC
  ```
- 索引由 `scripts/gen_index.py` 从 BOOK_INDEX 自动生成（词表更新后重跑即可重建）；此模式亦为全库 MOC 默认约定（见用户级记忆）
- **学史方法索引**：`1-MoC-索引/学史方法-试题索引.md` 按全六册 15 个学史方法组织（同属「混合式 MOC」模式：方法名手工骨架 + Dataview 按小节/课筛选）

## 铁律（组卷专属）

1. **出题范围裁剪**：用户限定范围（如「期中范围」「讲到第X课」）时，候选题按范围过滤；题目（含材料题设问）涉及范围外内容的，**裁剪超范围部分或整题剔除**——核心原则「**讲到哪儿考到哪儿**」，主要针对月考/期中考
2. **组卷标注题目来源**：学生卷中/高考题标来源，格式 `(年份·地区试卷·题号)`，如 `(2024·广东中考·1)`——**近 5 年中考题必标**，高考题**不限定年份**，凡引用原题均标注来源（完整规范见 `references/试卷排版规范.md` §十二：真题/模拟年份取考试发生年；**阶段测试按学年**，如 `（2024-2025学年·洛阳期末·4）`，与题目 id 卷名口径一致）
3. **答案分布均衡**：成卷前按 §3.2 检查，答案集中则重排选项并同步改答案
4. **跨册材料题慎用**：题库多值课字段的跨册综合材料题，仅主题贴合本卷考查课时选用，设问指向外册内容可裁小题

## 陷阱（组卷专属，血泪）

1. **导出文件勿入库**：`*_学生版.md`/`*_教师版.md` 会污染 scan/collect（已自动排除）
2. **`--only` 题号 1 与 01 互通**（v1.11.0 修）：写 `1` 或 `01` 都能命中 `01.md`；旧版只做文件名精确匹配，`--only 1,3` 实测报「没有匹配的题目文件」并退出码 1
3. **`_重复题清单.md` 不是题目**（v1.11.0 修）：不写 `--only` 的全卷导出，旧版会把它当作一道题拼进卷面——实测同一卷旧版 23 题 / 新版 22 题。现按 `_` 前缀统一排除
4. **教师卷的答案/解析里也可能有图**（v1.11.0 修）：`解析` 字段可内含 `![](images/…)`（实测 `2024河南中考-01` 解析末行即有一张）；旧逻辑只改写正文的图片路径，跨卷时该图断链。现对「正文＋答案＋解析」整体改写
5. **跨卷输出必须显式 `--输出`**：脚本会拦（退出码 1），别试图写进某个来源卷目录——那会污染源卷的 `images/`
6. **成卷文本流里的两处「隐形字符」坑**（v1.12.0 实测）：① `（　　）` 作答括号内部是全角空格、两侧是括号，**清理空格前必须先整段保护**，否则被清成 `（）`、与后补的括号叠成 `（）（　　）`；② 图片若以占位符形式在文本流里传递，**只能用私有区字符**（如 `\ue001`），**不能用 `\x00`** —— Word XML 不接受 NUL，写 docx 时直接抛 `ValueError: ... no NULL bytes`
7. **重排选项不重写解析文字**：`选项序` 只改选项顺序与答案字母，解析里「故选 C」之类的字母指代不会跟着变，重排后需人工核对
