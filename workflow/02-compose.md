# 流程二 · 组卷/出题

> **触发词**：出题、组卷、出一套卷子、某个范围/某个知识点（用户说「某个范围/某个知识点」→ 检索，**不是还原原卷**）。
>
> **前置检查**：运行前确认已初始化——`<skill>/scripts/skill_config.json` 含有效 vault 或 `TNOTE_VAULT` 已设；**若脚本报「未配置题库库」→ 先读 `workflow/00-init.md`** 完成配置再继续。

```
命题参数引导（§0：默认直走，仅难度/能力两项弹窗） ──> 检索题库 ──> 出候选清单 ──> 圈定写成「组卷清单」 ──> 一条命令出卷（md / Word / 答题卡）
```

> **成卷版式规范**：学生卷的卷面版式（卷头/大题结构/选项断行/图片/字体）一律遵循 `references/试卷排版规范.md`；题面信息标注（来源括注/分值括注/出处）格式见同文件 **§十二**（自包含副本）。教师侧的《命题说明》为独立内部资料，见 **§3.7**。

## 0. 命题参数引导（进入检索前先做）

**原则：默认直走，不写参数单、不逐项确认——只有「难度结构」「能力维度侧重」两项弹窗问用户。** 用户在对话里主动给的额外要求（如"避开周测已用题""别用含图题"）按其说的执行。

### 默认项（用户不提就按此执行，开工时在对话里带一句即可）

| 项 | 默认 |
|:--|:--|
| 卷面结构 | 选择 20 道×2 分＋非选择共 60 分＝100 分。**换算口径：中考满分 50 分，平时考试满分 100 分＝中考的 2 倍，卷面结构按 2 倍换算**——非选择题总分恒为 60 分（= 中考非选择 30 分 × 2），但**每题分值不必拘泥 12 分**：按题库原生分值凑总 60 即可，避免「题号总分 ≠ 题内小问分值之和」的卷面矛盾；用户点名「仿某卷」则按该卷结构 |
| 时长/卷头 | 60 分钟；注意事项 3 条（卷面结构／填涂要求／作答位置）。**小测试/周测等短卷 30 分钟**（用户一般会主动说明，说了按短卷处理，题量随之收缩） |
| 单元/课配比 | **中考高频课加权**（用 `scan_lesson.py` 的课次热度三梯队定各课题量）＋ **新增课保底每卷 ≥1 题**（新教材第一年，新增课考试卷从未考过） |
| 与近期卷去重 | **先跑 `record_usage.py --已用 <学年>`** 排出本学年已用题，检索候选时直接排除（见 §3.8）；用户另点名的排除卷（如某周测）一并剔除。学年内尚无登记时，在检索前提醒一句「未做近期卷去重，需排除请说」，不弹窗 |
| 图片 | 含图题照常保留（低质图后续人工替换）；用户说排除才排除 |
| 答案均衡 | 出卷体检报集中项后**建议** `选项序`（`--均衡选项` 直接给方案），写进清单前经用户确认 |
| 产物 | 月考/期中期末：学生卷＋**命题说明**＋**独立答题卡**三件全出。**小测试/周测：不单独出答题卡，答题区附在试卷末尾**（`--答题卡位置 卷末`，仅学生卷） |
| 来源标注 | 学生卷不标（要标加 `--标来源`）；题目来源一律记入**命题说明** |

### 弹窗确认项（AskUserQuestion 一次问两个，均带"自定义"入口）

1. **难度结构**（**整卷按分值 基础∶中档∶难 ≈ 7∶2∶1**，即 70∶20∶10 分；2026-10-29 起按此口径——选择题与非选择题**共同凑**，不再"非选择默认均中"）
   - 选择题 20 道 40 分的三档预设（非选择题按下方搭配，两段合起来接近 7:2:1）：
     - ① 易 14 / 中 4 / 难 2（**默认推荐**）
     - ② 易 16 / 中 3 / 难 1（基础巩固，整卷偏易）
     - ③ 易 11 / 中 6 / 难 3（选拔性，整卷偏难）
   - **非选择题按同一比例分档**：基础 3 题、中档 1 题、较难 1 题（难可只落在某一小问，整题仍记基础/中档）——默认 5 题 60 分卷即 36∶12∶12，整卷约 64∶20∶16
   - ⚠ **标注照 `references/fields.md`「难度标注判据」**：非选择题**也可以、也应当标「易」**。一律标「中」会让中档分值必然 ≥60 分，**7:2:1 在数学上不可能达成**（全库实证：河南中考 2022-2026 的非选择题恒为「4 中 + 1 难」，从无一道标易）
   - 落地后看 `--体检` 的「难度分值」与「选择题」两行：选择题易题对真题基线（37%）、分值对设计目标，**以前者为主**
2. **能力维度侧重**（郑林 9 要素）：
   - ① A3-概括＋B2-分析为主（合计 ≥60%），A1-识记 ≤1 题（仿中考，**默认推荐**）
   - ② A1-识记＋A2-说明为主（基础卷）
   - ③ 九要素均衡覆盖（全面摸底）

> ⚠ 题库「难度」字段与人工判断不完全一致（实测偏差见 LOCAL-PATCH），**按难度/能力过滤候选只能圈出大致池子，最终以圈定时的逐题判断为准**；难度比例以体检的按分值核算为准，不靠逐题数点。

### 0.1 题源配比（按考试规格，2026-10-29 补）

> **与「单元/课配比」是两个正交维度**：课配比管「每课出几题」（中考高频课加权＋新增课保底，**不变**）；题源配比管「题目从哪类卷里挑」。

| 考试规格 | 题源配比 | 取向 |
|:--|:--|:--|
| **月考 / 期中**（阶段检测） | **教材改编＋本地阶段卷为主、真题为辅**（约 6∶3∶1）；真题只取与本次范围吻合的 | 立足当前所学，引导学生回归教材、课堂 |
| **期末 / 中考模拟**（一模二模） | **本地真题优先**（近 5 年＋市级以上），模拟卷为辅 | 模仿命题逻辑，把握命题风向 |
| **单元测 / 周测** | 本单元/本课题目为主，可全取（含本校原创题） | 范围封闭 |

- **外省题准入**：只选分值结构、命题风格、难度系数相近地区的卷；全省统一命题区、教改先行区（北京／广州／四川等）可放宽，用于感知风向。**风格差异大的外地题不用**。
- **依标扣本**：正文表述、概念尽量与教材一致，`知识点` 宜对应课标条目。题源再"好看"，与教材表述冲突的不用。
- **常备对照**：《义务教育历史课程标准》（学业质量部分）、现行教材、近 3~5 年本地官方真题及权威解析。

### 0.2 推进次序（选择题优先、主观题回删，2026-10-29 定）

1. **搭框架**：按考查范围列考点清单 → 定各单元/课分值占比 → 定难度目标（7:2:1）
2. **先筛选择题**：铺满考点（保证基础全覆盖），此时**允许超配**
3. **再定主观题**：按主干知识选，控制阅读量、设问层次、开放性；跨范围题按小问裁剪（见铁律 1）
4. **回删选择题**：主观题已覆盖的考点，删去对应选择题；**重算总分与难度比例**后回到第 2 步微调
5. **两轮试做（人工）**：① 逐题排查考点重复、史料矛盾、设问歧义、答案冲突、排版配图；② 完整限时试做，核算答题时长，调难易比例
6. **出卷体检**：`--体检` 看结构、难度比例、材料形式、能力重复、时序，按提示改清单再出卷

### 非选择题：按主题选

1. 依据考查范围列核心主题（如「中外文化遗产比较」「大学的兴起」「帝国扩张与文明交流」「法制传统」）
2. 按主题检索非选择题（`scan_questions.py --dump` 过滤题型）
3. **候选双重冗余**：① 总量 **≥ 所需量 2 倍**；② **每个主考课（`课[0]`）≥2 道备选**——总量够而某考点只有 1 道时，该点无题可换（若圈定的首选被否，整卷配比就塌），须在候选池里标「**⚠ 单点风险：仅 1 道**」。选择题同法（同一核心考点储备 2~3 道备用，方便替换调整）
4. 给候选池（题号＋主题＋分值＋有无图＋难度＋**有无情境**＋**是否跨范围、需保留哪几问**）供用户圈定
5. **候选不足** → 明确说「主题 X 候选不足（仅 N 道）」，并建议：扩到相邻册别／从新卷补录／改用相邻主题

## 1. 检索

按 册别/单元/课/知识点/题型/难度/来源/年份 任意组合筛选：

- **Obsidian 内**：Bases/Dataview 查询（`TABLE 题干 FROM "历史题库" WHERE contains(册别, "8上") AND contains(知识点, "鸦片战争")`；册别/课/知识点均为多值 list，检索一律用 `contains(字段, "值")` 函数语法，参数必须双引号——⚠ Dataview DQL 没有 `CONTAINS` 操作符，字符串字面量只认双引号；操作符写法或单引号参数都会 PARSING FAILED）
- **命令行**：`python scan_questions.py --dump` 输出全量题目元数据（JSON 数组：id/册别/课/题型/难度/来源/年份/卷名/文件路径），按条件过滤

**三口径检索（v1.5.0）**——定位三字段多值、**首项＝命题落点**，按场景选口径：

| 口径 | 取法 | 适用场景 |
|:--|:--|:--|
| **主考** | 首项命中：`课[0]`（命令行取 `课` 数组第 1 项；DQL 写 `课[0] = "第5课 甲午中日战争与列强瓜分中国狂潮"`） | 出课练卷、判断课时投入 |
| **兼涉** | 非首项命中：`contains(课, "…") AND 课[0] != "…"` | 看「背景型课」、关联教学、答题落点总结 |
| **全涉** | 任一命中：`contains(课, "…")` | 复习卷、跨课主题组卷 |

- **默认用全涉**（不特别说明时，避免漏题）；课练卷/课时决策走主考；两者的差值即该课的「背景化程度」

## 2. 列出候选

向用户展示 题号、题干（截断）、册别/课、题型/难度/分值、**有无情境**，供用户圈定。

候选题多时建议落成**候选清单文件**（如 `candidates.md`：按单元/课分组，每题带 层次/能力/答案/知识点/解析/正文/有无图/**有无情境**），便于逐条比对圈定（`scan_questions.py --dump` 的输出可直接落成该文件）。**圈定结果写成「组卷清单」**（见 §3），不要再靠命令行堆题号。

### 2.1 情境判据：只判「有无」（初中，2026-10-29 定）

**初中阶段首要问题是「这道题到底有没有情境」，类型细分（学习/生活/学术情境）留待后续**，组卷环节不做。

| 判据 | 做法 | 结论 |
|:--|:--|:--|
| **遮住情境还能不能做** | 盖住材料/情境，只看设问 | 能作答 → **无情境**（实质是知识记忆题，情境只是包装）｜ 不能 → **有情境** |

- **应用位置**：列候选时逐题标注「有情境／无情境」，**圈定与备用题一律按此筛**（备用题也须有情境，否则换上去等于降级）
- 无情境题**不作首选**；仅当该考点必须有题覆盖且无替代时保留，并在《命题说明》第五部分备注
- **判据同源**：命题方法论 §2.9「情境有效性」（见 `workflow/04-angle-analysis.md` §5b）——那里用于判「典型题」，这里用于判「可选题」
- ⚠ **不判伪素养、不判情境七维度**：那是分析流程（04）的活；组卷只用这条二分判据，避免把简单事做复杂

## 3. 圈定后出卷（清单驱动）

**核心接口是一份「组卷清单」**——有序的题目引用，可跨卷，每项可带分值/来源括注/考察角度。
题目正文**实时从题库读取**（清单只管「选哪些、什么顺序、怎么标注」），题目日后修订，重跑即生效。

清单三种形态（同结构）：`.yaml`（人写，模板见 `templates/组卷清单.yaml`）、`.json`（程序/工作台产出）、`.txt`（一行一个 id）；
**兼容 9/21 式 `selected.json`**（顶层数组、元素带 id/文件 快照）——老清单可直接复用。

```bash
python export_student_paper.py --清单 组卷清单.yaml --体检                       # 先看卷面结构，不出卷
python export_student_paper.py --清单 组卷清单.yaml --均衡选项                    # 答案分布诊断 + 重排方案
python export_student_paper.py --清单 组卷清单.yaml --模式 学生 --docx 卷_学生版.docx
python export_student_paper.py --清单 组卷清单.yaml --模式 命题说明 --docx 卷_命题说明.docx
```

- **清单顺序即卷面顺序**，脚本自动重编题号（`1．2．…`）——跨卷不再有「两卷各有第 1 题」的问题
- **非选择题分值紧随题号**（`21．（6分）`）；学生卷默认不标来源，加 `--标来源` 才附来源括注
- **答案分布均衡**：先跑 `--均衡选项` 拿方案，再对相应题加 `选项序: [3,1,2,4]`（新 A/B/C/D 位依次放**原第几项**），**答案自动换算**，题库原题不动
- **作答括号**默认自动补；卡片式/条文式材料题的设问在材料之前，会补在设问行而非末行，此时体检提示核对，可用 `括号: 首行|末行|无` 手工指定
- **图片**统一放 `{输出目录}/images/{卷名}/`，跨卷同名图不互撞；解析字段里的图也一并改写命名空间（与题干重复的自动去掉）
- **体检**（每次出卷自动打印）：题量/总分/题型、难度分布、答案分布（仅选择题）、来源构成、册别、卷源数、考点覆盖，以及**同课多题、答案连续同项、括号补在非末行**三项告警
- **整卷结构四项**（2026-10-29 补，对标《关于高质量组卷的几点建议》；**均提示级、不阻断**）：

  | 项 | 输出 | 告警条件 | 处置 |
  |:--|:--|:--|:--|
  | 材料形式 | 纯文字/表格/图 各 N 题（非选择单列） | 全卷无表无图；或非选择题**全**为纯文字 | 换 1 道图表题、1 道图像题 |
  | 主观题素养 | 非选择题关键能力分布 | 同一关键能力 ≥2 题；无论述/综合探究（无开放题） | 换 1 题改考其他素养；补开放题 |
  | 通史时序 | 逆序处数＋前 5 处题号 | **同题型块内**课序回退（跨大题回退属正常结构，不报） | 调整清单顺序 |
  | 难度结构 | 分值三档 vs 设计目标 7:2:1；**选择题题量 vs 真题基线**（易 37%／中 63%／难 0%，河南中考 2022-2026） | 选择题易题**低于基线 15 个点** | 补基础题；分值口径偏离仅作参考（非选择题整题只标一档会放大） |

  难度一项刻意做成**双口径**：分值口径受「非选择题整题一档」掣肘，必定偏中（实测中考 75%、高考 78%、本校 82%），**不能当硬指标**；真正可执行的是选择题基础题够不够。基线数据与「标注为何失真」见 `references/分析基线-洛阳.md`「真题难度标注基线」、`references/fields.md`「难度标注判据」。

  未标注「关键能力」的题会计入「能力重复检测不完整」，属提示、不影响出卷。

### 产物形态（md / Word / 答题卡，同一条命令）

| 形态 | 场景 | 做法 |
|:---|:---|:---|
| **md 卷** | Obsidian 内使用/存档 | `--输出 卷.md`（默认） |
| **Word 卷** | 打印/分发/考试用 | 加 `--docx 卷.docx`（**可与 md 同时出**）。版式见下「Word 卷版式执行表」 |
| **答题卡** | 校级测试（手阅，非网阅） | 给了 `--docx` 就**默认同出** `{卷名}_答题卡.docx`（A4 两页）；`--无答题卡` 关、`--答题卡 <路径>` 另指位置、`--答题卡每行 N`（默认 10 题/行）、`--答题卡行数 N`（默认每小问 2 行）调参 |

**Word 卷版式执行表**（《试卷排版规范》条款 → 脚本实现）：

| 条款 | 实现 |
|:---|:---|
| §七 字号行距 | 正文宋体 12pt ＋ 固定行距 24pt；辅文 10.5pt／行距 ≥20pt |
| §二 大题结构 | 自动插入 `一、选择题（每小题X分，共Y分）`／`二、非选择题（共Z分）`；**小题跨大题连续编号** |
| §三/§12.4 选项 | **两项一行**、`A．` 全角顿点、项间全角空格×2 |
| §四 分值 | 非选择题**分值紧随题号**（`21．（6分）`）；选择题在卷头说明 |
| §四 材料 | `材料一/二` 顶格独立成段；**材料出处 `——摘编自…` 右对齐** |
| §12.1 来源括注 | 加 `--标来源` 时**紧跟题号后**（`1.（2026·河南中考·14）`） |
| §五/§十 图片 | **一律浮动图**（非嵌入型）：单图默认「上下型环绕＋居中」，宽幅图铺 155mm、普通图回落 78mm；`--图靠右` 改 §10.1「**四周型环绕**：图靠右 55mm、题干与选项绕左」；多图按 `(版心168−6×(N−1))/N` 等宽并排，图注用**无框表**逐列对齐（`--图片宽` 给值则固定宽） |
| §六 答案卷 | 学生卷不含答案；参考答案与《命题说明》为**独立文档**（内部资料），不并入学生卷 |
| §十一 自检 | 成卷后跑 `verify_paper_layout.py --docx`（有「✗ 不合规」不得交付） |

⚠ **图片质量**：脚本只管取图与摆放；扫描件清晰度不达标时由人工替换 `images/` 内原图后重出。
⚠ **图片环绕**：全部图片改用**文字环绕-上下型环绕**（脚本内 `add_float_pic()` 手写 `wp:anchor` ＋ `wp:wrapTopAndBottom`）。起因：原**嵌入型**图片随本卷「固定行距」被裁成横带（单元格 20pt 行距把三图压成横条）。⚠ 两处例外：**含图的普通表格**单元格行距须改**单倍**（该处图片保持嵌入型——格内浮动图会溢出格线）；**多行图组**（6 图＝图/注/图/注）按行各自锚定，页尾放不下时整行下移、该页会留白。
✅ **§10.1「图靠右、题干绕左」已实现**（`--图靠右`）：**四周型环绕**（`wp:wrapSquare wrapText="bothSides"`）——图锚在题干首段、靠右 55mm，题干与选项同绕图左；图注**补在选项之后**落图正下方（浮动图不占文档流，不补则下一题与本题图垂直重叠）。⚠ 图高于整题文本流时会延伸进下边距（Word 浮动图不受页边距约束）。

### 3.1 备用成卷路径（`--docx` 已覆盖常规成卷，以下仅供特例或改版）

**A. 本地 Office 编辑通道**（需逐块微调时）：以题库原题 md 为内容源——`create_doc` → 分块 `doc_insert_markdown` → `images/` 原图 `doc_insert_image`（独立段落居中）→ 标题/图片段落居中 → 答案分页另起 → `save_file`。
⚠ editor_sdk 插入图片的 `idx` 是 DOC 坐标，**不可手算**——用上一步写操作的返回值或 `doc_get_last_operable_pos` 链式取位；插错可用 `doc_undo_ai_edit` 按 version 撤销（2026-09 实测）。

**B. 自写 python-docx 脚本**（要批量出多卷、或加答题卡等脚本未覆盖的版面），版式参数与踩坑：

> **首要判断：题目在不在题库？** 在库 → 走 §3 清单驱动（`export_student_paper.py`）。**不在库 → 本节适用**。典型场景：**错题变式卷/二次检测卷、临时自编练习**——题目是现写的，题库里没有对应 md，`--清单` 无从驱动，只能自写脚本以 md（或直接以数据）为内容源出 Word。

- **版式参数**：一律照 `references/试卷排版规范.md` §七（A4、左右 21mm／上下 25mm、宋体 12pt ＋ 固定行距 24pt）。⚠ **自写脚本时唯一的额外坑**：辅文（卷头说明/图注/表内/续行）10.5pt 时行距须 **≥20pt**——16pt、18pt 的净空 <3.0mm，`--docx` 校验的 A3 项会直接拦
- **md 内容源的三处必清洗**（变式卷 md 常带 markdown 标记，直接喂 docx 会原样显示）：
  1. **剥 `**加粗**`**：`s.replace('**','')`——否则卷面出现裸星号（2026-09-30 实测）
  2. **半角引号 `"` → 中文弯引号 `“”`**（成对交替替换）
  3. **长选项改独占一行**：选项任一 >13 字时「两项一行」会折行错位（如 A 项尾巴挤到 B 项行首）→ 判据 `any(len(t)>13 for _,t in opts)`，命中则四项各占一行；否则维持两项一行
- **选项「两项一行」的配对**：第一行 `(A)(B)`、第二行 `(C)(D)`（`a,b = k*2, k*2+1`）；⚠ 误写成 `k, k+half` 会排成 A,C / B,D，卷面看着"整齐"但字母顺序错乱，极难自查
- **卷面惯例**：卷头标题居中、大题"一、选择题/二、非选择题"、**小题跨大题连续编号**（河南通例）；短选项同行（全角空格×2）／长选项两两换行；材料出处 `——摘编自…`；外国作者加 `[日]`/`[美]` 前缀；`右图`→`下图`（本 skill 单图居中而非靠右）
- **文本清理**：中文之间的半角 `,` `;` → 全角；**中文与中文之间的空格改全角**（保留并列词，如「兼收并蓄　融合创新」）、数字/字母两侧空格删除；成对半角引号内含中文时改弯引号
- ⚠ **清理前必须先保护 `（　　）` 作答括号**——括号内部是全角空格、两侧是括号（非中文字符），会被「删多余空格」清成 `（）`，与后补的括号叠成 `（）（　　）`（2026-09-25 实测）
- **图片**：单图独立段落居中（宽 58~138mm 按图幅定）；多图并排用**无框表格**（第 1 行放图、第 2 行放图注）以保证图注对齐；**图注行须从题干行中剔除**，否则卷面重复出现一次
- **防跨页**：题干段/图片段/图注段/首个选项段设 `keep_with_next`，各段设 `keep_together`
- **答题卡**：题号列宽须 **≥9mm**（25 题排一行会挤到"11"折行成"1/1"）→ 建议 **17 题一行、分 3 段**；页脚插 `PAGE`/`NUMPAGES` 域
- **成卷后**必跑 `verify_paper_layout.py --docx`；需要目视分页时用 win32com 导 PDF 复核（`ExportAsFixedFormat`；⚠ 目标 PDF 已存在会报"文件为只读"，导出前先删旧文件；Word COM 首次调用常报"被呼叫方拒绝接收呼叫"，先 `taskkill /F /IM WINWORD.EXE` 再重试即通）
- ⚠ **一次性生成脚本不入 skill**：出完卷即从工作区删除（见「目录规范」）；要留版本走 git

### 3.2 选择题答案分布均衡（v4：自动诊断 + 方案）

**诊断**（每次出卷/体检自动打印）：答案分布快照、**≥3 题连续同项**告警、分布极差超 15% 时提示「偏斜」。

**取方案**：

```bash
python export_student_paper.py --清单 组卷清单.yaml --均衡选项
```

输出每题应设的 `选项序`：

```
[均衡] 建议对 3 题重排（在清单对应项下加「选项序」，答案自动换算）：
        第 13 题　C → A　选项序: [3, 2, 1, 4]
        第 17 题　D → A　选项序: [4, 2, 3, 1]
        第 20 题　A → B　选项序: [2, 1, 3, 4]
```

把方案写回清单（v1.12.0 起脚本原生支持，**答案自动换算**，题库原题不动）：

```yaml
- id: 2024河南中考-15
  选项序: [3, 1, 2, 4]        # 新 A/B/C/D 位依次放**原第** 3、1、2、4 项
```

- **均衡口径**：各字母题量尽量相等（余数补给当前较少的字母）、**尽量避免三连及以上同项**；已带 `选项序` 的题视为人工已定，不再改动
- 目标：10 题卷各 2-3 个、20 题卷各 5 个上下
- 来源括注沿用原卷来源，不因重排改变；解析里提到「故选 C」等文字需人工核对（脚本不改解析文字）
- 重排记录由脚本自动写入《命题说明》第五部分（见 §3.7）

### 3.3 一题多卷题的处理（v1.3.0）

- 题库内一题只存一份（主卷），`id` 多值表示"另被哪些卷收录"——**检索按主卷命中即可，不会因多卷收录而重复出题**
- 学生卷**来源标注按主卷**（如 `(2024·河南中考·8)`）；若想体现"本卷亦曾收录"，可在《命题说明》里备注"原题另见《别名卷名》"
- 别名题已归档到 `{vault}/.trash/`（库内 Obsidian 回收站），**不在检索与组卷范围内**；**要还原某卷完整卷面，按「本卷 id（别名）」直接取题**——`build_index()` 对 `id` 多值的**每一项都指向主卷文件**（`paperkit/paths.py`），别名即插即用，不必绕「主题 id」。`_重复题清单.md` 只在别名丢失时作对照兜底（2026-10-30 更正：原写法「按主题 id 取题」是绕路，实测别名 id 可直接命中）
- ⚠ **还原不会缺题，但会缺两样**：① **分值**——`_重复题清单.md` 自 2026-10-30 起记「本卷分值」列；此前生成的旧清单无此列，取到的是**主卷**分值，与原卷不同则须人工核（**旧清单的抢救办法**：合并时若分值有差异，脚本会在主卷题的「解析」里写 `分值 主题值→别名值`，据此反推）；② **原卷形态**——归档在 `.trash`（回收站），**清空即丢**（实测 `2018河南中考B卷` 的归档件已不存在），早期清单头部写的 `_归档/重复题/…` 路径亦早已作废。**原卷 PDF 存档仍是分值、版式、题序的最终依据**
- ⚠ **清单里只能放该卷的 id**：别名 id 与主卷 id 混用会出**两道一样的题**（实测：同时写 `2018河南中考B卷-20` 与 `2015河南中考-20` → 卷面 2 题同一道）

### 3.4 版式合规自检（v1.4.0 起，成卷必做）

```bash
python verify_paper_layout.py --docx "<成卷.docx>" --清单 <组卷清单.yaml>   # Word 卷：版式 + 表图完整性
python verify_paper_layout.py --docx "<成卷.docx>"        # 只查版式（不给清单则跳过 D1）
python verify_paper_layout.py --卷 <卷名>                  # 题库卷结构层：题号唯一（合卷跳号放行）/选项/图片/学生卷无答案
```

- **D1 表图完整性**（需 `--清单`）：按清单还原题库题目，数出「应有几张表、几张图」，与卷面实际数比对——**少了即 ✗ 不合规（退出码 1 阻断）**。起因：表格曾被当语法 `re.sub` 静默删掉，200 道表格题的表格在 Word 卷上消失，而字号/行距/图片类检查全部照常通过——**版式合规 ≠ 内容没丢**，本项专门堵这个口子

- **有「✗ 不合规」项不得交付**（退出码 1，可作流程阻断）；按输出的「修法」列修正后重跑
- **国标底线**（GB 40070-2021 §7，强制）：正文 ≥12pt、行空 ≥3.0mm、辅文 ≥9pt——采用值与条款对照见 `references/试卷排版规范.md` §七；⚠ **Word 默认单倍行距与 1.5 倍行距均不达标**，成卷必须显式设固定行距
- **页面尺寸两模式**（A4 打印／中考仿真 185×260mm 三折单页、版心 155mm）见 `references/试卷排版规范.md` §7.1；河南中考卷实物为一张 6 开纸三折双面印、共 6 页
- 调参项：`--正文最少字号/--辅文最少字号/--行空最少` 可覆盖国标默认阈值（非标纸张实测校准时用，正常成卷不动）；`--json` 机器可读输出
- 版式条款见 `references/试卷排版规范.md`（含**图文混排规范**：单图靠右/多图并排/图注/表格/主题框）；依据与实测见 `references/标准-试卷排版依据.md`；核验分工见 `references/试卷版式核验矩阵.md`
- 人工项（同一题不得跨页、图注不脱图、选项两项一行、卷头注意事项）需在 Word 分页预览中过一遍

### 3.5 答题卡（两种形态）

**① 独立文件**（默认，月考/期中期末）——版式照 2026.09.22 月考答题卡实物（A4 两页）：

- **页面**：A4；**装订区在上侧（姓名栏页眉处）**——姓名栏**页眉距顶 2mm（0.20 厘米）**，正文上边距 22mm（只比常规略大，避免多挤出一页）；左右对称 20 / 下 18，页脚距 12.7mm，版心 170mm
- **姓名栏在页眉**（页面最上方，**仅第 1 页**）：`姓名____　班级____　考场____　考号____`，居中，页眉距顶 2mm
  - ⚠ 页眉距顶 **2mm（0.20 厘米）** 为实测正合位置，**不必改代码**；要更靠下可在 WPS「页眉页脚 → 页眉上边距」调大
  - 上侧装订钉若压到字，说明该批次装订位置比常规更靠上，此时再回调页眉距（如 4~6mm）
  ⚠ **不能作正文段落**——那样第二页顶部直接就是学生作答区，装订时会被钉住/盖住（2026-09-25 用户实测反馈）
  实现：`different_first_page_header_footer = True` ＋ 写 `first_page_header`（`header` 留空）；⚠ 启用「首页不同」后**页脚也分首页/后续页**，两处都要写页码
- **正文卷头**：卷名 ＋「答　题　卡」两行，黑体 14pt 居中
- **选择题栏**：`一、选择题（每小题X分，共Y分）`（分值不统一时写 `共N小题，Y分`）＋**全框线表**`题号`／`答案` 两行，每行 10 题（首列 16mm、其余 14.4mm、行高 8.5mm），超 10 题自动续表
- **非选择题栏**：`二、非选择题（共Z分）` ＋ 逐题逐小问 `21．（1）`（小问号从题目正文自动提取）
- **留白按分值自动算**（约 2 分/行、**下限 2 行**，对齐参考卡「12 分题 ÷ 3 小问 = 每问 2 行」的实测密度）：优先取设问末尾的「（X分）」，取不齐则把**整题分值均分**给各小问；无小问的题（论述题等开放题型）按整题分值留白（下限 6 行）；`--答题卡行数 N`（N>0）可改为**固定行数**覆盖
- **同一题的若干小问尽量同页**（方便批改）：该题所有段落（含留白段）除末段外全部设「与下段同页」，整题放不下时**整体下移**——不会出现 `23．（1）` 留在上一页、`（2）（3）` 甩到下一页的情形
  ⚠ 代价：题前那页底部可能留白（实测 23 题整体移到第 2 页）；要压满版面可把 `--答题卡行数` 调小
- **页脚**：`历史答题卡　第 X 页　共 Y 页`
- ⚠ 实测 20 选择 ＋ 5 材料题（每题 6 分 3 小问）＝ **2 页**；某题答案特别长时用 `--答题卡行数 N` 固定行数

**② 卷末附加**（小测试/周测，v1.17.0）——`--答题卡位置 卷末`：不出独立文件，学生卷 docx **末尾分页后**接「附：答题卡」（简版标题＋正文姓名栏＋同样的题号/答案表与非选择留白）。注意：附卷末后卷面表格数会多于题目自身表格数，D1 校验会列「人工确认」项，属预期。

### 3.6 从成品卷反查组卷清单（v1.15.0）

**场景**：手上有已出的卷子，但**清单没留存**，要还原出可复用的清单。

```bash
python backtrace_paper.py --卷 成品卷.docx --报告            # 先看匹配报告
python backtrace_paper.py --卷 成品卷.docx --输出 清单.yaml   # 输出清单（可直接喂 export）
```

- **输入**：文字版 `.docx` / `.md` / 文字版 `.pdf`；**扫描件先走 MinerU 提取**再喂进来
- **`--带题号` 必加**：清单每项带 `序号`（＝原卷面题号）。成品卷难免有改编题匹配不上，缺了它清单就缺项，按顺序登记会把后面题号整体顶错
- **卷首注意事项自动剔除**：行首带数字编号的「1.本卷为选择题卷…／2.每小题只有…／3.答题前请…」会被当成第 1、2、3 题，**全卷题号顶偏**（实测 50 题的周测，真第 1 题落到第 4 段）；脚本已自动剔除并打印 `[读卷] 剔除卷首注意事项 N 行`。⚠ 不能改成「剔前 N 段」——第 3 段里可能同时含卷头行与真第 1 题的开头
- **自动切题**（三条都踩过坑）：① 题号须**严格递增**；② 遇大题标题（`一、选择题`）**重置为「等待任意题号」**——河南卷小题跨大题连续编号，非选择题从 21 起，置 0 会导致整块漏切；③ 剔**零宽字符**、并把**段内软换行**压成空格（docx 的 `<w:br/>` → `\n`，会让 `.*$` 类正则失配，实测第 8、11 题因此漏切）
- **匹配**：**题干 ＋ 选项综合**（0.6 题干 + 0.4 选项，选项顺序无关）——先按题干粗排取前 40 名，再补算选项相似度重排。表格题/材料题题干信息弱，靠选项能显著找回（实测第 18 题「据下表可知…」纯题干 0.23 → 加选项 0.52 命中）
- **自动检测选项重排**：成品选项与题库选项集合相同但顺序不同时，反推 `选项序: [原第几项…]`（实测准确还原出第 4 题）
- **交叉校验**：卷内含答案连排行时提取答案，与题库逐题比对，差异即提示（"被改过/重排过"）
- **低分题**（< `--阈值`，默认 0.45）**不写入清单**，只在报告里列候选 → 人工确认后补。**定性前先排除两种假阴性**：① 题面材料是**图/表**且文字未提取 → 卷面只剩设问，分数被拉低（实测 `2017河南中考-21` 仅 0.34，实为同题）；② 题干自带**外省出处括注**（`2023·青岛城阳九上期中·10`）→ 直接查题库有无该卷。两者排除后仍低分，才判「自编/改编题」
- 实测：逐题命中，与「用命题说明细目表还原」的路径结果完全一致（9/22 月考 25/25；2026-10-24 周测修卷首后 50/50）

### 3.7 命题说明

**产物**：一份**内部资料**《{卷名}_命题说明》，记录题目来源与考察角度，**不随试卷印发**。教师侧归档与教研材料用这一件，不再出「带答案的教师卷」。

```bash
python export_student_paper.py --清单 组卷清单.yaml --模式 命题说明 --输出 命题说明.md --docx 命题说明.docx
```

**结构**（固定五部分，元数据**全部从题库实时生成**，题目修订后重跑即同步）：

| 节 | 内容 | 数据来源 |
|:--|:--|:--|
| 一、试卷结构与命题思路 | 卷面结构／各部分比例（按单元配比表）／学科能力维度（郑林 9 要素，含兼涉口径）／难度与答案分布 | 清单 ＋ 题库字段统计 |
| 二、选择题命题细目 | 题号／考查课（兼涉标注）／考查角度／关键能力／难度／题目来源 | `课`／`知识点`／`关键能力`／`难度`／`来源`；角度可被清单 `角度` 覆盖 |
| 三、非选择题命题细目 | 题号／考查范围（跨册兼涉带册别）／考查角度／**设问与分值**／关键能力／难度／题目来源 | 同上 ＋ 正文小问解析 |
| 四、参考答案与评分标准 | 选择题答案连排（每行 10 项）＋ 非选择题逐题答案 | `答案` 字段（含选项序换算） |
| 五、组卷处理说明与待办 | 来源不标注说明／分值调整／**选项重排记录**／**答案分值核对提示**／图片题号／卷面版式 | 清单与题库差异自动比对 |

**要点**：

- **分值口径**：非选择题「设问与分值」优先用清单 `小问分值: [6,4,2]`；未给时，题库答案自带分值之和恰等于卷面分值才采信，否则按卷面分值均分（与答题卡留白同一口径）
- **跨册兼涉带册别**：如 `第3课 古代埃及（兼涉7上第9课）`，避免「第9课」歧义
- **答案分值核对提示**：题库答案文本自带的分值与本卷赋分不符时自动列出题号，提醒人工核对评分标准文字（脚本**不改**答案文字）
- **图片题**按题库正文自动列出；卷面上撤图/换图以卷面实际为准（脚本无法感知）
- 单元配比表的课时范围与涵盖课只取**主考课**（首项）——兼涉可能是跨册课，会污染范围
- 命题说明**不打包图片、不出答题卡**；`--卷`（兼容用法）不支持本模式，须用清单驱动

### 3.8 本校考试卷登记与出卷去重（v1.38.0）

**做什么**：卷子定版后，把「这次考试用过哪些题」记进题库——**不新增字段、不重复存题**，沿用「一题多卷」语义：卷面每题的 `id` 追加 `{卷名}-{卷面题号}`、`来源` 成对追加 `(卷名, 类型标签)`；同时在题库建卷目录，**只放 `_组卷清单.md`**。

```bash
# ① 登记（默认 dry-run，先看清单再 --apply）
python record_usage.py --清单 组卷清单.yaml --卷 2026-2027-7上月考1 \
                       --日期 2026-10-11 --范围 "7上第1-2单元" --满分 100 --时长 60 --apply
# ② 看这次用了哪些题
python record_usage.py --卷 2026-2027-7上月考1 --查题目
# ③ 出卷去重：本学年已用题
python record_usage.py --已用 2026-2027 --json
# ④ 撤销（题目 id/来源 复原、档案入库内回收站、空卷目录移除）
python record_usage.py --卷 2026-2027-7上月考1 --撤销 --apply
# ⑤ 体检（卷目录 ↔ 题目 id ↔ 档案题目表 三方一致）
python record_usage.py --体检
```

**卷名格式**：`{学年}-{年级册}{考试类型}{序号}`，如 `2026-2027-7上月考1`、`2026-2027-9上期中`、`2026-2027-7上课堂练习3`。年级册**必须写**（同一学年同时带 7 与 9 年级，缺它撞名）；类型词决定来源标签（`月考→月考卷`、`课堂练习→练习卷`、`专题→专题卷`…），无类型词的卷名直接拒绝。详见 `references/fields.md`「本校考试卷」。

**产物**（三处，各有分工）：

| 位置 | 内容 |
|---|---|
| 题目 frontmatter | `id: [主卷id, …, 2026-2027-7上月考1-01]`、`来源: [原出处, 原类型, 2026-2027-7上月考1, 月考卷]`——**首项主卷永不动**，其余字段与正文一字不改 |
| `{初中,高中}-3阶段测试/{卷名}/_组卷清单.md` | 卷面题号／题目 wikilink／题型／分值／主考课／难度；YAML 里 `题目: [主卷id…]` 供 Dataview 与体检读取 |
| `{vault}/.usage/YYYY-MM-DD.json` | 登记/撤销日志（含改动题目与备份路径） |

**与「一题多卷合并」的区别（别混）**：本校卷只产生**别名 id，不产生题目文件、不产生归档件**——`_` 前缀的清单不会被 `is_question_file` 判为题目，不参与 scan/检索/组卷/统计；`dedupe --check-authority` 遇「归档区找不到别名」按设计跳过，属正常，**不要去手工修**。撤销走 `record_usage.py --撤销`，不走 `dedupe --rollback`。

⚠ **一个例外——本卷兼作主卷**：本校原创题**首次入库**就放在本卷目录（`{卷名}_{题型}/{题号}.md`），此时该题 `id` 首项就是本卷（无需再追加别名），卷目录下同时存在题目文件与 `_组卷清单.md`。`--体检` 对此只报 `[兼作主卷]` **提示**、不算问题、不阻断（2026-10-24 首批 15 道原创题入库实证）。

**为什么不用新字段**：`id` 多值本就是「本题还被哪些卷收录」，本校考试就是一张卷；新增字段会与 `id` 语义重叠，且要连带改 `gen_problem --force` 的保留列表、`dedupe` 的并集字段、`edit_fields` 的白名单三处，风险大于收益（2026-10-24 用户裁定）。

**三条硬规矩**：

1. **`--apply` 只在卷子定版后跑一次**——`export_student_paper.py` 会被反复跑（试排版、改清单、md 出完再出 docx），登记不挂在它上面，避免留「中途删掉的题」的幽灵记录；改过卷面就 `--覆盖` 重跑一次（幂等，已登记的不重复追加）
2. **来源不成对时只追加 `id`**：脚本**不猜类型**，告警要求先补类型标签——猜错会把后续成对解析全部错位
3. **原创题首次入库的卷**：本卷同时是主卷（题目文件就在本卷目录）时，撤销会被硬阻断（会删掉主卷 id），须先迁移题目文件

**配合出卷**：§0 的「与近期卷去重」直接读 `--已用 <学年>` 的输出；候选清单里剔除这些主卷 id 即可，不必再靠用户口述。

手上有 `docx`／文字版 `pdf`、没有清单时，**两步**：先按 §3.6 反查生成清单（`--带题号` 必加），再登记。

## 4. 册别索引
**默认 MOC 模式 = 「混合式 MOC：手工骨架 + 动态查询」**：vault 的 `1-MoC-索引/` 下已有 7上/7下/8上/8下/9上/9下 六个试题索引，按教材逻辑（单元-课）半自动索引：

- **特征**：① 单元-课分组标题 = 手工静态骨架（与 BOOK_INDEX 词表一致，保留教材层级）；② 每课下题目 = Dataview 动态查询（新题自动流入已有课）；③ 新课需手动补一个标题+查询块（半自动）；④ 跨课/跨册题会同时出现在其命中的多个课块下
- 查询模板（⚠ DQL 无 CONTAINS 操作符，一律 `contains(字段, "值")` 函数 + 双引号参数）：
  ```dataview
  TABLE id AS 题号, 课, 知识点, 题型, 素养层次水平, 关键能力
  FROM "初中-1中考真题" OR "初中-2中考模拟题" OR "初中-3阶段测试"
  WHERE contains(册别, "7上") AND contains(课, "第X课 课名")
  SORT id ASC
  ```
- 索引由 `scripts/gen_index.py` 从 BOOK_INDEX 自动生成（词表更新后重跑即可重建）；此模式亦为全库 MOC 默认约定（见用户级记忆）
- **学史方法索引**：册索引末尾的 `## 学史方法` 单元节（由词表 `- 学史方法` 单元生成，每方法条目一个 Dataview 块、带 `contains(单元,"学史方法")` 限定）；另有 `1-MoC-索引/学史方法-试题索引.md` 按全六册 15 个方法组织（同属「混合式 MOC」模式：方法名手工骨架 + Dataview 筛选）

## 铁律（组卷专属）

1. **出题范围裁剪（按小问裁）**：用户限定范围（如「期中范围」「讲到第X课」）时，候选题按范围过滤；**跨范围题**（「课」/「单元」字段多值、涉及范围外单元或册别）按以下顺序处置——① **优先整题剔除**（换一道更贴范围的）；② 确需保留则**按小问裁剪**：只留范围覆盖的小问及其所依据材料，删去范围外小问与材料，**分值随之重算**（卷面总分须重新配平），卷面该题标「节选」。核心原则「**讲到哪儿考到哪儿**」，主要针对月考/期中考。
   - **判断哪一问在范围内**：逐小问看设问指向的课/单元——落在考查范围内的保留；题为跨课综合而设问只涉及范围外内容的小问整体删去。
   - **材料随小问走**：保留「材料 N」当且仅当被保留的小问需要它；「综合上述材料…」类设问若含有范围外材料，须一并核对可否缩为范围内的材料。
   - ⚠ **脚本不支持小问级裁剪**：`export_student_paper.py` 按整题渲染，清单无「小问」字段 → 卷面节选**只能人工**（圈定候选时即定好保留哪几问；出卷后如需微调则人工处理版面）。**题库原题一律不改**——节选只发生在卷面/报告等输出环节（同 `workflow/04 §6d`）。
2. **组卷标注题目来源**：学生卷中/高考题标来源，格式 `(年份·地区试卷·题号)`，如 `(2024·广东中考·1)`——**近 5 年中考题必标**，高考题**不限定年份**，凡引用原题均标注来源（完整规范见 `references/试卷排版规范.md` §十二：真题/模拟年份取考试发生年；**阶段测试按学年**，如 `（2024-2025学年·洛阳期末·4）`，与题目 id 卷名口径一致）
3. **答案分布均衡**：成卷前按 §3.2 检查（`--均衡选项` 直接给方案），答案集中或有三连同项则重排选项并同步改答案
4. **跨册材料题慎用**：题库多值课字段的跨册综合材料题，仅主题贴合本卷考查课时选用；设问指向外册内容的**裁去该小问**（同铁律 1 的按小问裁剪与分值重算），其材料随之删减

## 陷阱（组卷专属）

1. **导出文件勿入库**：`*_学生版.md`／`*_教师版.md`／`*_命题说明.md` 会污染 scan/collect（已自动排除）
2. **`--only` 题号 1 与 01 互通**：写 `1` 或 `01` 都能命中 `01.md`
3. **`_重复题清单.md` 不是题目**：按 `_` 前缀统一排除，不会被当题目拼进卷面
4. **答案/解析里也可能有图**：对「正文＋答案＋解析」整体改写——只改正文会让 `解析` 字段里的图跨卷断链
5. **跨卷输出必须显式 `--输出`**：脚本会拦（退出码 1），别试图写进某个来源卷目录——那会污染源卷的 `images/`
6. **成卷文本流里的两处「隐形字符」坑**（v1.12.0 实测）：① `（　　）` 作答括号内部是全角空格、两侧是括号，**清理空格前必须先整段保护**，否则被清成 `（）`、与后补的括号叠成 `（）（　　）`；② 图片若以占位符形式在文本流里传递，**只能用私有区字符**（如 `\ue001`），**不能用 `\x00`** —— Word XML 不接受 NUL，写 docx 时直接抛 `ValueError: ... no NULL bytes`
7. **重排选项不重写解析文字**：`选项序` 只改选项顺序与答案字母，解析里「故选 C」之类的字母指代不会跟着变，重排后需人工核对
