# 流程二 · 组卷/出题

> **触发词**：出题、组卷、出一套卷子、某个范围/某个知识点（用户说「某个范围/某个知识点」→ 检索，**不是还原原卷**）。
>
> **前置检查**：运行前确认已初始化——`<skill>/scripts/skill_config.json` 含有效 vault 或 `TNOTE_VAULT` 已设；**若脚本报「未配置题库库」→ 先读 `workflow/00-init.md`** 完成配置再继续。

```
检索题库 ──> 列出候选题（题号+题干预览+考点） ──> 用户决定选哪些 ──> export --only 出卷（md） / Word 成卷（编辑通道+排版规范）
```

> **成卷版式规范**：学生卷/教师卷的卷面版式（卷头/大题结构/选项断行/图片/答案卷/字体）一律遵循 `references/试卷排版规范.md`；题面信息标注（来源括注/分值括注/出处）格式见「历史原创命题」`language-specification.md` 第六节。

## 1. 检索

按 册别/单元/课/知识点/题型/难度/来源/年份 任意组合筛选：

- **Obsidian 内**：Bases/Dataview 查询（`TABLE 题干 FROM "历史题库" WHERE contains(册别, "8上") AND contains(知识点, "鸦片战争")`；册别/课/知识点均为多值 list，检索一律用 `contains(字段, "值")` 函数语法，参数必须双引号——⚠ Dataview DQL 没有 `CONTAINS` 操作符，字符串字面量只认双引号；操作符写法或单引号参数都会 PARSING FAILED）
- **命令行**：`python scan_questions.py --dump` 输出全量题目元数据（JSON 数组：id/册别/课/题型/难度/来源/年份/卷名/文件路径），按条件过滤

## 2. 列出候选

向用户展示 题号、题干（截断）、册别/课、题型/难度/分值，供用户圈定

## 3. 用户决定后出卷

**不重复生成原卷，只出用户选中的题**：

```bash
python export_student_paper.py --卷 <来源卷> --only 01,03,05 --模式 学生
python export_student_paper.py --卷 <来源卷> --only 01,03,05 --模式 教师
```

- `--only` 必须：组卷只导出用户选定的题号；不写 `--only` 会导出整卷（仅用于确认全卷场景，日常组卷不使用）
- 输出默认 `{卷目录}/{卷名}_学生版.md`（或 `_教师版.md`），图片打包到同级 `images/`；`--输出` 可指定其他位置，排序默认按题号（文件名），`--排序 路径` 可改
- 跨卷组卷：多卷分别 `--only` 导出后人工合并（export 一次只处理一个卷目录）

### 3.1 产出形态选择（md 卷 / Word 卷）

组卷产出按需二选一：

| 形态 | 场景 | 做法 |
|:---|:---|:---|
| **md 卷** | Obsidian 内使用/存档 | `export_student_paper.py` 学生/教师版（上述） |
| **Word 卷** | 打印/分发/考试用 | 以题库原题 md 为内容源，按《试卷排版规范》经本地 Office 编辑通道（tencent-local-office-edit / editor_sdk）成 `.docx`：`create_doc` → 分块 `doc_insert_markdown` → 题库 `images/` 原图 `doc_insert_image`（独立段落居中、宽≤440px）→ 标题/图片段落居中 → 答案分页另起 → `save_file` |

Word 成卷要点（细节全见《试卷排版规范》）：
- 卷头标题居中、大题"一、选择题/二、非选择题"、**小题跨大题连续编号**（河南通例）
- 选择题选项断行：短选项同行（全角空格×2 分隔）／长选项两两换行
- 材料出处 `——摘编自…`；外国作者加 `[日]`/`[美]` 前缀
- 图片逐张从原题 `images/` 取用，插入后补段落分隔符
- 教师卷参考答案分页另起
- ⚠ 实操血泪：editor_sdk 插入图片的 `idx` 是 DOC 坐标，**不可手算**——用上一步写操作的返回值或 `doc_get_last_operable_pos` 链式取位；插错可用 `doc_undo_ai_edit` 按 version 撤销（2026-09 实测）

### 3.2 选择题答案分布均衡（成卷前必检）

候选题答案集中于某一选项时，**重排部分题目选项顺序**（正确项换位、干扰项平移），使 A/B/C/D 大致均衡（10 题卷各 2-3 个）：
- 重排选项**必须同步更新该题答案**（题库原 md 不动，仅在卷内重排）
- 学生卷与教师卷使用同一重排后版本
- 来源括注沿用原卷来源，不因重排改变

## 4. 册别索引

**默认 MOC 模式 = 「混合式 MOC：手工骨架 + 动态查询」**：vault 的 `1-MoC-索引/` 下已有 7上/7下/8上/8下/9上/9下 六个试题索引，按教材逻辑（单元-课）半自动索引：

- **特征**：① 单元-课分组标题 = 手工静态骨架（与 BOOK_INDEX 词表一致，保留教材层级）；② 每课下题目 = Dataview 动态查询（新题自动流入已有课）；③ 新课需手动补一个标题+查询块（半自动）；④ 跨课/跨册题会同时出现在其命中的多个课块下
- 查询模板（⚠ DQL 无 CONTAINS 操作符，一律 `contains(字段, "值")` 函数 + 双引号参数）：
  ```dataview
  TABLE id AS 题号, 课, 知识点, 题型, 素养层次水平, 关键能力
  FROM "初中-1中考真题" OR "初中-2中考模拟题" OR "初中-3阶段测试"
  WHERE contains(册别, "7上") AND contains(课, "第X课 课名")
  SORT id ASC
  ```
- 索引由 `scripts/gen_index.py` 从 BOOK_INDEX 自动生成（词表更新后重跑即可重建）；此模式亦为全库 MOC 默认约定（见用户级记忆）
- **学史方法索引**：`1-MoC-索引/学史方法-试题索引.md` 按全六册 15 个学史方法组织（同属「混合式 MOC」模式：方法名手工骨架 + Dataview 按小节/课筛选）

## 铁律（组卷专属）

1. **出题范围裁剪**：用户限定范围（如「期中范围」「讲到第X课」）时，候选题按范围过滤；题目（含材料题设问）涉及范围外内容的，**裁剪超范围部分或整题剔除**——核心原则「**讲到哪儿考到哪儿**」，主要针对月考/期中考
2. **组卷标注题目来源**：学生卷中/高考题标来源，格式 `(年份·地区试卷·题号)`，如 `(2024·广东中考·1)`——**近 5 年中考题必标**，高考题**不限定年份**，凡引用原题均标注来源（完整标注规范见「历史原创命题」`language-specification.md` 第六节：年份取考试发生年、期末卷按学年末考年等）
3. **答案分布均衡**：成卷前按 §3.2 检查，答案集中则重排选项并同步改答案
4. **跨册材料题慎用**：题库多值课字段的跨册综合材料题，仅主题贴合本卷考查课时选用，设问指向外册内容可裁小题

## 陷阱（组卷专属，血泪）

1. **导出文件勿入库**：`*_学生版.md`/`*_教师版.md` 会污染 scan/collect（已自动排除）
