# 素养/层次水平/能力词表（题库标注受控词表）

> **来源与理论依据**：本词表依据《义务教育历史课程标准（2022年版）》与《普通高中历史课程标准（2017年版2020年修订）》的学科核心素养体系，及郑林「历史学科能力 3 层次 9 要素」（A1-C3）、徐奉先 3×3 能力框架整理；条目为标注实践用的受控词表，供题库建设者参考使用。
>
> 题库 YAML 三个多值字段（list）：`核心素养` / `素养层次水平` / `关键能力`，均可多值标注。
> 标签格式：
>
> - 素养：`素养-细分条目`（如 `史料实证-史料信息的提取`）
> - 层次/水平：`素养名称-层次N-具体体现`（初中）／`素养名称-水平N-具体体现`（高中）
> - 能力：`关键能力-编号要素`（郑林 9 要素，如 `B2-分析`）
>
> ⚠ **注记标记**：条目行中 `⟦…⟧` 内为来源说明/示例/归口注记（如 `⟦据课标点1①⟧`、`⟦如疆域⟧`、`⟦总结⟧`、`⟦如岳飞抗金…⟧`），仅作条目语义、来源与归口依据的参考；**录入题库 YAML 时只取 `⟦` 之前的内容本身，注记不写入属性信息**（规则详见「二（三）标注规则」）。

## 二、素养层次水平

> 初高中**不跨学段换算**：初中按学业质量三层次标「层次 1-3」，高中按课标素养水平划分标「水平 1-4」。
>
> 取值格式：`素养名称-层次N-具体体现`（初中）／`素养名称-水平N-具体体现`（高中），体现短语从本词表摘录或按题总结。
>
> 体现短语除课标原文摘录外，个别为按内涵总结（条目中标 `⟦总结⟧`）；**初中**史料实证层次2/3 无课标直接表述，按材料运用内涵总结；**高中**史料实证水平2/3 已据附录素养水平划分有明确表述（非总结）。

### （一）初中·素养层次词表（依据义教课标·学业质量三层次）

#### 层次1 掌握重要史事
- 时空观念-层次1-识读历史地图、将重要史事置于正确时空
- 时空观念-层次1-运用记录历史年代的基本方式记录与定位史事 ⟦据课标点1①⟧
- 史料实证-层次1-理解并辨识实物/文献/图像/口述等可信史料的含义
- 历史解释-层次1-运用史料对重要史事简要说明、有理有据表达看法
- 家国情怀-层次1-表现出正确的价值判断和人文情怀
- 唯物史观-层次1-从物质生产是基础、生产力与生产关系、人民群众创造历史等理解史事意义，运用唯物史观作出合理的解释与简要评价 ⟦原「历史解释-层次1-运用唯物史观…」归口于此，避免双标⟧

#### 层次2 了解各种联系
> 本层次对应学业质量「了解各种联系」，含四种重要联系——(1)古今联系 (2)不同史事的因果联系 (3)不同领域的横向联系 (4)中国与世界的联系；标注时优先据此判断属层次2。
- 时空观念-层次2-从古今联系与变化的角度论述史事 ⟦如疆域⟧
- 史料实证-层次2-依据多则材料分析史事的原因与联系 ⟦无课标直接表述，按材料运用内涵总结⟧
- 唯物史观-层次2-初步分析生产力对政治经济文化的推动、阶级斗争是历史发展动力
- 历史解释-层次2-解释一定时空条件下政治、经济、文化间的相互关系与影响
- 历史解释-层次2-分析近代中国半殖民地半封建社会的内外因、理解民族独立与人民解放是历史任务
- 家国情怀-层次2-感悟五四精神、伟大建党精神、抗战精神等
- 家国情怀-层次2-认识捍卫国家主权和民族尊严是中华民族的优良传统 ⟦据点2(4)中外联系⟧
- 家国情怀-层次2-感悟先贤英雄精神 ⟦如岳飞抗金、文天祥，情感层面；推断·非原文直引⟧

#### 层次3 认识基本规律与大趋势
- 时空观念-层次3-了解世界历史形成过程、初步具有国际视野和全球意识
- 史料实证-层次3-运用史实材料认识历史发展规律与意义 ⟦无课标直接表述，按材料运用内涵总结⟧
- 唯物史观-层次3-简要说明时代特征、了解人类社会从低级到高级发展历程
- 唯物史观-层次3-把握中外发展线索与规律，了解人类社会从分散到整体发展历程 ⟦据点3世界史例⟧
- 唯物史观-层次3-初步理解和平、发展、合作、共赢是不可阻挡的历史潮流
- 历史解释-层次3-在叙述中体现历史发展的基本线索与规律
- 历史解释-层次3-知道资本主义、社会主义和殖民地半殖民地民族解放运动的发展，了解世界历史形成的基本线索 ⟦据点3世界史例⟧
- 家国情怀-层次3-了解统一多民族国家巩固发展意义、认同中华民族多元一体 ⟦认知层面⟧
- 家国情怀-层次3-坚定四个自信、认同社会主义核心价值观、铸牢中华民族共同体意识
- 家国情怀-层次3-增进爱祖国爱家乡的情感
- 家国情怀-层次3-树立人类命运共同体意识
- 家国情怀-层次3-了解世界文明的多元性、差异性及其发展的不平衡性 ⟦据点3世界史例；世界史视野下的文明认知⟧

### （二）高中·素养水平词表（依据课标·学业质量描述）

> 高中学业质量描述按水平 1-4 综合表述（每条含多素养组合，比附录「素养水平划分」更详细），本词表按水平组织、拆分为各素养的具体体现标签；学业质量应用：**水平 2 为毕业应达（合格考标准），水平 4 为等级考最高参照**。

#### 水平1
- 时空观念-水平1-判断具体史事与相关史料发生的时间、空间 ⟦据附录水平1⟧
- 时空观念-水平1-辨识不同的时间与空间表达方式并理解其意义
- 史料实证-水平1-说明给定史料的类型和价值，提炼与之关联的事件、人物、现象等历史要素；知道史料与历史叙述的区别，了解史料的基本类型及分类方法 ⟦据附录水平1⟧
- 历史解释-水平1-运用所给史料说明历史问题，做到观点和材料的统一
- 历史解释-水平1-运用历史术语叙述历史演进的基本过程及人类创造的文明成果
- 历史解释-水平1-辨别教材和教学中的历史解释、概述历史发展基本进程 ⟦据附录水平1⟧
- 唯物史观-水平1-运用唯物史观基本观点和方法，体现对唯物史观主要内容的基本了解与科学性认知
- 家国情怀-水平1-举出认同家乡、民族、国家的事例，简要说明中华民族多元一体的发展进程及意义
- 家国情怀-水平1-举出世界历史发展的多样性事例，了解各国、各地区、各民族文化传统

#### 水平2
- 时空观念-水平2-综合判断多则史料所反映史事的时间、空间及特征；
- 时空观念-水平2-借助历史年表、历史地图描述史事，认识事物来龙去脉，理解空间和环境因素对认识历史与现实的重要性 ⟦据附录水平2⟧
- 史料实证-水平2-辨别史料类型并说明各自价值，明了史料间的相互关联，提炼关键信息
- 史料实证-水平2-运用历史资料制作历史图表
- 史料实证-水平2-从史料中提取有关的历史信息 ⟦据附录水平2⟧
- 历史解释-水平2-运用史料描述、解释相关历史现象及规律，说明史事间的联系，关照现实问题
- 唯物史观-水平2-运用唯物史观基本观点和方法，体现对唯物史观是科学历史观的初步理解
- 家国情怀-水平2-把握具体史事蕴含的社会主义先进文化、革命文化和中华优秀传统文化要素，表达对中华民族共同体的认同
- 家国情怀-水平2-运用世界历史发展事例说明文化传统多样性，尊重不同国家、地区、民族文化传统

#### 水平3
- 时空观念-水平3-综合判断复杂史事的时空特征及变化，建立较长时段、多个史事间的时空联系
- 史料实证-水平3-对史料进行整理并规范使用
- 史料实证-水平3-综合运用多则史料作为证据，对较长时段、较大空间、较复杂的历史现象进行概括
- 史料实证-水平3-从多种渠道获取史料、选择相关史料探究历史问题 ⟦据附录水平3⟧
- 历史解释-水平3-从来源、性质、目的等多维度评析复杂历史现象
- 唯物史观-水平3-运用唯物史观说明、论述历史的发展变化和社会形态演变的基本规律
- 家国情怀-水平3-把握社会主义先进文化、革命文化和中华优秀传统文化的历史价值和现实意义，了解中华文明的五个突出特性
- 家国情怀-水平3-全面、客观地分析历史和现实社会问题，具有构建人类命运共同体意识
- 家国情怀-水平3-从历史中汲取经验教训，形成正确的历史观、国家观、民族观、文化观 ⟦据附录水平3-4⟧

#### 水平4
- 史料实证-水平4-对不同来源、不同观点的史料进行比较、分析与互证，辨析史料作者意图，判定史料内容的真实性及价值
- 时空观念-水平4-有意识地运用时空框架、选择恰当时空尺度，对历史和现实问题进行独立的分析、比较、综合、探究
- 史料实证-水平4-运用多种资源和方法搜集史料并恰当取舍，综合运用多学科知识解决历史问题
- 唯物史观-水平4-运用唯物史观说明、分析历史的发展变化和社会形态演变的基本规律，实事求是地论述与探究历史与现实问题
- 家国情怀-水平4-把握社会主义先进文化、革命文化和中华优秀传统文化的内涵，说明社会主义核心价值观的历史依据
- 家国情怀-水平4-铸牢中华民族共同体意识，体现四个自信，树立构建人类命运共同体意识
- 历史解释-水平4-在独立探究中验证以往说法或提出新解释、将历史知识与其他学科知识联系 ⟦据附录历史解释水平4⟧

### （三）标注规则

- 字段名：`素养层次水平`（list，可多值）
- 取值格式：`素养名称-层次N-具体体现`（初中）／`素养名称-水平N-具体体现`（高中）
- 初中题标层次（1-3），高中题标水平（1-4）；**不跨学段换算**
- 一道题可多值（多素养、或同素养跨层次/水平）
- 高中题按学业质量水平 1-4 标注；附录素养水平划分的合并档（唯物史观/家国情怀 水平1-2、3-4）仅作判据参考，不直接作标签
- 体现短语：优先从本词表摘录；词表未覆盖时按设问从课标内涵中总结
- **注记剔除（2026-08-24 起）**：词表条目中 `⟦…⟧` 内为来源说明与注记（归口注、总结、如疆域、如岳飞、据课标点/附录、据点N 等），仅作条目语义、来源与归口依据的参考；**录入题库 YAML 时只写 `⟦` 之前的内容本身**，注记一律不写入 `素养层次水平` 等属性信息
- **判定锚点（怎么判层次/水平）**：
  - 初中：层次1＝将史事置于正确时空、辨识/简要说明史料（掌握史事）；层次2＝建立古今/因果/横向/中外「联系」（了解联系）；层次3＝概括时代特征、把握线索规律、认同共同体与人类命运共同体（认识规律与大趋势）。
  - 高中：水平1＝单则史料/单史事的判断与叙述；水平2＝多则史料综合判断、解释现象与联系；水平3＝复杂史事较长时段的概括与多维度评析；水平4＝独立探究、比较互证、跨学科论述。

## 三、关键能力：郑林「三层次九要素」（主词表）

> 主词表采用郑林教授《中学生历史学科能力构成及表现研究》（《课程·教材·教法》2017 年第 8 期）三层次九要素体系。
>
> 徐奉先 3×3（源自高考评价体系）保留为对照与迁移映射，不再用于新标注。

### (一) 郑林三层次九要素（A1-C3）

| 层次 | 编号 | 要素 | 能力指向（操作动词） |
| --- | --- | --- | --- |
| A 学习理解 | A1 | 识记 | 再认再现已学历史知识 |
| | A2 | 说明 | 历史名词与史实对应、历史观点与其证据对应 |
| | A3 | 概括 | 从文字/图片/视频等材料提炼要点、归纳史实本质与阶段特征 |
| B 实践应用 | B1 | 比较 | 纵比延续与变化、横比异同、比较对同一史实的不同看法 |
| | B2 | 分析 | 原因探究、影响推断、目的判断 |
| | B3 | 评价 | 定位人物/事件/制度的地位、评析不同观点 |
| C 创新迁移 | C1 | 建构 | 从零散素材中选取材料，按时序与因果关系完整叙述历史过程 |
| | C2 | 考证 | 鉴别史料可信度与适用性、选取可靠证据证明史事或论证观点 |
| | C3 | 探究 | 发现并表述历史问题、运用史实与理论解答、从历史视角解释现实 |

## 四、与题库字段的对应

- 题库 YAML 三个多值字段（list）：
  - `核心素养`: `[素养-细分条目]`，如 `[史料实证-史料信息的提取, 历史解释-史事的因果性阐释]`
  - `素养层次水平`: `[素养名称-层次N-体现]`（初中）或 `[素养名称-水平N-体现]`（高中），如 `[史料实证-层次2-从史料中提取历史信息]`
  - `关键能力`: `[编号-要素]`（郑林 9 要素），如 `[A3-概括, B2-分析]`
- 检索：
  - 按层次/水平筛题：`素养层次水平 CONTAINS "层次2"` 或 `CONTAINS "水平3"`
  - 组合筛选：`核心素养 CONTAINS "史料实证" AND 素养层次水平 CONTAINS "层次2"`
  - 能力检索：按编号 `关键能力 CONTAINS "B2"` 或按层次 `关键能力 CONTAINS "B"`（如筛「实践应用」级全部题）
- 说明：素养回答「考什么」，层次/水平回答「考到哪一层」（初高中分轨），能力回答「怎么考」，各维正交；关键能力主词表为郑林 9 要素，徐奉先 3×3 见第三章对照，存量旧标注按迁移映射换算。
