# 字段详解与 JSON 模板

## 目录规则

```
{vault}/{学段}-{序号类别}/{卷名}/{卷名}_{题型}/{序号}.md
示例：{vault}/初中-1中考真题/2026河南中考/2026河南中考_选择题/01.md
```
（`{vault}` = `TNOTE_VAULT` 环境变量指向的题库库根，见 SKILL.md「初始化」）

- 学段-类别（vault 根目录，**原创/改编不占目录**）：
  - 初中：`初中-1中考真题` / `初中-2中考模拟题` / `初中-3阶段测试`
  - 高中：`高中-1高考真题` / `高中-2高考模拟题` / `高中-3阶段测试`
  - 案例学习：`4-案例学习`（论文/著作收录的典型试题；非卷类，故用功能目录序号体例，见下方「案例学习类」）
- 卷名：如 `2026河南中考`；题型子目录：`{卷名}_{题型}`
- **序号 = 原卷面题号**（不重编、不按录入先后临时编号），两位补零：
  - 单科卷题号 1~N 连续 → `01.md`…`25.md`
  - **合卷题号跳跃属正常**——如高考文综合卷历史部分：选择题 24~35、非选择题 41~47（41~43 为三选一）。直接按原题号落 `24.md`…`47.md`，**缺号 36~40 无需补空文件、也不要改成连续号**；同理其他合卷（理综/文综、联考合卷、分卷合订）一律以卷面题号为准
  - 题号 ≥100 按实际位数（`100.md`），不截断、不补零
  - **补零的必要性**：`gen_index.py` 用 `SORT file.name ASC` 字符串排序，不补零会出现 `1,10,11,2` 乱序；故 `1` 一律写作 `01`，`41` 保持 `41`
  - ⚠ **与组卷导出无关**：序号只用于溯源与定位，导出成品卷时按清单顺序自动重编 `1．2．…`（见 `workflow/02-compose.md` §3）
  - ⚠ **与卷名内卷次无关**：卷名里的 `…模拟卷1` 是卷次，纯数字不加前导零，两处勿混
- id 自动生成：`{来源首标签}-{序号}`（如 `2026河南中考-01`；高考文综合卷如 `2025全国甲卷-41`）——**id 末段的序号同样是原卷题号**

## 卷名命名约定（避免每次询问）

**阶段测试**（分类至 `初中-3阶段测试` / `高中-3阶段测试`）：

```
{地点}{学年}学年{X}{上|下}学期{月考|期中|期末}
```
- 地点：省/市/区/县/校名（`郑州市` / `河南省信阳市浉河区` / `河南省实验中学` / `河南省镇平县`）
- 学年：`YYYY-YYYY` 单连字符（推荐） 或 `YYYY--YYYY` 双连字符（历史数据兼容）
- 年级：**必须使用数字简写**（`7`/`8`/`9`）
- 后缀（文件名，非目录）：学科 + 版本 + 答案标识（例：`7上期末历史试题`）
- 完整示例：
  - `郑州市2021-2022学年7上期末`
  - `河南省实验中学2025-2026学年7下期末`

**中高考（含模拟）**（分类至 `*-1中考真题/高考真题` 或 `*-2中考模拟题/高考模拟题`）：
```
{地域}{年份}{中考|高考}[几模|联考名]
```
- 地域：`河南` / `洛阳` / `全国` 等
- 年份：4 位（`2026`）
- 类型：`中考` / `高考`，模拟标 `一模`/`二模`/`三模`，联考用联考名（`金太阳联考`/`华大新高考联盟`）
- 完整示例：
  - `2026河南中考`（真题）
  - `2026洛阳一模`（一模）
  - `2026衡水金卷联考`
  - `2025新课标II卷`

**教辅卷**（出自教辅/作业本/复习资料的成套试卷；分类至 `初中-2中考模拟题` / `高中-2高考模拟题`）：

```
{年份}{教辅简称}{地域版}{中考|高考}模拟{n}
```

- **年份**：取**卷面适用年份**（教辅标「2026版」即写 `2026`），不写版次、印次
- **教辅简称**：固定用下方简称表，不写全名、不加书名号；表外教辅**先登记简称再录入**
- **地域版**：仅当该教辅有明确专版时写（如 `河南`）；通用版省略
- **卷次**：**纯数字、不加前导零**（`1`、`2`…`10`），不用 `01` / `（一）`。⚠ 这是**卷名内的卷次**，与题目文件名序号（**＝原卷面题号、两位补零**，如 `01`~`25`，合卷可为 `41`／跳跃不连续）是两回事，勿混
- **来源标签**：类型标签沿用受控值 `模拟卷`（如 `["2026万唯河南模拟卷1", "模拟卷"]`），不另设「教辅卷」标签
- 完整示例：
  - `2026万唯河南模拟卷1`（万唯·河南专版，中考模拟第 1 套）
  - `2026天利38套高考模拟卷3`（天利38套，高考模拟第 3 套）
  - `2026金考卷中考模拟卷2`

**教辅简称表**（新增教辅先登记再录入）：

| 简称 | 对应教辅 | 备注 |
|---|---|---|
| 万唯 | 万唯中考试题研究、黑白卷等万唯系列 | |
| 五三 | 五年中考三年模拟 / 五年高考三年模拟 | |
| 必刷题 | 中考必刷题 / 高考必刷题 | |
| 一遍过 | 一遍过（同步、复习） | |
| 天利38套 | 天利38套 | |
| 金考卷 | 金考卷（特快专递、百校联盟等） | |
| 基础性作业 | 河南省义务教育阶段基础性作业 | **同步类**，单元/课时卷见下注 |
| 课时练 | 课时练（同步练习册） | **同步类**，单元/课时卷见下注 |
| 解析与检测 | 河南省中考《解析与检测》 | 分册成套卷见下方「分册成套卷」变体 |

**分册成套卷变体**（教辅按「册」分册发行、每册内含多套综合检测卷时）：

```
{地域}{教辅简称}{年份}历史{上册|下册} 综合检测卷{n}
```

- 适用：《解析与检测》等教辅分「上/下」两册发行，每册含 N 套「综合检测卷」的场景（**与 `…模拟{n}` 主格式并存**）
- **地域前置**：地名提到最前（`河南解析与检测…`），不加书名号
- **学科词**：历史学科须带 `历史`（与教辅名连写，无分隔）
- **册别词**：用 `上册` / `下册`（不用 `上` / `下`）
- **主体词**：用卷面原词 `综合检测卷`（不用 `模拟卷`），**卷名前与册别词之间有一空格**
- **卷次**：紧随 `综合检测卷`，**纯数字不加前导零**
- 完整示例：
  - `河南解析与检测2026历史上册 综合检测卷1`
  - `河南解析与检测2026历史下册 综合检测卷8`
- ⚠ **一册多卷时卷名逐套独立**：每套建独立卷目录（`…综合检测卷1`、`…综合检测卷2`），**不合并为 `卷1、2`**；同日录入同册多卷时尤为注意
- 归类：`初中-2中考模拟题`（模拟卷性质）

> ⚠ **同步类教辅**（基础性作业、课时练）多为单元卷、课时卷而非整套模拟卷：若录入的是**单元/课时检测**，卷名按阶段测试惯例写 `{教辅简称}{学年}{X上|下}{单元|期中|期末}`（如 `基础性作业2026-2027学年7上第1单元`）并归 `3阶段测试`；若录入的是其成规模的**模拟卷、专题复习卷**，仍用上方 `{年份}{教辅简称}…模拟{n}` 格式归 `2*模拟题`。

> 命名遵循上图示例。录入卷子时若用户给原始文件名 → 按上规范提炼为卷名（去扩展名、去学科后缀、去版本号、去答案标识），保留地点/学年/年级/学期/考试类型/类型标识等核心字段。来源标签第一项=卷名。

**案例学习类**（论文／著作／讲座等收录的、有典型学习与借鉴价值的试题；分类至 `4-案例学习`）：

```
{年份}{作者名}{主题}
```

- **适用**：非考卷来源、以「示范命题思路／体现某教学理念」为目的被收录的案例题（如某学者论文中的原创项目式命题、著作中的教学设计示例）。与考卷（真题/模拟/阶段测试）**性质不同**，故独立成类，不占学段卷目录
- **序号前缀**：目录用**功能目录序号体例**（`4-`），与 `0-Template-模板 / 1-MoC-索引 / 2-命题与评价 / 3-试题研究` 同列（这些也是非卷类的功能目录）；⚠ 不写成 `学段-N` 的卷类体例
- **卷名**：`{年份}{作者名}{主题}`——年份 4 位、作者名用**真实姓名全名**（如 `黄牧航`）、主题为命题所依托的学术主题或题组名（如 `项目式命题`）；不加书名号、不加学科后缀
- **题型子目录**：按该案例内的题型分（`{卷名}_{题型}`），与普通卷一致
- **来源标签**：第一项＝卷名；**类型标签固定用 `案例题`**（新增受控值，区别于真题/模拟卷/原创题）
- **考区**：固定 `案例`（**无地域属性，不参与按考区分组、不计入地域饼图**）
- **册别归属**：按题目**实际册别**标（如纲要上/纲要下），**不因「案例」而跳过定位字段**——册别/单元/课仍按常规三字段标注铁律执行
- **跨册案例**：同一案例卷可跨册（如同时含纲要上、纲要下题），册别字段按题标全，遍历时不需归到单一学段目录
- **展示口径**：题库总览「收录试卷清单」中独立成组（`案例学习（学术/论文收录）`），按题目实际册别判断归左（初中）/右（高中）栏；**该组不细分考区**（考区恒为 `案例`，再细分只会多一层同义小标题），直接以「卷类名 + 卷名」平铺，实现上置于总览 `FLAT_GROUPS` 集合
- 完整示例：
  - `2026黄牧航项目式命题`（黄牧航论文收录的项目式命题案例，含小论文/综合探究题两组）
- ⚠ **与「原创题」区分**：`原创题` 是教师自己命制、投放在常规卷目录里靠来源标签区分的题（见上方「来源标签规范」）；`案例题` 是**被外部论文/著作收录、具有示范意义**的他人试题，独立成目录 `4-案例学习`

**来源标签规范**：
- 出处标签（自由）：卷名/教材课名，如 `2026河南中考`、`2025洛阳一模`、`8上教材第1课`
- 类型标签（建议受控）：`真题 / 教材改编 / 中考改编 / 原创题 / 期末卷 / 期中卷 / 月考卷 / 模拟卷 / 案例题`
- **阶段测试卷按实际考试类型标注**：期中卷 → `期中卷`，月考卷 → `月考卷`，期末卷 → `期末卷`——不得一律沿用 `期末卷`
- 示例：真题卷 `["2026河南中考", "真题"]`；教材改编（含中考题改编自教材）`["8上教材第1课", "教材改编"]`；中考改编 `["2024江西卷", "中考改编"]`；原创 `["2026原创", "原创题"]`
- 原创/改编题**不建独立文件夹**（无「原创命题/模拟卷」目录），放在对应学段-类别卷目录或新建卷名下，靠来源标签区分
- **一题多卷（多卷收录同一题）**：成对平铺，卷名与类型交替出现，首对为主卷所在卷；追加由 `dedupe_questions.py --merge` 自动完成，不手工拼
  - 示例：`["2024河南中考", "真题", "河南省实验中学2025-2026学年8上期末", "期末卷"]`

**考区标注规范**（2026-09-27 起；2026-10-24 修订全国卷口径；铁律：**考区与卷名一致**——以卷名可辨识的地域为准，同库同类卷口径统一）：

- 卷名含省名 → 标省：`河南` / `海南` / `山东` / `广东`…
- 卷名含市名 → 标市：`洛阳` / `郑州` / `开封` / `新乡` / `南阳` / `驻马店` / `安阳`…（⚠ 同为市级模拟卷，不得有的标省有的标市）
- 区级卷 → 标**所属市**：涧西区/洛龙区→`洛阳`；驿城区→`驻马店`；宛城区→`南阳`；经开区/二七区→`郑州`
- **学校卷按学校所在市标**，不因校名含省名而标省（如「河南省实验中学2026年中考二模」→ `郑州`）
- 省级教辅 / 省级联盟卷 → 标省（`河南解析与检测…`、`中原名校联盟…`→ `河南`）
- **全国卷 → 适用省份多值**（2026-10-24 起，**不再写 `全国`**）：写该卷**当年实际适用**的全部省级行政区，流式单行
  - 示例：某年Ⅱ卷 → `[山西, 内蒙古, 吉林, 黑龙江, 安徽, 江西, 河南, 陕西, 甘肃, 青海, 宁夏, 新疆]`
  - **排序口径：按行政区划代码升序**（北京 11 … 新疆 65），不按网页／资料原序——便于比对去重、便于肉眼查漏
  - **逐年会变，须按当年实际（两处已实测）**：**西藏 2017 用Ⅱ卷、2018 起用Ⅲ卷**；**山东 2019 用Ⅰ卷、2020 起退出（转新高考）**
  - 一题多省是「**同一适用面**」而非「多卷收录」——`id` 与 `来源` 都不因多省而变，**只改 `考区` 一个字段**
  - 统计口径连带变化：多值按数组展开、**每省各计一次** ⇒ 考区分布饼图**合计大于题目总数**（全国卷被按省数重复计入，属预期，勿当数据错误）
- **多省联考卷（卷名本身就是省份简写，如 `2026黑吉辽蒙高考`、`2025陕晋宁青高考`）→ 与全国卷同法：展开为省份多值**（2026-10-24 起，**不再写简写**）
  - `黑吉辽蒙` → `[内蒙古, 辽宁, 吉林, 黑龙江]`（行政区划码 15／21／22／23）
  - `陕晋宁青` → `[山西, 陕西, 青海, 宁夏]`（14／61／63／64）
  - 与全国卷同一逻辑：一题多省＝「**同一适用面**」，`id`／`来源` 不动，只改 `考区`；仍按行政区划代码升序
  - **看板归组需登记**：`1-MoC-索引/题库总览.md` 与 `题库总览-初中.md` 的 `volArea` 维护 `MULTI_AREA_VOLS = ["全国", "黑吉辽蒙", "陕晋宁青"]`，卷名命中者整卷归该名——否则多值展平后各省频次相同，**众数平票会把整卷拆进某一省小节**。**新增多省卷（新简写）时必须在该名单登记**
- 原创 / 项目式题 → `原创`（无地域属性，不参与按考区分组）
- **论文/著作收录的案例题 → `案例`**（无地域属性，不参与按考区分组、不计入地域饼图；目录归 `4-案例学习`，来源类型标签用 `案例题`）

> 题干 + 选项：选择题两者都填（脚本拼 `题干\n(A)… (B)…`）；材料题只填题干（含材料与设问，多行用 `\n`）。
> 必填校验字段（REQUIRED_FIELDS）：id/册别/单元/课/题型/难度/分值/来源/年份/考区/答案。
>
> * 题干不在必填字段内（选择题可只有选项），但**正文非空由 scan 校验兜底**——材料题必须填题干，否则生成的文件正文为空会被 scan 检出。
>
> **多值字段说明（2026-08-22 起；2026-09-14 修订为「多值优先」）**：`册别/单元/课` 与 `小节/知识点/核心素养/素养层次水平/关键能力` 均为 list，可多值。
>
> **铁律：定位三字段（册别/单元/课）多值优先**——综合性命题下「一课对一题」是例外而非常态，凡材料、情境、选项涉及的课都应标全（**不设项数上限**，按实际涉及写全），顺序为：
>
> 1. **首项＝命题落点**（设问直接考查的那一课，唯一必填，写在最前）
> 2. 其后依次为**兼涉项**（作为背景、参照、结论落点被调用的课）
>
> 三项（册别/单元/课）**同序平铺**：第 n 项课对应第 n 项单元（同册多课时册别不必重复）。
>
> **录入判据（逐题三问）**：
>
> | 问 | 落笔 |
> |---|---|
> | ① 设问**直接考**的是哪一课？ | 该课＝首项（命题落点） |
> | ② **材料/设问**还落在哪些课？ | 依次作兼涉项 |
> | ③ 跨册了吗？ | 跨了就写全册别，三项同序 |
>
> **防滥约束**：兼涉项必须在**材料或设问**中**可指认**（凭「感觉相关」的不写）；标完自查「每一项都能说出它出现在题目哪里」。
>
> ⚠ **依据只认「材料 / 设问」两个来源——选项不是依据，干扰项尤其不是**（2026-09-17 河南高考实测教训）：
>
> - 选择题的 A/B/C/D 中，**错误选项（干扰项）涉及的内容属于「排除范围」，不是本题考查范围**，据此标兼涉项＝系统性误标。
> - 实测误标形态：2025-01 标「+第2课 诸侯纷争」依据是 A 项「从邦国林立走向国家统一」；2026-04 标「+第11课/第9课」依据是 C 项「绍兴和议」、D 项「因俗而治」——**这类项须一律删除**。
> - 正确选项对应的课通常**已由落点课涵盖**；若落点课与正确选项指向不同课，则该项应升为**落点课**而非兼涉项。
> - 兼涉项的价值在于「该课被当背景/参照/结论调用」，**若该课只是被排除的错误方向，标进去会污染「兼涉/全涉」口径检索结果**。
>
> **跨册多值先看命题取向**（同次实测）：先判断该卷是否跨册命题，再决定要不要写跨册兼涉项——河南卷 **0/40 题跨册**（单册内深挖），河北卷 **16/20 题跨册**（必修×选必交叉）。**对单册深挖型卷子硬凑跨册兼涉项，是靠干扰项撑依据的高危信号**。
>
> - **单值兼容**：旧数据单值 str 与分号分隔串（`8上;8下`）均被脚本自动识别为多值，无需改写；新数据统一写 list。
> - **三口径检索**（服务不同场景，互不冲突）：**主考**＝只取首项（出课练卷、课时投入决策）｜**兼涉**＝只取非首项（看「背景型课」、关联教学、答题落点总结）｜**全涉**＝命中任一项（复习卷、跨课主题组卷）。
> - **录入兜底校验**（v1.5.0 起 `scan_questions.py` 自动执行）：若「课」的所属单元/册别未写进本题 单元/册别 字段，输出 `ℹ 定位字段提示`（提示级，不计入问题）——照提示补齐即可；跨册题课名分属多册也别漏写册别。
>
> **开放论述题（设问不限定课与史事）的定位口径**（2026-09-28 四川卷实测确立）：设问形如「结合 20 世纪以前某一具体历史事件或历史人物加以论证」时，题目**不指向任何单课**——此时**切不可硬凑一个课名充数**（如按材料首句随手挂在「第1课」），那会让该课在课次热度/单元配比统计中被虚增。
>
> | 字段 | 标法 |
> |---|---|
> | 册别 | 按**可选论证范围**标全（如 `[纲要上, 纲要下]`，即 20 世纪以前中国史与世界史都可能入选） |
> | 单元 / 课 | 按**最典型的可选论证方向标代表课**（2 项左右，每册一），**不设「唯一落点」**；代表课取法在同一卷内保持一致 |
> | 知识点 | 写题性词（`开放性论述` / `历史认识的方法` / `多角度认识历史`），不写具体史事名 |
> | 解析 | **必须显式写明**：设问不限定课与史事，定位字段仅为检索代表，**实际作答不限于此**；并提示取题宜按**题型**或**素养**（如 `历史解释-水平4`）检索，勿按单课检索 |
>
> 库内先例：`2026海南高考-19`（科技革命与国家战略，标第10/19/28课三个代表方向）、`2026四川高考-18`（盲人摸象，标第3课秦统一／第6课全球航路）。

> **史料研读 / 史学方法类题（高中选修1/选修2）的判定口径**（2026-09-28 高考真题库全量实测确立）：高中选修模块（选修1 史学入门 / 选修2 史料研读）**不是按内容范围标定位的，而是按设问考查对象标定位的**——
>
> - **标选修的铁则**：**设问直接考史料学 / 史学方法本身**，才标选修1或选修2。六类信号词：**史料价值 / 史料类型 / 史料互证 / 考证辨析（史料真伪与可信度）/ 史实与观点之辨 / 图像等新史料的入史路径**。
> - **不标的铁则**：**史料仅作载体、设问考的是历史内容**——无论材料形式多「史料化」（碑铭、方志、档案、图表、图像），只要设问落在具体史事上（如「据碑铭说明该国兴起」「据地方志概括铁路影响」），定位仍归内容课，**不标选修**。选项含史料术语同样不是依据（呼应上方「依据只认材料/设问」）。
> - **首项 vs 兼涉**：
>
> | 题型结构 | 选修定位 |
> |---|---|
> | 单问或多问**全部**落在史学方法上（如「说明该组史料的类型与价值」「指出两则史料能否互证并说明理由」） | 选修专题作**首项**（命题落点） |
> | 主体是内容设问，仅**附带一个史料价值小问** | 内容课作首项，选修专题作**兼涉项**（挂在该小问对应的材料上） |
>
> - 选修的`单元`＝模块名（`选修1 史学入门` / `选修2 史料研读`），`课`＝`专题X.Y 名称`（词表见 BOOK_INDEX.md「高中选修」两节）；兼涉项同样须在设问中可指认。
> - 库内首批实例（2026-09-28 补标 11 题）：**作首项**——2025山东-17、2026山东-17（多源互证→选修2·专题2.2）、2026山东-18（史实与观点之辨→选修1·专题1.6）、2026江西-19（以图证史→选修2·专题2.5）；**作兼涉**——2021海南-21、2022海南-19、2024海南-16、2026广东-20、2026江西-17、2026河北-19、黄牧航综合探究-01 共 7 题（内容课落点＋史料价值/研究方法小问）。

> **学史方法（初中教材「学史方法」栏目）的入选标准**（2026-10-06 定稿）：与选修模块的判定逻辑同源——**看设问是否**要求运用该方法，而非材料**是否**属于该方法可读的载体。**两档并标、可不限定册**：
>
> | 档位 | 判据 | 标注方式 |
> |---|---|---|
> | **首项**（直接考查） | 设问**直接要求运用该方法**，或直接考查方法本身的内涵/要素（如「依据材料提取……信息」「撰写一篇历史小论文」「绘制……时间轴」「按年代顺序排列」） | 方法条目作 `课` 字段**首项**，`单元` 追加 `学史方法` |
> | **兼涉项**（间接运用） | 材料**是**该方法可读的载体（给历史地图/文献史料/统计图表/历史图像），但设问考的是**内容** | 内容课作首项，方法条目作**兼涉项**（三项同序平铺中排在对应内容课之后） |
> | **不标** | 材料虽含可地图化/可史料化信息，但既未直接考查方法、也未在设问中用到该方法 | 不写 |
>
> - **两级边界（易混）**：兼涉项 ≠ 「材料有史料/图表就标」——必须是**该题的作答确实用到了该方法**（如给统计图表、设问要「概括变化趋势」，即用到了「解读统计图表」）；仅材料中出现图片而设问与图像解读无关者不标。
> - **不限定册**：方法可跨册使用，`册别` 按所涉**史事**册别标注即可（历史纪年法中国古代史有、近代史还可能涉及民国纪年法）。
> - 写法：`单元: [第N单元 …, 学史方法]`、`课: [第X课 …, 如何xxx方法]`；**序号一致、逐项对应**（首项内容课 ↔ 首项单元；兼涉方法条目 ↔ 兼涉单元）。方法条目名**不带前缀**（旧前缀写法存量兼容）。
> - 库内实例：`2026湖北中考-33`（作首项：8上抗战史 + 小论文方法）、`2026郑州一模-02`（作首项：7上商朝利簋 + 从出土文物中获取信息）、`郑州市二七区2024-2025学年7上期末-29`（作首项：7上科技文化 + 小论文方法）。

## id 写法与规范化（2026-10-23 全库统一）

### 三种历史形态

| 形态 | 写法 | 统一前存量（3677 题） |
|---|---|---|
| **流式 list（推荐）** | `id: [2026河南中考-01]` | 2275 题 |
| 标量 | `id: 2026河南中考-01` | 1366 题 |
| 块式 list | `id:` ＋ 换行 `  - 2026河南中考-01` | 36 题 |

三者 `qb_schema.split_frontmatter` 都读得懂，**但混写会误伤自写解析器**：按「一行取一个 id」写的正则（如 `^id:\s*(.+)$`）遇块式会把 `- 2026河南中考-01` 当成值、遇多值流式会把整串当单值，结果是**索引漏题或断链**——2026-10-23 实测，两份单元考查方向分析各有 1—2 处链接因此被判为断链（`2023全国新课标卷-34`、`2026原创-01`）。

### 统一口径

- **写入一律流式单行**：`id: [A]`／`id: [A, B]`。`qb_schema.dump_yaml` 已按流式输出，**`gen_problem.py` 无需改**（2026-10-23 复核第 560 行）。
- **读取必须兼容三形态**，且把 id 当**多值**处理——**首项才是主卷**，其余是合并归档追加的别名。
- **id 值不手改**：值只由 `gen_problem.py` 生成、`dedupe_questions.py --merge` 追加。值本身不合规（如序号位写成板块名「知识深化·探究」）属个案，人工判定后单独处理，别当批量规则跑。

### 体检与修复

```bash
python scripts/normalize_id.py                          # 体检（有待改项退出码 1）
python scripts/normalize_id.py --apply                  # 修复：只改 id 写法，其他字段与正文一字不动
python scripts/normalize_id.py --apply --limit=10       # 试点前 10 题
python scripts/normalize_id.py --rollback <日志.json>     # 按日志回滚
```

- 备份与回滚日志写**系统临时目录**（`%TEMP%/qb-id-normalize/<时间戳>/`）——不落库、不落 `scripts/`
- **何时跑**：① 重装或跨机同步后；② 用 Obsidian 属性面板手工编辑过题目后（面板会把单元素 list 降级成标量、多元素写成块式）；③ 自写脚本按 id 建索引报「漏题」时，先跑体检再怀疑数据

## 正文题号与分值规范（录入时）

**总则：一道题一个 md——题号与整题分值已由 id / YAML 承载，正文不重复；只删两处冗余，其余全保留。**

| 处理 | 对象 | 示例 | 依据 |
|---|---|---|---|
| 删 | 原卷题号（选择/非选择题正文一律不写） | `21.` / `1.` | 序号＝原卷题号＝文件名，id 末段已含（`2026河南中考-21`），正文再写即重复 |
| 删 | 总题号后的整题分值 | `21. (6分)` 的 `(6分)` | 整题分值已在 YAML「分值」字段 |
| 留 | 作答要求引导语（属题干组成部分） | `阅读下列材料，回答问题` | 删则丢题意 |
| 留 | 各小问的具体分值 | `(1)(2分)` | 小问分值是题面信息，YAML 无对应字段 |
| 留 | **选择题题干末尾的作答括号** | `……反映出西非地区（　　）` | 题干组成部分，组卷导出后即学生卷的答题位 |

要点：
- 非选择题题干 = 作答要求引导语 + 材料 + 设问，完整保留；选择题题干 + 选项完整保留
- **题干末尾作答括号：保留，形式统一为「（　　）」**（2026-09-18 用户裁定）——即**全角括号 U+FF08/U+FF09 + 两个全角空格 U+3000**。原卷末的作答括号属题干组成部分，**不删、不改半角、不缩成一个空格**；库内存量另有半角 `(　　)`、全角单空格 `（　）` 等混写，**不强制回改**，新录入一律按 `（　　）`。
- 小问分值写在对应小问后（如 `(1) ……（2分）`），原卷无论标在题号后还是小问后，均按小问就地保留
- 题号信息如需追溯，看 id（`2026河南中考-21`）或文件名 `21.md`——**两者都是原卷面题号**，不因录入顺序而改

## 一题多卷与去重（v1.3.0 起）

同一道题常被多卷收录（**中考真题被期末卷/模拟卷原样收录**最常见）。题库只保留权威版本的唯一一份，其余记录为「别名」并归档，避免重复存题与重复组卷。

### 数据形态

```yaml
id: [2024河南中考-08, 河南省实验中学2025-2026学年8上期末-03]      # 首项=主卷 id，其余=别名 id
来源: [2024河南中考, 真题, 河南省实验中学2025-2026学年8上期末, 期末卷]   # 成对平铺
```

- 主卷题文件留在原目录；别名题文件移入 `{vault}/.trash/<原相对路径>`（＝库内 Obsidian 回收站，面板内可还原到原位）
- 别名卷目录留 `_重复题清单.md`（题号 → 主题 id），供还原本卷时取题
- 合并日志 `{vault}/.dedupe/YYYY-MM-DD.json`（含主题 frontmatter 快照，可回滚）

### 合并对笔记引用的影响（方案一，2026-09-21 定案）

题目被合并归档后，**此前引用过它的 `3-试题研究/` 报告会静默断链**——这是「一题多卷」的固有副作用，必须在合并时一并处置：

- **症状隐蔽**：Obsidian 不报错，只把链接显示为「未创建的笔记」；而题库存在大量同名文件（`25.md` 全库十余个），模糊匹配可能把链接带到**另一道无关题**上——看起来还能点，实际指错了
- **处置原则（方案一）**：把失效引用改指**主卷**。旧题的「身份」并未消失——它以 id 形式被吸收进主卷的 id 多值数组（`id: [2022河南中考-15, 洛阳市涧西区2023-2024学年9上期中-06]`），所以正确做法**不是**把引用引到归档区（那会破坏「归档区不被引用」的规矩），而是改指吸收它的主卷文件
- **工具**：`scripts/check_note_links.py`——从失效路径 `{类别}/{卷名}/{卷名}_{题型}/{序号}` 反推旧 id `{卷名}-{序号}`，在全库 id 索引中定位主卷。同时检出**指向库内回收站 `.trash/` 的引用**（文件虽在，但 Obsidian 不索引该目录＝已呈断链）；不可定位者单独列出待人工确认，**不猜测**
- **别名**：默认保留原别名（只换路径），使报告上下文可读；改用主卷 id 作别名加 `--alias theme`。表格单元格内的 `\|` 转义风格原样保持
- **安全**：写盘前出计划（`--fix`）、写盘记日志 `{vault}/.linkfix/`、`--rollback` 可回滚
- **其他两种情形不适用方案一**（评估后放弃）：① 建「引用台账＋定期体检」——多一道工序且台账会过期，不如巡检脚本随时可跑；② 改用 id 式链接（`[[2022河南中考-15|…]]` 走别名解析）——**行不通**，`id` 是 YAML 列表，Obsidian 的 aliases 机制不读它，且全库 id 同名歧义同样存在

### 权威序（谁当主卷）

```
中/高考真题 > 中/高考模拟（一模/二模/联考） > 阶段测试（期末 > 期中/月考/单元卷）
同级：年份最早者优先；再按卷名、题号稳定排序
```

- 真题 B 卷与 A 卷同级（同属真题）
- 跨年真题撞题（如 2015 与 2018 河南中考同题）取**年份最早者**（2026-09-13 裁定）
- ⚠ **权威序倒挂 = 错误合并**（2026-10-22 定）：主题的权威序**不得低于**任一别名。`--merge` 在写盘前硬阻断（`--allow-inferior` 才放行，且写入日志 `authority_inverted`）；已合并题用 `--check-authority` 体检。
  - 实案：`2023全国新课标卷-34`（高考真题）曾被并入 `2026洛阳涧西区一模-18`（中考模拟）——旧版脚本对倒挂**只告警不阻断**，违规合并得以落地。已反向修正（真题为主卷），报告引用同步改指。
  - 修正倒挂的次序：① 把现主卷 frontmatter 还原为 `.dedupe` 日志里的 `theme_frontmatter_before`；② 归档件还原到原位；③ 以更权威者作主题重跑 `--merge`；④ 跑 `check_note_links.py --fix`。

### 同题判定边界（2026-09-13 裁定）

| 情形 | 判定 |
|---|---|
| 题干同、选项顺序不同、答案同 | **同题** |
| 题干同、选项有增删替换（干扰项不同）、答案同 | **同题（变体）**，差异写入主题「解析」备注 |
| 题干同、答案不同 | 待核 —— 回源卷核对官方答案，以官方为准 |
| 分值 / 难度 / 年份 / 考区不同 | 不构成不同题：保留主题值，差异写备注 |
| 仅课/知识点/素养标注不同 | **同题**，标注取并集 |
| 图片一有一无 / 图不同 | **同题**，图片合并到主题 |
| 材料同、设问不同（考查角度不同） | **不同题**（不合并且可关联标注） |
| 材料题部分小问重合、部分不同 | **不同题** |

### 判定流水线

| 级别 | 方法 | 说明 |
|---|---|---|
| L1 精确指纹 | 正文归一化后哈希（去图片引用/分值括注/题号、全角转半角、去标点空白） | 抓"一字不差" |
| L1' 选项集合指纹 | 选项内容**排序后**拼接再哈希 | 抓"选项顺序被重排"（实测有效） |
| L2 相似度 | 3-gram Jaccard（长度分桶加速），阈值：选择题 0.85 / 其他 0.72 | 抓少量改写，**会误报** |
| L3 结构化预筛 | 同册别 + 课有交集 + 答案相同 | 提高置信 |
| L4 AI 裁定 | 逐对给结论（同题 / 变体同题 / 同材料不同题 / 无关）+ 差异点 | 人工前最后一道机器关 |
| L5 用户裁定 | 在《疑似重复清单》上圈定 | 边界题最终裁定 |

> **阈值只用来缩小人工面，不单独下结论**——实测 2016/2019 河南中考两道论述题（原小论文题型）相似度 0.81，实为两题（材料主体不同：计算机与互联网 / WTO 与一带一路）。论述类必须过 L4/L5。

### 命令

```bash
python dedupe_questions.py --scan [--卷 X] [--阈值 0.85] [--out 清单.md] [--json]   # 全库查重
python dedupe_questions.py --check <新题.json>                # 录入前预检（逐题返回疑似 Top-N）
python dedupe_questions.py --merge <主题.md> --with <别名.md>[,...] --apply   # 合并（默认 dry-run；倒挂则拒绝）
python dedupe_questions.py --list-merged                     # 已合并题一览
python dedupe_questions.py --check-authority                 # 权威序体检（别名比主卷更权威即倒挂）
python dedupe_questions.py --rollback <{vault}/.dedupe/YYYY-MM-DD.json> --apply   # 回滚
```

## 试题研究笔记属性（vault `3-试题研究/`，2026-09-20 立）

`3-试题研究/` 下的笔记与题目文件是**两套属性体系**——题目文件的 YAML 是内容检索字段（见上文「字段表」），研究笔记的属性用于**归档、检索与摘要**。模板两份：`templates/试题研究笔记.md`（A 档）、`templates/试题报告笔记.md`（B 档），初始化时一并复制到 `{vault}/0-Template-模板/`。

### 分档与字段

| 档 | 适用 | 字段 |
|---|---|---|
| A · 单题/单卷研究 | 题目对照、逐字比对、改编诊断、命题技术、整卷对比分析 | 类型 / 学段 / 册别 / 来源 / 课 / 难度 / 核心素养 / 关键能力 / 关联题目 / 主题 / 核心结论 / 撰写日期 |
| B · 课·单元·专题·册别报告 | 流程四、流程五 产物 | 类型 / 维度 / 对象 / 学段 / 册别 / 覆盖卷别 / 课 / 难度 / 核心素养 / 关键能力 / 关联题目 / 主题 / 核心结论 / 撰写日期 |

**必填矩阵**（缺必填项则 Dataview 检索不到）：

| 字段 | A 档 | B 档 | 说明 |
|---|---|---|---|
| 类型 / 学段 / 册别 / 主题 / 核心结论 / 撰写日期 | 必填 | 必填 | 两档共用；跨学段研究的 `学段` 可多值（如 `[高中, 初中]`） |
| 来源 | 必填 | — | 卷名或教材课名，多值 |
| 维度 / 对象 / 覆盖卷别 | — | 必填 | B 档定位三件套 |
| 难度 / 核心素养 / 关键能力 | 有则填 | 有则填 | 不填则**省略该行**，不留空值 |
| 课 | 可选 | 可选 | 涉课少时填；整卷/跨册研究留空 |
| 关联题目 | 涉题 ≤10 道时填 | 同左 | 题量更大时留空（正文末节附表已列全） |

- **定位方式不同**：A 档用「来源＋关联题目」定位；B 档用「维度＋对象＋覆盖卷别」定位
- **A 档整卷研究**（如两卷对比）：`来源` 写全部卷名、`册别` 写覆盖到的全部册别、`课` 与 `关联题目` 留空
- **`覆盖卷别` 粒度**：卷源 ≤10 个时**逐卷列卷名**（与题库目录名同形，如 `洛阳市2025-2026学年9上期末`）；超过 10 个时允许写**卷组**（如 `河南中考2010-2026（含B卷）`、`洛阳市各学年9上期末`），全量卷名以正文样本说明为准
- **可选字段**：`title`（供 Dataview 显示名用）；`tags` 为历史遗留字段，新笔记一律用 `主题`，不再写 `tags`

### 受控值

- **类型**（五值取一）：`试题研究`（单题/单卷的对照与拆解）｜`考查方向分析`（课/单元/专题的命题角度归纳）｜`考情分析`（卷/册的成绩与结构画像）｜`命题研究`（命题方法与技术）｜`组卷记录`（一次组卷的选题取舍留痕）
- **维度**（B 档，五值取一）：`课` ｜ `单元` ｜ `专题` ｜ `册别` ｜ `考情`
- **学段**：`初中` ｜ `高中`；跨学段研究写多个值（如 `[高中, 初中]`）。**难度**：`易/中/难`；**册别 / 课 / 核心素养 / 关键能力**：同题目字段口径
- **对象**：报告对象名，与文件名主干一致（如 `9上第5单元走向近代`）；专题写 `专题-{专题名}`
- **覆盖卷别**：卷名与题库目录名同形，多值；**不写自创简写**

### 命名

| 类别 | 命名 | 例 |
|---|---|---|
| 考查方向分析（流程四） | `{册别}第N课{课名}-考查方向分析.md` ｜ `{册别}第N单元{单元名}-考查方向分析.md` ｜ `专题-{专题名}-考查方向分析.md` | `9上第5单元走向近代-考查方向分析.md` |

- ⚠ 分析报告命名**不带日期前缀**（日期进 `撰写日期` 属性，便于 Dataview 排序）；手写研究笔记保留日期前缀

### 关联题目（wikilink 铁律）

格式 `[[{类别}/{卷名}/{卷名}_{题型}/{序号}|{题目id}]]`——**显示名用 id**，短链接不依赖别名机制、解析必成；禁写简写笔记名。例：

```
关联题目:
  - "[[初中-1中考真题/2026河南中考/2026河南中考_选择题/01|2026河南中考-01]]"
```

#### ⚠ 序号须与磁盘文件名逐字一致（2026-09-27 立）

库内题目文件是**补零命名**（`01.md`…`09.md`、`10.md`）——路径段写 `/1` 必解析失败：Obsidian 显示为不可点击的灰链、报 `…/1 (unresolved)`，而**源码里完全看不出来**。两处都要注意：

> 序号＝**原卷面题号**（两位补零）：定位某题时**照原卷题号写**，合卷跳号（如 24~35、41~47）不必补齐、也不要自行改连续号。

| 位置 | 路径段（须补零） | 显示名（可短） |
|---|---|---|
| 属性 `关联题目` | `/01` | id（规范要求） |

#### ⚠ 正文表格内引用（务必转义管道符）

题目链接出现在**正文表格单元格**时，`|` 必须写作 `\|`，否则会被 Markdown 当作列分隔符吞掉，链路失效、页面直接显示原始 `[[...]]` 文本且不可点击：

| 情形 | 写法 | 结果 |
| --- | --- | --- |
| 正文段落 | `[[路径/25\|别名]]` 或用裸 `|` | ✅ 均解析 |
| 表格单元格 | `[[路径/25\|别名]]` | ✅ 解析 |
| 表格单元格 | `[[路径/25|别名]]`（未转义） | ❌ **失效**（表格内专属，与是否有别名无关） |

- 仅**表格行**需要转义；路径与 `\|` 之间**不得留对齐填充空白**（`.../25␣␣␣\|别名` 会把空格算进路径尾部导致匹配失败），填表时用 `路径.rstrip()`
- 验证方法（不可只数 `[[` 出现次数，那只是源码字符串）：
  ```bash
  obsidian links path="3-试题研究/报告名.md"   # 数解析出的 .md 目标条目数
  ```
  实测对照：34 处链接中，表格内 26 处未转义时**仅 7 个目标能解析**；转义后 **25 个目标全部解析**
- 批量修正脚本思路：逐行判断 `line.lstrip().startswith("|")` → 只对该类行内的 `[[...]]` 做 `body.replace("|", "\\|", 1)`（首个未转义分隔符）+ 路径侧 `rstrip()`

#### 正文出处补链（研究报告，2026-09-21 起）

流程三/四的研究报告，正文大量以「2024 年河南中考 第 25 题」形式给出处——**这是纯文本，读者无法点开看原题**。用 `scripts/linkify_citations.py` 批量转成库内 wikilink：

```bash
python scripts/linkify_citations.py                  # 扫描 3-试题研究/ 全部笔记（只读）
python scripts/linkify_citations.py --files a.md b.md # 指定笔记
python scripts/linkify_citations.py --apply           # 执行（建议先备份）
```

| 决策点 | 口径 |
| --- | --- |
| 显示名 | `{卷名} 第 N 题`（如「2024河南中考 第 25 题」）——与正文出处表述同构，读者一眼可懂；**不带空格**的卷名形式亦可（属性字段用 `{卷名}-{题号}`） |
| 表格内 | 自动转义 `\|` |
| 替换范围 | 只把「卷别 第N题」这一段包进链接，`**【中考真题】`、`> `、`| ` 等前缀留在链接外——否则破坏 `**…**` 加粗配对 |
| 每处提及 | **都建链接**（用户 2026-09-21 裁定）：表格列一遍、正文再引一次，两处都可点 |
| 不处理的 | 缺卷别的指代（「例如 2026 年第 24 题」「同卷第 9 题」）**不猜测**，单列交人工 |

**卷匹配用要素法**（年份＋考试类型＋册别＋地名＋检测卷序号），并带三条硬判据：
① **A/B 卷**——`2016 河南中考` 会同时命中 `2016河南中考` 与 `2016河南中考B卷`，须按「表述与目录的 B卷 属性一致」淘汰；
② **区级**——`2025 年洛阳市一模` 会撞上 `2025洛阳涧西区一模`，表述无区名则排除区级目录；
③ **文件名补零**——库内题目文件是 `06.md`/`01.md`，而报告写「第 6 题」，查找须同时试 `6.md` 与 `06.md`（否则大面积误报「卷内无此号」，本次实测即因此一度只匹配到 35/96）。
④ **「年」字可省**——`2026涧西区一模第11题` 不带「年」字，出处正则须写 `\s*年?\s*`（实测因此漏识 4 处）。

**实测（2026-09-21）**：三份报告一次补链 228 处（河南中考非选择题 89／9上第5单元 86／7上第2单元 53），**零未定位、零断链**；结构无损比对（把新旧文件的链接与出处表述都换为占位符后逐行比对）全行一致。

**校验口径**：`obsidian links path="…"` 输出的是**去重后的目标数**，须与「源码里去重后的路径数」相等——不等即有静默失效（本次初次比对曾因漏切正文链接的单竖线分隔符而误报 25 处缺失，实为比对脚本 bug，链接本身完好）。

### 陷阱

1. **两套属性别混**：研究笔记**不是**题目文件——不写 `id/题型/分值/答案/解析`；反之题目文件不写 `维度/对象/覆盖卷别`
2. **B 档 `关联题目` 默认留空**：报告涉题常数十道，正文末节附表已列全；涉题 ≤10 道时才逐个填双链（否则属性面板被长列表淹没）
3. **`类型` 不写目录名代称**：报告类按受控表填「考查方向分析」或「考情分析」，不要一律写「试题研究」
4. **旧笔记迁移**：早期笔记或套用了题目字段（`来源/册别/核心素养/关键能力`）、或整体缺属性——按本表**补齐**；原有可用字段不删，唯 `tags` 例外（值并入 `主题` 后删除，避免双套标签）
5. **不适用字段直接省略**：`难度/核心素养/关键能力/课/关联题目` 无值时**不写该行**，不要留 `字段:` 空值——空值行会让属性面板出现一片「—」，且 Dataview 判空逻辑易踩坑
6. **报告改名同步改属性**：`对象` 必须与文件名主干一致（如文件名 `9上第5单元走向近代-考查方向分析.md` → `对象: 9上第5单元走向近代`），改名后**两处一起改**
