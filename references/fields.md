# 字段详解与 JSON 模板

## 目录规则

```
{vault}/{学段}-{序号类别}/{卷名}/{卷名}_{题型}/{序号}.md
示例：{vault}/初中-1中考真题/2026河南中考/2026河南中考_选择题/01.md
```
（`{vault}` = `TNOTE_VAULT` 环境变量指向的题库库根，见 SKILL.md「初始化」）

- 学段-类别（vault 根目录，**原创/改编不占目录**）：
  - 初中：`初中-1中考真题` / `初中-2中考模拟题` / `初中-3阶段测试`
  - 高中：`高中-1高考真题` / `高中-2高考模拟题` / `高中-3阶段测试`
- 卷名：如 `2026河南中考`；题型子目录：`{卷名}_{题型}`；序号：两位（01~25）
- id 自动生成：`{来源首标签}-{序号}`（如 `2026河南中考-01`）

## 卷名命名约定（避免每次询问）

**阶段测试**（分类至 `初中-3阶段测试` / `高中-3阶段测试`）：

```
{地点}{学年}学年{X}{上|下}学期{月考|期中|期末}
```
- 地点：省/市/区/县/校名（`郑州市` / `河南省信阳市浉河区` / `河南省实验中学` / `河南省镇平县`）
- 学年：`YYYY-YYYY` 单连字符（推荐） 或 `YYYY--YYYY` 双连字符（历史数据兼容）
- 年级：**必须使用数字简写**（`7`/`8`/`9`）
- 后缀（文件名，非目录）：学科 + 版本 + 答案标识（例：`7上期末历史试题`）
- 完整示例：
  - `郑州市2021-2022学年7上期末`
  - `河南省实验中学2025-2026学年7下期末`

**中高考（含模拟）**（分类至 `*-1中考真题/高考真题` 或 `*-2中考模拟题/高考模拟题`）：
```
{地域}{年份}{中考|高考}[几模|联考名]
```
- 地域：`河南` / `洛阳` / `全国` 等
- 年份：4 位（`2026`）
- 类型：`中考` / `高考`，模拟标 `一模`/`二模`/`三模`，联考用联考名（`金太阳联考`/`华大新高考联盟`）
- 完整示例：
  - `2026河南中考`（真题）
  - `2026洛阳一模`（一模）
  - `2026衡水金卷联考`
  - `2025新课标II卷`

> 命名遵循上图示例。录入卷子时若用户给原始文件名 → 按上规范提炼为卷名（去扩展名、去学科后缀、去版本号、去答案标识），保留地点/学年/年级/学期/考试类型/类型标识等核心字段。来源标签第一项=卷名。

## 字段表

| 字段 | 必填 | 类型 | 说明 / 枚举 | 示例 |
|---|---|---|---|---|
| id | ✓ | str | 自动：{来源}-{序号} | 2026河南中考-01 |
| 册别 | ✓ | list | 7上/7下/8上/8下/9上/9下/纲要上/纲要下/选必1/选必2/选必3；**支持多值**（跨册别综合题，主考点在前） | ["8上", "8下"] |
| 单元 | ✓ | list | 教材单元全称；**支持多值**，与课对应 | ["第1单元 中国开始沦为半殖民地半封建社会"] |
| 课 | ✓ | list | 教材课名全称（须过 BOOK_INDEX）；**支持多值**，与册别/单元对应 | ["第1课 鸦片战争"] |
| 小节 | ✗ | list | 课内子目，可多值（多课时按课顺序平铺） | ["鸦片战争的爆发", "南京条约"] |
| 知识点 | ✗ | list | 课标条目/核心概念，可多值 | ["鸦片战争的影响"] |
| 核心素养 | ✗ | list | 学科核心素养细分，可多值（词表见本技能 `references/素养能力词表.md` 第一章） | ["史料实证-史料信息的提取", "历史解释-史事的因果性阐释"] |
| 素养层次水平 | ✗ | list | 初高中分轨，可多值：初中 `素养名称-层次N-体现`、高中 `素养名称-水平N-体现`（词表见本技能 `references/素养能力词表.md` 第二章；**不跨学段换算**） | ["史料实证-层次2-从史料中提取历史信息"] |
| 关键能力 | ✗ | list | 郑林 9 要素编号 A1-C3，可多值（词表见本技能 `references/素养能力词表.md` 第三章；**新题不用徐奉先 3×3**，存量旧值按迁移映射换算） | ["A3-概括", "B2-分析"] |
| 题型 | ✓ | str | 选择题/材料解析题/论述题/综合探究题/小论文/填空题 | 选择题 |
| 难度 | ✓ | str | 易/中/难 | 中 |
| 分值 | ✓ | int | | 1 |
| 来源 | ✓ | list | **多值标签**：出处标签自由 + 类型标签建议受控 | ["2026河南中考", "真题"] |
| 年份 | ✓ | int | **改编题写改编年份**（非原卷年份） | 2026 |
| 考区 | ✓ | str | 河南/原创/… | 河南 |
| 答案 | ✓ | str | 选择题填字母；材料题填 (1)…(2)… | A |
| 解析 | ✗ | str | 考查点+解题思路（YAML 内，多行用 \n） | 考查… |
| 题干 | ✓* | str | 正文：选择题题干；材料题=材料+设问全文 | 阅读材料… |
| 选项 | ✗ | list | 选择题专用，2~6 项，自动拼A B C D | ["…", "…", "…", "…"] |
| 图片 | ✗ | list[dict] | `[{"src": 源路径, "name": 引用名}]`，正文用 `![](images/名字)` | 见下 |

**来源标签规范**：
- 出处标签（自由）：卷名/教材课名，如 `2026河南中考`、`2025洛阳一模`、`8上教材第1课`
- 类型标签（建议受控）：`真题 / 教材改编 / 中考改编 / 原创题 / 期末卷 / 模拟卷`
- 示例：真题卷 `["2026河南中考", "真题"]`；教材改编（含中考题改编自教材）`["8上教材第1课", "教材改编"]`；中考改编 `["2024江西卷", "中考改编"]`；原创 `["2026原创", "原创题"]`
- 原创/改编题**不建独立文件夹**（无「原创命题/模拟卷」目录），放在对应学段-类别卷目录或新建卷名下，靠来源标签区分

> 题干 + 选项：选择题两者都填（脚本拼 `题干\n(A)… (B)…`）；材料题只填题干（含材料与设问，多行用 `\n`）。
> 必填校验字段（REQUIRED_FIELDS）：id/册别/单元/课/题型/难度/分值/来源/年份/考区/答案。
>
> * 题干不在必填字段内（选择题可只有选项），但**正文非空由 scan 校验兜底**——材料题必须填题干，否则生成的文件正文为空会被 scan 检出。
>
> **多值字段说明（2026-08-22 起）**：`册别/单元/课` 与 `小节/知识点/核心素养/素养层次水平/关键能力` 均为 list，可多值。
> - **跨册别/跨单元/跨课综合题**：各字段填完整多值 list，顺序按「主考点在前」；`小节` 按课的顺序平铺对应。
> - **单值兼容**：旧数据单值 str 与分号分隔串（`8上;8下`）均被脚本自动识别为多值，无需改写；新数据统一写 list。
> - **检索**：`WHERE 册别 CONTAINS "8上"` / `核心素养 CONTAINS "史料实证"`（Dataview/Bases 均可命中）。
> - **跨册别题校验**：课名分属多个册别时册别须一并写全，避免 BOOK_INDEX 词表校验误报。

## CSV 批量录入（备选）

`gen_problem.py --csv 题.csv`：列名与 JSON 字段一致；`小节/知识点/选项` 用分号分隔；`题干/解析` 含逗号/换行时用引号包裹（CSV 标准）。图片字段 CSV 不支持，材料题图片走 JSON。
