# 学史方法正文（新教材栏目原文要点）

> **用途**：本文件收录新修订初中历史教材各册末「学史方法」栏目的**正文要点**（栏目原文，含步骤与示范锚点），作为**标注判据的权威依据**。
> 标注规则（字段写法、只校验方法名不校验册别）见 `references/fields.md` 与 `SKILL.md`；方法名白名单见 `scripts/BOOK_INDEX.md`「初中·学史方法（全六册）」表。
> ⚠ **可携带性**：本文件自包含，不含外部路径依赖。

## 本篇缘起

栏目正文均以**「某课某内容」为示范锚点**，并把方法拆成**带编号的步骤**——即方法＝**一套可操作程序**。这决定了标注判据：**判"方法意识"是否进入设问，而非材料形式**。

---

## 一、纳入口径（分主考／兼涉两档）

**主考（记入 `课` 字段首项）**：设问**直接指向方法本身**——含下列任一：
1. 出现**元认知标志词**：「如何……」的方法、步骤、程序、"获取信息"、"读图/读表/读史料的方法"等；
2. 设问动作与栏目**步骤完整对应**且**题为方法运用**（如"由出土文物可知……""据表格数据概括……趋势""评价××人物"）。

**兼涉（记入 `课` 字段非首项，与常规课名同序平铺）**：材料以该方法载体呈现、设问**兼及**方法，但**命题落点仍是史实**。

**不纳入**（只作材料载体，设问考史实内容）：
- 典型反例——**年代尺／时间轴题**问"时代特征／主题"（是**内容**，非"如何制作年表"）；
- **历史剧情境题**问"哪一幕／谁的台词"（是**史实**，非"如何编写剧本"）；
- 一般**图片／地图／图表**题问历史结论（属常规史料实证题，不因材料形式自动命中）。

> 判据一句话：**看设问"问的是怎么读/怎么查/怎么评"，还是"问的是史实是什么"**。

**两档并标的写法**（与库内「多值优先」体例一致）：`单元` 首项为原有单元、末项加 `学史方法`；`课` 中方法名按**落点**排位——主考时置于**首项**，兼涉时置于**兼涉项**。示例：
- 主考：`单元: [第1单元 史前时期, 学史方法]`　`课: [第3课 中华文明的起源, 如何从出土文物中获取信息]`
- （若方法为唯一落点则 `课` 首项即方法名。）

## 二、各方法正文要点（7上～9下）

### 7上

#### 如何从出土文物中获取信息
**示范**：第8课《夏商周时期的科技与文化》·**司母戊鼎**（世界上出土最重的青铜器之一）。**文物是凝固的历史**。从三方面入手：
1. **历史价值**——获取时间、空间信息（司母戊鼎出土于河南安阳，商王为祭祀其母"戊"所铸，展现商朝晚期高度发达的青铜文明）；
2. **艺术价值**——获取审美信息（造型大气庄重，耳部双虎食人图案、鱼纹/兽面纹/回形纹等）；
3. **科学价值**——获得科技信息（含铜 84.77%、锡 11.64%、铅 2.79%，与《考工记》所记比例相符；泥范铸造法、鼎耳铸接工艺高超）。

#### 如何掌握历史纪年法
**示范**：第13课《东汉的兴衰》·张角起义口号"苍天已死，黄天当立，岁在甲子"（"甲子"表年份）。**四种纪年法**：
1. **干支纪年法**——10 天干 + 12 地支依序组合，60 干支循环，每 60 年一循环（甲子年＝184 年）；
2. **王位纪年法**——按国君在位年数纪年（《史记》秦王政"元年"＝公元前 246 年）；
3. **年号纪年法**——用皇帝在位年号纪年（始于汉武帝；汉武帝太初三年＝公元前 102 年；明清一帝一年号，故以年号指代皇帝如万历、康熙）；
4. **公元纪年法**——公元元年为标志，以前称"公元前某某年"，以后称"公元某某年"或"某某年"（教科书主要采用）。

#### 如何阅读历史地图
**示范**：第16课《三国鼎立》·多幅历史地图（反映特定时期历史地理状况，含丰富时空信息）。**四方面**：
1. **看图名**——区别地图类型、了解主题（历史时期形势图、战争示意图、经济分布图、交通路线图等）；
2. **看图例**——弄清符号含义、了解事件发展态势（如《官渡之战示意图》，通过图例知袁军自北向南攻、曹军自南向北攻，观曹军偷袭路线与袁军败退路线）；
3. **看图注**——了解时间范围与地理方位，关注古今地名变化（官渡主战场位于今河南；"河水"古代专指黄河；黄河下游历次改道致入海口不同）；
4. **将图中信息与课文内容对照**——如结合课文可知曹军绝对兵力处劣势，但曹操夜袭乌巢烧粮扭转战局。

### 7下

#### 如何读懂文献史料
**示范**：第2课《唐朝建立与"贞观之治"》·唐太宗"以铜为镜，可以正衣冠……今魏征殂逝，遂亡一镜矣！"。**文献史料是书面记录史事的主要载体，读懂文献史料是学习历史的基础**。**四方面**：
1. **关注史料的出处**（蕴含时间、主题等信息——该史料出自刘昫等编撰《旧唐书·魏征传》，是唐太宗名臣魏征劝谏的故事）；
2. **查阅字典等工具书，弄清字词含义**（"以铜为镜"指古人梳妆常用铜镜；"以古为镜"指以历史为鉴；"以人为镜"指虚心接受别人意见）；
3. **理解文献史料的整体意思**（此则是对魏征劝谏的高度评价）；
4. **与其他史料相互印证**（欧阳修、宋祁编撰《新唐书·魏征传》有相似文字，表明唐太宗懂得"兼听则明、偏信则暗"，对其谏言择善而从）。

#### 如何把握史事要素
**示范**：第10课《金与南宋对峙》·"靖康之变"。**史事包括重要事件、历史人物和历史现象**；掌握史事是认识历史现象和建立历史联系的基础。从**事件的时间、地点、人物、原因、过程、结果**入手：
1. **时间和地点**（1127 年、北宋都城东京）；
2. **历史人物**（宋徽宗、宋钦宗，心存幻想、措施失当被掳，客死他乡）；
3. **背景和原因**（辽宋夏金多民族政权并立；宋金联合灭辽中金愈强、看到北宋腐败无能）；
4. **过程**（从宋金联盟抗辽始，以金军攻破东京为高潮，到二帝被掳止）；
5. **结果**（北宋灭亡，赵构随即建立南宋，形成金与南宋对峙局面）。

> 7下 学史方法栏目共 **2 个**（如何读懂文献史料、如何把握史事要素）。

### 8上

#### 如何评价历史人物
**示范**：第6课《戊戌变法》·**梁启超**。**历史人物是历史活动的主体，评价历史人物有助于把握历史活动的进程和影响**。**五方面**：
1. **确定时代背景，弄清生卒年和国别**（梁启超生于 1873 年，历经晚清和民国初年，1929 年去世，国别中国）；
2. **分阶段梳理参与的历史事件，了解其作用**（戊戌变法前撰文/办报/讲学宣传维新；变法失败后海外推动君主立宪；民国成立后反对袁世凯称帝）；
3. **从政治、经济、文化等方面了解其活动**（梁启超在政治方面的作为、思想文化方面的贡献等）；
4. **了解阶级属性，揭示其活动代表的阶级利益**（代表中国民族资产阶级，有何历史进步性与局限性）；
5. **看其对解决社会主要矛盾和影响历史发展趋势所起的作用**——是否顺应历史潮流、推动还是阻碍生产力发展及人类社会进步；顺应潮流、推动进步者充分肯定，反之否定。

#### 如何从历史图像中获取信息
**示范**：第21课《人民解放战争的胜利》·宣传《中国土地法大纲》的历史图像。**五角度**：
1. **阅读图像的标题，了解主题**（宣传《中国土地法大纲》）；
2. **依方位（从上到下或从左到右）、按系统（如从人物到背景）、有条理地观察**，重点观察主要部位（常以位置、色彩体现——图中文件即焦点）；
3. **看图像的表象信息细节**——人物穿着打扮、身体语言、神情气质，以判断身份、情绪和活动背景等；
4. **在表象基础上思考**——图中形象代表哪些历史人物、反映哪个时期历史场景，揭示时代风貌、重要社会现象和生活状况，在头脑中形成合理的历史景象；
5. **逐层深入地解释图像**——先直接描述画面场景、说感受；再解释不同人物或图案的位置、大小比例、图案象征意义；最后解释人物身份、事件或场景背景，并结合所学评价。

#### 如何从重大历史题材影视剧中获取信息
**示范**：第1课《鸦片战争》课后活动建议观看电影《鸦片战争》；第12课《中国共产党诞生》课后活动建议观看电影《建党伟业》。**观看重大历史题材影视剧是学习历史的辅助手段，能获取并印证历史知识**。**三要点**：
1. **了解其本着"大事不虚，小事不拘"原则创作**——主要人物及主要事件要有历史依据，不能虚构；主要角色和情节反映历史真实，但**任何影视剧都是文学创作，不等同于历史著作**；
2. **了解剧情细节、次要人物、对话场景是可以虚构的**——不一定具有历史实证，但必须符合历史逻辑和生活逻辑；从影视剧获取历史信息时要了解它所反映的历史时期、事件、人物、现象的重要程度等；
3. **观察场景、服饰、台词、动作等**，感受时代氛围和历史风貌。

### 8下

#### 如何建立历史的纵向联系
**示范**：新疆自古是中国领土、中央政府对新疆的有效管辖。**纵向联系**是指发生在**不同历史时期**的相关历史现象之间的联系；建立纵向联系，是将不同时期的历史事件按**相同类型、性质、意义**等方面进行联结。**三步骤**：
1. **把握历史事件的时空关系，找出历史上发生的相关事件**并串联（西汉设西域都护府；唐设安西都护府和北庭都护府；元设北庭都元帅府管理西域军政；清在南疆实行伯克、札萨克制，乌鲁木齐等汉族聚居区行州县制，平叛后设伊犁将军管全疆军政，1884 年建行省）；
2. **根据串联起来的事件，归纳出历史发展的过程和趋势**（汉至清早期称西域，西汉起正式归属中央政权，历代中央政府不断加强系统治理；新中国成立后新疆维吾尔自治区成立）；
3. **形成纵向的历史认识**（新疆自古是中国领土不可分割的一部分，对统一多民族国家发展具有重要意义；中央政府对新疆地区进行有效管辖）。

#### 如何解读统计图表
**示范**：无单一锚点课。**统计图表能更直观、更精准地反映历史**。**四步骤**：
1. **看统计图表的标题**——了解反映哪个时期、哪个方面的历史现象；了解主题的特定概念和术语（国内生产总值、人均国内生产总值、年平均、指数、总额、份额、增长率、百分比、收支、贸易顺差、贸易逆差等）；
2. **弄清各类统计图表的行、列统计项目和内容，按不同方面提取数值**（城镇人均可支配收入、城乡居民存款余额等）；**古代或外国的数值需查找资料换算**成今天或中国的相应数值，再加减计算等；
3. **分析数据信息，弄清大小、增减、高低、升降、快慢等变化趋势**，将数据解读与所学知识结合，**把数学语言转化为历史语言**，弄清数据变化的原因、影响；
4. **分辨图表样式**——表格/柱状图/折线图/饼状图各有读法：表格看横栏纵栏横向纵向比较（由数值看规模、变化，由条目及纵横对比找特点）；柱状图看直条长短描述增减、概括趋势；饼状图先观察分项、再比较比重、最后对应史实；折线图看总体找趋势、再看拐点分阶段（增/减趋缓、急缓，对应拐点时间，再解释趋势或转变）。

#### 如何制作历史年表
**示范**：⚠ **正文图待补**（8下 第 3 个方法）。已知方法名以 `scripts/BOOK_INDEX.md` 白名单为准。

### 9上

#### 如何建立历史的横向联系
**示范**：第14课《探寻新航路》+ 第15课《早期殖民掠夺》。**横向联系**是指与某一史事相关联的**同时期**历史现象之间的联系，可能发生在**不同地区、不同领域**；建立横向联系有助于强化时空观念，更全面地理解和解释历史。**三方面**：
1. **把握历史事件的时空关系，找出同时期发生的相似事件**并串联（15—16 世纪西欧开辟新航路中迪亚士、哥伦布、达·伽马、麦哲伦等人的航行）；
2. **从不同地区历史事件间的时空关系中，找出相关因素**并串联（西欧开辟新航路的原因：新兴资产阶级对香料黄金的渴求、开拓市场的需求，奥斯曼帝国控制东西方传统商路并征重税，中国人发明的罗盘航技术传入欧洲等）；
3. **把不同地区的政治、经济、文化等内容，放在同时段进行总结和归纳**，从中发现历史发展趋势（新航路开辟对世界历史产生的相互关联影响：葡萄牙、西班牙最早殖民；欧洲殖民者争夺殖民地不断战争；欺骗性贸易、贩卖黑奴、掠夺财富促进欧洲资本主义发展，给殖民地人民带来深重灾难）。

#### 如何研读经典著作——以阅读《共产党宣言》为例
**示范**：第20课《马克思主义的诞生》·《共产党宣言》。**研读经典著作是学习领会马克思主义的基本途径**。**五方面**：
1. **了解经典著作产生的背景和作者情况**（《共产党宣言》在第一次工业革命完成、阶级矛盾尖锐、工人运动逐渐高涨背景下，由马克思和恩格斯为共产主义者同盟起草的无产阶级革命纲领）；
2. **掌握经典著作中的专业词语**（阶级、阶级斗争、资产阶级、无产阶级、资本主义社会、共产主义社会、空想社会主义、科学社会主义等）；
3. **把握经典著作的主要内容**（揭示有文字记载以来的全部历史都是阶级斗争的历史、资本主义社会必将被共产主义社会取代的人类社会发展规律；肯定资产阶级历史上的革命作用，也带来资本主义社会无法克服的矛盾；代表新生产力的工人阶级通过建立自己的政党、进行无产阶级革命、用暴力推翻资产阶级统治、建立共产主义社会）；
4. **理解经典著作中包含的历史规律和作者的立场观点**（体现唯物史观基本原理——"蒸汽和机器引起了工业生产的革命……"包含生产力变革促进生产方式变革、进而促进社会历史演进的思想内涵，体现用唯物史观基本原理**解释历史的方法**）；
5. **了解经典著作的影响**（《共产党宣言》发表标志马克思主义诞生，揭示人类社会发展规律，提出无产阶级革命目标和道路，使社会主义从空想走向科学，为无产阶级解放斗争提供科学理论指导）。

> 9上 学史方法栏目共 **2 个**（如何建立历史的横向联系、如何研读经典著作）。

### 9下

#### 如何写作历史小论文
**示范**：第5课《第二次工业革命》"想一想"（第二次工业革命对世界产生了哪些影响）→ 以"科学技术进步对人类社会发展的作用"为题撰写小论文。**历史小论文是对历史问题进行深入学习、思考后写成的创新性文章**，包括读书札记、调查考察报告、专题小论文等。**四步骤**：
1. **确定小论文主题，拟定能明确表达自己观点的标题**；
2. **围绕主题细化所要讨论的问题，查阅相关资料，拟定写作提纲**（可通过社会调查或查阅档案搜集资料；也可结合个人兴趣）；
3. **将思路与所搜集材料组织起来写作**（如从科技成果、科学方法和科学精神等方面，将第二次工业革命与第一次工业革命对比，论述"蒸汽时代"到"电气时代"人类文明的巨大进步）；
4. **小论文要有论点、论据和结论**，运用证据进行推论，反复推敲、验证观点，不作假、不抄袭、不强词夺理；论据不用很多，但要能清楚表达自己的观点。

#### 如何运用网络资源
**示范**：二战/反法西斯（第15课语境）·以"战争与和平"为主题办板报或主题班会。**历史学习中，利用网络查阅历史文献、媒体素材（图像、音频、视频、地图等）及网络学习课件、作业和试题等，能拓宽学习路径、获取更多信息、加深理解**。**四要点**：
1. **明确目的**（如通过搜集整理德、意、日法西斯反人类暴行和世界人民反法西斯斗争的资料，办板报或组织主题班会）；
2. **紧扣主题**，在专业学术网站和权威资源网站上用检索工具查找，将找到的网络资源**筛选、排序，建立所获资源之间的联系**；
3. **围绕重点内容阅读查到的资源**，丰富课堂学习内容，将零散不系统的网络知识**补充并整合到完整知识体系**中；
4. **网络资源查阅方便、信息量大、交互性强、能跨时空共享**；但**找到网络资源不等于完成历史学习，资源存储在电脑中不等于能记住和理解**——要以"问题—任务"驱动自己的阅读和思考，加深知识理解，提升思维能力，形成正确的历史认识。

> 9下 学史方法栏目共 **2 个**（如何写作历史小论文、如何运用网络资源）。
