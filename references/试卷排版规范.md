# 试卷排版规范（成卷版式层）

> 适用范围：「Obsidian历史题库搭建」组卷流程产出**学生卷/教师卷**（md 与 Word 两种形态）时的卷面版式统一要求。
> 定位：本文件只管**卷面呈现**；题目自身携带的标注信息（来源括注/分值括注/材料出处/选项符号）格式见「历史原创命题」技能 `references/language-specification.md` 第六节「题面信息标注规范」。
> 成卷依据：河南中考真题卷版式通例 + 2026-09 实测课练卷（9上第5/6课）实践经验。

---

## 一、卷头版式

| 元素 | 版式 |
|:---|:---|
| 主标题 | 居中；格式 `{年级}上册 第{X}课《课名》 练习题/测试`（年级用阿拉伯数字：9年级上册） |
| 副标题行 | 居中；`（考查范围：{子目1}·{子目2}·…）`，按本课 BOOK_INDEX 子目或主要知识点列 |
| 说明行（可选） | 如做题时间/满分，置于考查范围行后 |

## 二、大题结构与小题编号

- 大题：`一、选择题` / `二、非选择题`（卷面只此两大区；判断题/填空融入选择题区外时另立）
- **小题跨大题连续编号**（河南中考通例）：选择题 1~N，非选择题从 N+1 起续编（如 10 选择 + 2 大题 → 非选择题为 17、18 号）。若按各大题独立编号（1-10、1-2），同卷内保持一致并在卷头不另注
- 大题目录（可选）：大题标题下可列小题号+分值，视篇幅而定

## 三、选择题区

- 题首说明：`一、选择题（每小题2分，共20分。每小题只有一个选项符合题意）`——分值随卷调整
- 每题为：题号+来源括注行 → 题干段 → 选项段
- **选项断行规则**：
  - 短选项（单行放得下）：同行排布，选项间**全角空格×2**分隔：`A．雅典　　B．斯巴达　　C．罗马　　D．迦太基`
  - 长选项（4 个同行放不下）：**两两换行**——A、B 一行，C、D 一行；题干较长时亦可四行排布（每项一行），同卷内风格统一
- 题干引用材料自带出处时，材料文本缩进或加引号以示区分

## 四、非选择题区（材料解析题）

| 元素 | 版式 |
|:---|:---|
| 大题头 | `二、非选择题（第17题X分，第18题X分，共X分）`（可选列各题分值） |
| 小题头 | `17．（年份·地区考试·题号）阅读下列材料，回答问题。`（题号连续续编；材料题惯用导语模板见命题技能语言规范 3.1） |
| 材料编号 | `材料一` / `材料二`…独立成段；材料内引文与说明文字可混合 |
| 材料出处 | 段尾 `——摘编自《××》`，可独立一行右排或随文（中式排版惯用随文左排，不强制右对齐） |
| 设问 | `(1) ……（X分）` 逐条换行；设问与材料之间不插空行（可空一行便于辨认） |
| 图片题 | 图片为独立段落，居中；题干先指图（`如下是……`）再设问 |

## 五、图片处理

- **来源**：组卷时从题库原题 `images/` 目录直接取用（export 时随卷打包/内嵌）
- **尺寸**：宽 ≤ 440px@96DPI（约 11.6cm，A4 正文宽内安全）；超宽图等比压缩，保持清晰
- **位置**：图片所在段落居中；图片后必须与后续文字分段（段落分隔符），不得与文本同段
- 多图合一原图（如中考卷两图拼一张）直接取用，不再拆分

## 六、答案与评分（教师卷）

- **学生卷**：不含答案
- **教师卷**：卷末 `参考答案` 部分**分页另起**（Word 插入分页符；md 用 `---`+标题）
- 选择题答案连排：`1．B　2．D　3．C　4．B　5．C`（题号全角点号、项间全角空格）
- 主观题：`17．(1) ……（2分）(2) ……（3分）` 分点给采分点；开放题注明"答出其中任意X点即可，其他言之成理也可"
- 洛阳系期末卷若原卷无官方答案、题库答案为整理推断，保留题库内 `【说明】原卷PDF未附参考答案` 注记溯源

## 七、字体与页面（Word）

- 正文默认字体：宋体（SimSun）
- 标题：可加粗或用标题样式；主标题醒目即可，不强制黑体
- 页面：A4 常规边距即可，无需特殊设置
- 执行通道：Word 卷经本地 Office 编辑通道（tencent-local-office-edit）或 python-docx 脚本生成；本规范只约束内容侧结果，工具细节不在此列

## 八、组卷适配操作（版式外的成卷动作）

1. **答案分布均衡检查**：候选题答案集中于某选项（如 10 题中 6 个 A）时，**重排部分题目选项顺序**（正确项换位，干扰项顺序平移），使 A/B/C/D 大致均衡（各 2-3 个/10题）
2. 重排选项必须**同步更新该题答案**；学生卷与教师卷使用同一重排后版本
3. **来源括注**沿用原卷来源（`（2024·河南中考·15）`），不因重组而改变
4. 材料题若为跨册综合题（题库多值课字段），仅当主题贴合本卷考查课时选用，卷内设问指向外册内容可裁剪超范围小问

## 九、文件命名

- `{年级}上第{课}课《课名》练习.docx / .md`（如 `9上第5课《古代希腊》练习.docx`）
- 分学生/教师两版时：`{卷名}_学生版`、`{卷名}_教师版`（与 export_student_paper.py 输出命名一致）
