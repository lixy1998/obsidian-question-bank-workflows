# BOOK_INDEX 词表：结构与维护

## 是什么

`BOOK_INDEX.md`（`<skill>/scripts/BOOK_INDEX.md`，随 skill 分发）是题库的**课名受控词表**（本技能唯一权威，独立维护）。`qb_schema.load_book_index()` 解析它，`gen_problem`/`scan_questions` 据此校验课名。

## 解析规则（load_book_index）

- **按册别映射版本节**（`qb_schema.BOOK_INDEX_VERSION`）：7上/7下 → `#### 2024版` 节；8上/8下 → `#### 2025版` 节；9上/9下 → `#### 2026版` 节；未映射册别（纲要/选必）不收录、不校验
- `### 9上`/`### 9下` 标题 → 册别 key（映射：7上→7上 … 9下→9下）
- `  - 第X课 课名` / `  - 活动课 名称` 行 → 课名全称
- 结果：`{"7上": [2024版节课名…], "8上": [2025版节课名…], "9上": [2026版节课名…], …}`（各册别只收录 `BOOK_INDEX_VERSION` 映射的版本节课名）

> **版本策略（2026-08-24 定稿）**：按**教材首印定版年份**命名版本节——7上/7下（2024 首印定版）→ 2024版节；8上/8下（2025 首印定版）→ 2025版节；9上/9下（2026 首印定版）→ 2026版节；高中册别不建节、不校验。各册首用后仅小修订，**不新建版本节**，在对应册别版本节上**就地修订**条目（课名微调、子目增删等）。
>
> **修订联动（AI 自动关联）**：词表条目就地修订时，AI 须按清单自动排查并同步所有关联项——① 存量题「课」字段（scan 校验定位 → 一次性映射脚本或手动 Edit 重映射）；② 试题索引（`gen_index.py` 重跑重建）；③ 映射与缓存（涉及册别→版本节映射变化时同步 `qb_schema.BOOK_INDEX_VERSION`；缓存新会话或 `qb_schema._BOOK_CACHE=None` 后生效）。**只改词表本体、不动关联项 = 不完整修订**。

## 维护铁律

1. **BOOK_INDEX.md 为唯一权威词表**：本技能内 `scripts/BOOK_INDEX.md` 直接维护，无第二副本
2. 新增册别词表：从对应版本教材（单元→课→子目）或课标/培训资料提取，按体例写入 BOOK_INDEX.md → 重启校验（qb_schema 缓存首次调用后不再重读，新会话或 `python -c "import qb_schema; qb_schema._BOOK_CACHE=None"` 后生效）。**册别→版本节映射记得同步维护 `qb_schema.BOOK_INDEX_VERSION`**
3. 子目不确定时标 `[?]`（据旧版推断），并更新节内核实说明——**不要**臆造确认
