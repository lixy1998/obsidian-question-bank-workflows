# BOOK_INDEX 词表：结构与维护

## 是什么

`BOOK_INDEX.md`（`<skill>/scripts/BOOK_INDEX.md`，随 skill 分发）是题库的**课名受控词表**（本技能唯一权威，独立维护）。`qb_schema.load_book_index()` 解析它，`gen_problem`/`scan_questions` 据此校验课名。

## 解析规则（load_book_index）

- **初中按册别映射版本节**（`qb_schema.BOOK_INDEX_VERSION`）：7上/7下 → `#### 2024版` 节；8上/8下 → `#### 2025版` 节；9上/9下 → `#### 2026版` 节
- **高中不走版本节**：由 `qb_schema.GAOZHONG_SECTIONS` 映射整节——`#### 中外历史纲要（上）/（下）`、`#### 选择性必修1~3` 依教材目录；**`#### 选修1 史学入门`／`#### 选修2 史料研读` 官方无教材，依课标选修课程【内容要求】的 7 个专题建表**（课名 `专题X.Y 名称`）。即课名校验**已覆盖全部高中册别**（2026-09-17 起覆盖纲要/选必，2026-09-28 起覆盖选修）
- ⚠ **同文件还有第二套解析：`load_lesson_units()`（v1.5.0 起）**——解析出 `{(册别, 课名): 单元全称}`，**初中取目标版本节 + 高中各册节**（`#### 中外历史纲要（上）/（下）`、`#### 选择性必修1~3`、`#### 选修1`、`#### 选修2`，合计 242 课），供 `scan_questions.py` 的「课 ↔ 单元/册别」**定位字段提示**使用。与 `load_book_index()` 是用途不同的两套解析，**改词表结构时两者都要验**
- `### 9上`/`### 9下` 标题 → 册别 key（映射：7上→7上 … 9下→9下）
- `  - 第X课 课名` / `  - 第N课 活动课 名称`（方案A，见下）/ `  - 专题X.Y 名称` / `  - 如何…（学史方法条目）` 行 → 课名全称
- 结果：`{"7上": [2024版节课名…, 如何…方法条目], "8上": [2025版节课名…], "9上": [2026版节课名…], "选修1": [专题1.1~1.7], "选修2": [专题2.1~2.7], …}`（初中各册只收录 `BOOK_INDEX_VERSION` 映射的版本节课名；学史方法条目按课名一并收录）

> **版本策略（2026-08-24 定稿）**：按**教材首印定版年份**命名版本节——7上/7下（2024 首印定版）→ 2024版节；8上/8下（2025 首印定版）→ 2025版节；9上/9下（2026 首印定版）→ 2026版节；**高中册别（纲要/选必/选修）不建版本节、整节收录**（选修无教材，依课标 7 专题建表）。各册首用后仅小修订，**不新建版本节**，在对应册别版本节上**就地修订**条目（课名微调、子目增删等）。
>
> **修订联动（AI 自动关联）**：词表条目就地修订时，AI 须按清单自动排查并同步所有关联项——① 存量题「课」字段（scan 校验定位 → 一次性映射脚本或手动 Edit 重映射）；② 试题索引（`gen_index.py` 重跑重建）；③ 映射与缓存（涉及册别→版本节映射变化时同步 `qb_schema.BOOK_INDEX_VERSION`；缓存新会话或 `qb_schema._BOOK_CACHE=None` 后生效）。**只改词表本体、不动关联项 = 不完整修订**。

## 活动课（册末课，2026-10-06 起方案A）

- **词表写法**：册末**顶格**写 `- 第N课 活动课 名称`（**教材目录体例**，N＝接该册常规课末号顺延；如 7上 常规 20 课 → 活动课第21课；9上/9下 常规 21 课 → 活动课第22课）；无子目层级。
- **层级定性（A2）**：活动课**不作独立单元**、也不属任何常规单元；它是「册末的一个课条目」。**课** 字段写整行 `第N课 活动课 名称`；**单元** 字段统一写固定值 `活动课`（`qb_schema.ACTIVITY_UNIT`）。
- **各册活动课一览**（2026-10-06 补全，7上/7下/8上 为新增）：7上 第21课 从考古发现看中华文明的起源｜7下 第22课 我国传统节日的起源与传承｜8上 第22课 探寻红色文化的历史基因｜8下 第24课 新时代社会生活的巨大变化｜9上 第22课 唱响《国际歌》｜9下 第22课 英国脱欧｜纲要上 第31课 家国情怀与统一多民族国家的演进｜纲要下 第24课 放眼世界，推动构建人类命运共同体｜选必1 第19课 中国历史上的大一统国家治理｜选必2 第16课 技术进步与社会生活的变化｜选必3 第16课 信息革命与人类文化共享。
  - ⚠ **8下/9下 名称已由用户裁定**：8下 保留 `新时代社会生活的巨大变化`（网络所查「生活环境的巨大变化」系**旧教材**）；9下 用 `英国脱欧`（非旧教材的「时事溯源」）。
- **解析联动（改词表后须四验）**：① `load_book_index` 收录活动课整行作课名；② `load_lesson_units` 返回 `(册别, 活动课整行) → 活动课`；③ `gen_index` 为顶格活动课行生成独立 `## 第N课 活动课 名称` 节（`_is_activity_lesson` 判据）；④ `paperkit.spec.short_lesson` 对活动课**不缩为「第N课」**（防与同号常规课撞名）。
- **历史沿革**：曾写作顶格 `- 活动课 名称`（无编号）；2026-10-06 用户裁定改方案A 加编号。旧写法仍兼容（`_ACTIVITY_LINE_RE` 容许无编号）。

## 学史方法（教材单元层级，2026-10-06 起）

- **层级映射**：`单元` ＝ 固定值 `学史方法`；`课` ＝ **方法条目本身**（如 `如何从出土文物中获取信息`，**不带任何前缀**）；`册别` 按所涉史事册别标注（不强绑）。
- **两处呈现、逐字一致**：① 各册版本节末尾的 `- 学史方法` 单元 + 缩进 2 格的方法条目（**真正的教材单元层级**）；② `## 初中·学史方法（全六册）` 总表（`| 序号 | 学史方法 | 所属册次 |`）——**权威清单**，共 18 行（六册各 3 个）。
- **入库写法**：`单元: [第N单元 单元名, 学史方法]`、`课: [第X课 课名, 如何xxx方法]`——三项**同序平铺**，首项＝设问落点，其后依次为兼涉项（与其它字段同一约定）。
- **校验**：`qb_schema.load_method_names()` 解析总表为**方法名白名单**（18 条，尾随 `[?]` 剥除）；`validate_lesson` 对方法条目**只校验方法名、不校验册别**。理由：中高考题常按「史事 + 方法维度」**跨册**标注（如 `2026湖北中考-33` 考 8上抗战史 + 小论文方法；历史纪年法中国古代史有、近代史还可能涉及民国纪年法），严格按册会误伤。兼容旧前缀写法 `学史方法-<方法名>`（存量迁移期，剥前缀后同样按方法名比对）。
- **入选标准（2026-10-06 定稿；两档并标）**：
  - **首项（直接考查）** ——设问**直接要求运用该方法**（含直接考查方法本身的内涵/要素），标为课字段首项；如「依据材料并结合所学，提取……信息」「撰写一篇历史小论文」「绘制……时间轴」。
  - **兼涉项（间接运用）** ——材料**呈现该方法可读的载体、但设问考的是内容**（如给一张历史地图问图中史实、给一段史料问事件原因），标为课字段的兼涉项；仅在确有此维度才标，不滥标。
  - **不限定册**——方法可跨册使用，按所涉史事册别标注即可（如历史纪年法中国古代史有、近代史还可能涉及民国纪年法）。
- **维护**：新增/修订方法名一律改总表（唯一权威）；各册节内的单元条目须同步逐字一致。方法名不确定时标 `[?]`（当前 7下/9上/9下 第 3 个方法名待核实），**不要臆造确认**。
- **解析联动**：`load_book_index()` 收录各册方法条目（作为课名）、`load_lesson_units()` 返回 `(册别, 方法条目) → 学史方法`、`load_method_units()` 返回各册实际挂载集合——三处都要在改词表后验证。

> **历史沿革**：曾用「方案 B」——课名写 `学史方法-<完整方法名>`、方法视为独立总表不占单元。2026-10-06 用户裁定改为**教材单元层级**（单元＝`学史方法`、课＝方法条目本身、取消前缀），存量 3 题已迁移。旧写法仍兼容但**不再作为新录入口径**。

## 选修模块栏目（`#### 选修1 史学入门` / `#### 选修2 史料研读`）

- **背景**：高中**选修课程官方未编写教材**，既无教材目录可依，也无版本节概念。经用户裁定（2026-09-28），**依《普通高中历史课程标准（2017 年版 2025 年修订）》「五、课程内容 →（三）选修课程」的【内容要求】建表**——课标每个模块明列 **7 个专题**，即以此为「课」层级（**有教材则依教材、无教材则依课标内容要求**，是高中词表的建立原则）
- **层级映射**：`单元` ＝ 模块名（`选修1 史学入门` / `选修2 史料研读`）；`课` ＝ `专题X.Y <专题名>`（编号沿用课标原文，如 `专题2.2 文献史料研读`）；`册别` ＝ `选修1` / `选修2`
- **入库写法**：`册别: [选修2]`、`单元: [选修2 史料研读]`、`课: [专题2.3 实物史料研读]`
- **校验**：与其它册别同口径——`load_book_index` 与 `load_lesson_units` 均已收录，`validate_lesson` 会拦截错写（如把教材课名写进选修册别、或专题名不在 14 条内）
- ⚠ **维护要点**：改这两节时 **`qb_schema` 三处须同步**——① `GAOZHONG_SECTIONS`（节标题→册别缩写）；② `load_book_index` 的课名正则（须容许 `专题\d+\.\d+ ` 行）；③ `_UNIT_RE` / `_LESSON_RE`（须容许「选修N 模块名」单元与「专题X.Y」课）。**只改词表不动正则 → 选修条目解析不到、课名校验反而误报**
- **课标修订联动**：课标再修订（专题增删改名）时，按【内容要求】就地修订本节 14 条，并排查存量题「课」字段

## 维护铁律

1. **BOOK_INDEX.md 为唯一权威词表**：本技能内 `scripts/BOOK_INDEX.md` 直接维护，无第二副本
2. **新增册别词表**：从对应版本教材（单元→课→子目）**或课标/培训资料**提取，按体例写入 BOOK_INDEX.md → 重启校验（qb_schema 缓存首次调用后不再重读，新会话或 `python -c "import qb_schema; qb_schema._BOOK_CACHE=None"` 后生效）。**四处须同步**：① `qb_schema.BOOKS` 册别枚举（否则报「不在受控枚举内」）；② 初中册别维护 `BOOK_INDEX_VERSION`（册别→版本节）、高中册别维护 `GAOZHONG_SECTIONS`（节标题→册别缩写）；③ **无教材、依课标建表的册别（如选修）须扩展 `_UNIT_RE`/`_LESSON_RE` 与 `load_book_index` 的课名正则**，只加节不改正则＝解析不到、静默失效；④ `references/fields.md`、`SKILL.md`、`templates/` 的册别枚举表述一并更新
3. 子目不确定时标 `[?]`（据旧版推断），并更新节内核实说明——**不要**臆造确认
4. **学史方法改总表 + 各册节两处**：单元写 `学史方法`、课名写方法条目本身（无前缀），方法名须与 `## 初中·学史方法（全六册）` 总表逐字一致（写错会被 scan 拦下）；新增方法先改总表与各册节、再录题。改后须验 `load_book_index`/`load_lesson_units`/`load_method_units` 三处解析
